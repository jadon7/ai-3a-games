# 商场突袭（MALL STRIKE）

在浏览器里运行的第一人称射击游戏。场景、光照、角色、武器、HUD 和音效都来自《COD 风格枪战》视频的同一套素材，画面按视频的渲染标准实时还原。

## 怎么开始

1. 双击 `启动游戏.command`（第一次运行时，macOS 可能要你在"系统设置 → 隐私与安全性"里点"仍要打开"）。
2. 浏览器会自动打开 `http://localhost:8765/`。推荐使用 Chrome。
3. 加载大约 15–20 秒（场景和光照贴图共约 200MB），然后点击"点击开始"。
4. 不玩了就关掉那个终端窗口。

也可以手动启动：在这个文件夹里运行 `python3 serve.py`，再打开 `http://localhost:8765/`。

## 规则

- 团队死斗：先拿到 30 杀获胜，限时 8 分钟。
- 敌人会从店铺里、商场两端和二楼回廊冲出来，跑到能看见你的位置开火。
- 爆头一枪毙命，打身体需要 3 枪。
- 受伤后 4 秒不再挨打，生命值会自动回满。
- 阵亡 4 秒后复活，系统会选离敌人远的出生点。

## 画面是怎么做到的

- **光照：**商场的全部静态光照在 Blender Cycles 里预先算好（路径追踪），烘焙成光照贴图。阳光透过天窗的钢梁投影、筒灯光斑、店铺灯光、墙面之间的反弹光，都和视频是同一次计算的结果。
- **动态物体：**敌人和枪用 92 个 Cycles 渲染的全景光照探针打光，再叠加一个实时阳光（带阴影）。人走进阳光里会被照亮，也会在地上投下影子。
- **地面反射：**抛光大理石地面用实时平面反射，再按材质粗糙度做模糊。
- **空气感：**实时体积雾里有阳光光柱，阳光中还有漂浮的灰尘。
- **调色：**视频用的 Blender AgX（Medium High Contrast，曝光 -0.3）被原样烘成 3D LUT。泛光、色差、锐化、暗角、胶片颗粒的参数和视频的后期脚本一致。
- **运动：**相机运动模糊按视频的快门（0.45 帧）计算。

## 文件

- `index.html`、`src/`：游戏代码（three.js）。
- `assets/`：模型、光照贴图（`lm/`）、光照探针（`probes.exr`）、贴图、音效（`sfx/`）、色彩 LUT。
- `serve.py`：本地服务器，不缓存文件，方便直接改代码刷新。
- `test/`：HUD 和音效的单独测试页。

## 调试参数（地址后面加）

- `?fps=1`：左上角显示帧率。
- `?god=1`：无敌。
