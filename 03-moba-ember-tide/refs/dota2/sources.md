# Dota 2 画面对标参考图来源

仅作内部画面对标参考，不再分发。共 25 张：terrain 7 / heroes 6 / vfx 6 / ui 6。

来源缩写：
- **Steam** = Steam 商店页 https://store.steampowered.com/app/570/Dota_2/ （官方截图，1920x1080）
- **IIG** = Interface In Game https://interfaceingame.com/games/dota-2/ （2019 年 7 月的实机截图，3840x2160）
- **官方技能演示视频帧** = dota2.com 英雄页用的官方技能演示视频（1920x1080 webm），用 ffmpeg 截取的单帧，不是原生截图；画面是当前版本地图上的演示模式，无完整 HUD

注意：Steam 的 vfx-01、vfx-02、vfx-03 三张用的是付费/活动换肤地形（非默认地图），看特效可以，不要拿来对标默认地表。
