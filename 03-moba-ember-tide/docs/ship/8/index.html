打磨和上线

这一阶段做了六件事：把进一局要下载的东西从 66 MB 压到 26 MB（手机 20 MB）；做了手机横屏的界面和触屏操作；做成能装到主屏幕、断网也能开的 PWA；对着 Dota 2 的截图改了调色、影子、河面和面板质感；加了音效；宣传片交给 Opus 5.5 做了一条。游戏已经发布到 moba.dsxzai.com（你选的域名）。

已经上线

发布在你的 Cloudflare 账号下，一个叫 jinyuchao 的静态站（Workers 的静态资源托管），域名 moba.dsxzai.com 是发布时自动绑的（解析记录和证书都是 Cloudflare 自己建的）。任何拿到地址的人都能打开。重新发布只要 npm run build && npx wrangler deploy。从这台电脑的网络第一次打开，选好英雄到进对局用了 15 到 27 秒（都花在下载那 20 多 MB 上，Cloudflare 在大陆没有节点）；第二次起走缓存，几秒。

moba.dsxzai.com　点开就是主菜单；手机上横过来玩

宣传片（Opus 5.5 做的）

交给 Opus 5.5 做的（后台任务，前后约两个小时）：它自己写分镜、自己从游戏里录素材、自己用 ffmpeg 剪，改了三轮；水晶爆炸的效果修好以后又重录重剪了结尾。它没有用实时录屏（只有二十帧上下）：写了一个脚本把页面的时间接管过来，每推进三十分之一秒截一张图，所以每一帧都准，慢放也平滑。成片 1920×1080、30 帧、64.8 秒、没有声音（没有配乐素材，留给你配）。我把成片每秒抽一帧看过，结尾那一段抽得更密：没有白屏，没有网址和调试字。下面是压到 13 MB 的网页版；质量优先的那一份（118 MB）在项目里的 docs/trailer/trailer.mp4，分镜和能重现的命令在 docs/trailer/README.md。

《烬与潮》宣传片，64.8 秒，无声。

  • 17–24 秒：塔下二打二带击杀慢放；葛隆打野猪
  • 24–34 秒：六个英雄各一个技能特写，左下角是英雄名和技能名
  • 34–40 秒：岩甲巨兽、岩石巨魔两只 Boss
  • 40–50 秒：五人团战带击杀慢放；奥森的大招收人头

  • 57–65 秒：手机外框里的触屏对局，“手机横屏，也能玩” → 落版：标题加“三对三 · 三条线 · 一条河”

它自己说还弱的地方

  • 六个技能特写都在测试场同一个河道口、对着同一组靶子，背景一样，有点像测试录像。
  • 团战和推塔里血条、伤害数字多，画面挤。
  • Boss 只有打架的画面，没拍到倒下。
  • 手机那一镜是电脑在打，摇杆不会动，只能看出是触屏布局。
  • 水晶爆掉那一镜里打水晶的人几乎不在画面中，看着像水晶自己炸了；推塔那一镜开头有一块半透明的技能范围提示入画。
  • 中间几段都在烬誓庭的红地上，颜色变化少；立绘原图只有 600×800，放大后在大屏上会有点软。
  • 它和我都只看过抽帧，没有在播放器里从头到尾实时看一遍，节奏是按秒数判断的。

做宣传片时顺带查出的游戏问题

Opus 5.5 录素材时报了五个游戏本身的问题。我逐个核实，修了三个。

它报的问题我做了什么
塔和水晶被拆时没有爆炸，一帧里直接换成残座；水晶是一局的结尾，很不够劲已修。现在会炸开：一团亮光、两圈冲击波、飞溅的碎晶和火星、往上翻的烟尘、地裂，镜头震一下；水晶接着再炸两下，一下比一下大。宣传片的结尾按新效果重录重剪了

导播会长时间盯着一个人单挑 Boss（有一段 35 秒），几乎不看打小野怪已改。打野和人少的 Boss 战看十几秒就歇十二秒；打小野怪的分数提到普通对线之上。跑了五分钟观战没有报错，但换镜头的节奏有没有变好，我没有长时间看过

手机横屏和触屏

布局照手机 MOBA 的行业习惯（王者荣耀、LoL 手游）：左下摇杆，右下一个大的攻击键，技能键绕着它排成一段弧，大招在最上面、大一圈；小地图在左上，下面是金币（点开商店）；血条蓝条在底部正中。技能键点一下自动对准最合适的目标，按住拖动自己瞄，拖进右上角的“取消”圈就不放。点地面照样能走。竖着拿会盖一层提示并暂停。

一段真的发触摸事件的操作（844×390，手机档画质）。白色圆点是手指的位置：推摇杆走到兵线 → 按住攻击键 → 点一下技能自动对准 → 按住第三个技能拖着瞄再松手 → 大招拖着瞄、拖进“取消” → 再放一次 → 开商店。这是脚本在电脑的 Chrome 里按手机的参数跑的，不是真手机。

手机上画质自己降

手机和平板用贴图小一号的模型（2048 → 1024，法线 512）、小一号的阴影，总像素封顶 170 万。帧率不到 45 就降分辨率，最低降到一半；降到底还不到 30 帧再关阴影。用软件渲染模拟了一台很慢的设备，确认它会一档一档降下去。

位移技能不乱飞

技能点一下默认对准敌人，但薇萝的翻滚不该朝敌人滚过去：这类技能标了“朝摇杆的方向”，没推摇杆就朝面前。

苹果手机的全屏

苹果的浏览器不给网页全屏，只能“添加到主屏幕”。主菜单在苹果手机上会多一句提示；安卓上第一次点屏幕就进全屏并锁横屏，能装的浏览器在主菜单上多一个“安装到桌面”。

下载量：66 MB → 26 MB，手机 20 MB

量的是“选好英雄进一局”实际下载的字节数（打包版，本机量的）。代码那 1.07 MB 是没压缩的大小，CDN 会再压到三分之一左右。

装到主屏幕，断网也能开

有 manifest、图标、service worker。外壳（页面和代码）装的时候就存好；模型贴图用到才存，进过一次对局以后在后台把这一档剩下的补齐。重新上线以后，老用户下次打开就换成新版，旧缓存整个删掉。

离线测试（打包版，脚本跑的）结果
service worker 装上并接管是
manifest烬与潮 / 全屏 / 横屏 / 3 个图标都拿得到
进一局以后缓存里的文件78 个
断网后重新打开同一局能进，对局在走
断网后打开主菜单能开

这次测试抓到的一个真问题

  • service worker 的注册原来挂在页面的 load 事件上，但挂的那一刻 load 有时已经过了，结果就是没注册上（WebKit 里碰巧注册上了，Chrome 里没有）。离线测试超时才发现，已经改成“页面已经载完就直接注册”。

对着 Dota 2 的截图改了三轮

做法是在同一类场景下把我们的截图和 Dota 2 的参考图并排放，挑最显眼的差距改。第一轮：Dota 2 有一层柔和的调色、影子又软又浅，我们的画面偏灰、影子又硬又黑。第二轮：桌面界面的面板太平。第三轮：近镜头下河面的粼光是一块一块的白，是画面里最碎的东西，Dota 2 的河是平静的。下面每组图都是左边改之前、右边改之后（同一个机位、同一个时刻）。

音效

之前游戏完全没有声音。现在有了：打中、开火、放技能（沉月会是往上扬的水声，烬誓庭是往下沉的火声）、击杀、拆塔、升级、补到刀的金币声、Boss 的重击和咆哮、界面按钮、买装备、胜负，加一层很低的风声。全部用 WebAudio 现场合成，没有任何音频文件；小兵互殴的声音很轻，离镜头远的听不见，同一种声音不堆叠。菜单里可以关。我听不了声音：只能确认有声、没有爆音（峰值 −12 dB），事件和声音对得上；好不好听要你来听，下面是录下来的 16 秒。

观战模式里的一段打架，原样录的。这些是合成出来的占位级音效，能分清谁打了谁、放了什么，谈不上录音棚的质感。

差距、没验证的、花费

和 Dota 2 比还差的

  • 场景的层次：Dota 2 有高大的树冠压边、成片的植被和雾，我们的地图更空、更平。这是内容量的差距，不是这一阶段调参数能补的。
  • 英雄在画面里还是偏小偏暗，没有 Dota 2 那种一眼跳出来的轮廓光。
  • 音效是合成的占位级；没有配乐、没有英雄语音。
  • 面板加了质感，但还是没有雕花的外框。
  • 阶段 6、7 留下的那些没动：电脑三档难度拉不开、对线偏保守、阵营平衡只是粗调、野怪动作的毛病、没有技能加点和装备合成。
  • 薇萝大招的箭太细，画面里看不清；被拆以后的塔和水晶只剩一截矮石座，没有倒塌的过程（现在靠爆炸盖过去）。

没验证的

  • 真手机。没有在任何一台真的手机上跑过。iOS 模拟器的访问授权没人应答，所以也没用上；用 WebKit 内核代替，只能说明同一个内核下能跑、布局对。刘海和地址栏的实际占位、真实显卡的帧率和发热、内存够不够，都不知道。
  • 安卓上的全屏和锁横屏、“安装到桌面”的弹窗。
  • 声音好不好听。
  • 我没有亲手打完一整局。
  • 别的网络（尤其是手机流量）下第一次打开要多久；很多人同时打开时的表现。
