# 新英雄 · 刺客「伊缇 · 绯刃」设计方案（第一阶段，待用户确认）

用户原话：“我感觉现在的角色技能都很普通，没有张力，没有视觉效果，设计一个刺客英雄，所有技能和特效要足够帅，爆发流上海，四个技能，动作有张力、幅度大。有多段位移效果。特效层面我看到 https://www.douyin.com/video/7709870497600860645 这个链接里别人用 codex 实现的特效非常好，可以让我们的 codex 也试试”；“这个角色的设计，也分阶段来完成，过程中找我确认”。

## 参考视频里值得学的（只看，不拿素材）

那条视频是 UE5 里用 GPT 6.2 做的一组特效，52 秒，我逐段截图看了：

| 时间 | 是什么 | 我们要学的 |
|---|---|---|
| 0:03–0:05 | 人物身边一圈白色螺旋刀气 | 刀光有厚度、有一层白芯加一层带颜色的身子，外沿拖细丝 |
| 0:11 | 竖直劈下的紫色闪电，背后一道暗红能量柱 | 先暗后亮的节奏，地面一道亮线 |
| 0:13–0:15 | 品红、橙、紫三色的动漫风爆发，边缘是硬的色块 | **最适合我们的卡通厚涂**：平涂两三阶的色块、硬边，不靠发光堆亮 |
| 0:21 | 一弯紫粉色的新月斩，周围碎光点 | 新月的形状干净，细光点点缀 |
| 0:22 | 蓝色星图法阵 | 地上有形状清楚的图案 |
| 0:27 | 霓虹光带（五线谱）拖尾 | 干净的光带拖尾 |
| 0:43 | 火柱爆开、火星、地面冲击 | 爆点的体积感和层次 |

结论：最打动人的是“形状干净 + 两三阶硬色块 + 亮芯克制 + 节奏有停顿”，这正好和你一直要的“干净、融合、发光克制”对得上，也和现在的卡通厚涂画风搭。

## 定位

- **阵营**：烬誓庭（现在的刺客岚是沉月会，补一个对面阵营的刺客）。
- **位置**：中路刺客，也能打野（选人时位置写“中单 / 打野”，电脑默认放中路）。名册变成 11 人。
- **主色**：**绯红到品红**的“绯焰”，亮芯是暖白，点缀少量赤金火星。烬誓庭现在已经有很多橙红（葛隆、卡兹、薇萝、赫达），绯红偏品红一档，一眼分得开；参考视频里最好看的那段动漫爆发也是这个色系。
- **玩法一句话**：贴脸前看不见，贴上去以后两秒内连着闪三四次、把脆皮打穿，然后闪回安全处。

## 外形（第二阶段出设定图）

- 人形，身材修长，动作轻；穿深色贴身短甲，烬誓庭的暗铁护臂。
- **一条很长的绯红围巾**拖在身后：跑、闪、转身时都飘起来，是动作张力的主要来源，俯视镜头下也是最好认的轮廓。
- 半张暗铁面具盖住下半脸，眼睛一道亮色。
- 武器：**双持反握短刃**，刃身暗铁、刃口一道绯红（和岚的钩镰分开）。
- 和岚的区别：岚是兜帽、钩镰、青色；伊缇是围巾、双短刃、绯红。

## 技能（四个 + 被动）

数值是第一版，第四阶段放进对局里调。

**被动 · 烬痕**
- 伊缇的技能打中敌方英雄，给它叠一层烬痕（最多 3 层，4 秒）。
- 叠满 3 层的那一下引爆：额外打 **目标已损失生命的 12%**（对英雄），目标身上炸开一朵绯红的花形爆裂。
- 伊缇参与击杀一个英雄：Q 立刻回满、R 冷却减少 20%。

**Q · 三叠斩（三段位移）**
- 4 秒内能放三次，每次朝瞄准方向冲 4 米，砍穿路上的所有敌人（每段 70 + 0.7 攻击力）。
- 第三段是腾空翻身下劈：冲 5 米，落地砸出一圈冲击（110 + 1.0 攻击力），把周围敌人减速 40%。
- 每段打中英雄，下一段的冷却间隔缩短；三段都放完或超时，进 9 秒冷却。
- 参照：瑞文 Q 的三段、永恩 Q3 的冲刺斩。

**W · 残焰（留影、换位）**
- 原地留下一个绯焰残影，自己往前冲 5 米。
- 4 秒内再按一次：瞬间换回残影的位置（闪现），残影原地炸开（90 + 0.6 攻击力）。不换回，4 秒后残影自己炸。
- 冷却 14 秒。进场留后路、打完换回去，或者反过来用残影骗位置。
- 参照：劫的影分身、乐芙兰 W 的回位。

**E · 影步 · 穿心（指向闪现）**
- 闪到 6.5 米内一个敌方英雄的**身后**，反手刺一下（80 + 0.8 攻击力），让它 3 秒内受到的伤害多 15%。
- 目标身上已经有 2 层烬痕时，这一刺直接叠满引爆被动。
- 冷却 10 秒。
- 参照：塔隆、阿卡丽 R 一段的贴身。

**R · 绯月千刃（连锁闪现 + 大爆发）**
- 指定一个落点（8 米内），伊缇消失、不能被选中 1 秒，在落点 6 米内的敌人之间来回闪砍，最多 6 下（每下 60 + 0.4 攻击力，每下都叠烬痕），优先英雄。
- 最后回到中心，一道巨大的十字新月斩炸开（200 + 1.2 攻击力 + 目标已损失生命的 20%），中心 3 米内再多 25%。
- 冷却 70 秒（6 级学）。
- 参照：易大师 Q、亚索 R 的落地、劫 R 的标记爆发。

**爆发怎么打出来**：E 贴身（1 层）→ Q 一段（2 层）→ Q 二段（3 层，被动引爆）→ R 收尾，1.5 秒左右；残血就 W 换回残影撤走。

## 动作（第三阶段做，全部新出，不套旧动作）

这次要“有张力、幅度大”，所以照第九轮新英雄的做法：即梦出动作视频 → 读成动作 → 烘到 Tripo 绑的骨架上。共 10 段：

| 段 | 怎么动 |
|---|---|
| 待机 | 压低重心的蹲姿，双刃反握在身侧，围巾在身后飘 |
| 跑 | 身体大幅前倾的冲刺跑，双手向后拖，围巾拉成一条直线 |
| 普攻 1、2 | 左右交替的大幅旋身斩，刀光划满半圈 |
| Q 一、二段 | 低身前冲斩，一刀横切 |
| Q 三段 | 腾空前空翻，下劈落地成单膝跪地 |
| W | 后撤一步留影，接一个前扑冲刺 |
| E | 原地一缩消失，下一帧在身后出现、反手上挑刺 |
| R | 起跳到空中连续翻转劈砍几刀，落地双刃交叉成十字收势 |
| 死亡、回城 | 照常 |

出手时刻照手感的规矩：普通技能 ≤0.3 秒、大招 ≤0.4 秒（大招的空中连砍是技能本身的时长，不算前摇）。

## 特效：交给 Codex 做（第二阶段先试两个技能）

做法：
1. 给 Codex 单独一个文件夹（`lab/fx_codex/`），里面放一个独立的特效试验页：和游戏一样的 three.js 版本、一样的俯视镜头（约 50 度、27 米）、B 的地面和光照，一个占位的小人沿着技能路径移动。
2. Codex 每个技能写成一个独立的特效模块（一个函数生成、每帧更新、结束回收），用着色器画新月刀光、动漫风的硬边爆发（两三阶色块）、拖尾光带、地面裂痕和冲击环。我把画风规矩写进任务说明：主色绯红到品红、亮芯暖白、发光只在核心那一下、深色地面痕迹用暖褐不用黑、手机档减半。
3. 它在试验页里自己录像、并排看、改几轮（和建塔那次一样，它会照着改）。
4. 第二阶段先做 **R 的十字新月斩** 和 **被动的绯红爆裂** 两个，录成视频给你看 Codex 的水平；你认可了，第四阶段再做全部，由 Opus 接进游戏、调节奏。
5. 和建塔那次一样，Codex 要按你电脑上的默认权限（完全访问）跑——在沙盒里 Blender、浏览器会崩——任务说明里写死它只能写自己的文件夹。
