只出图，没改代码，没提交 git，没碰 `lab/`。画风照 `docs/style_b/STYLE.md` 路子一（王者式卡通厚涂），外形照 `docs/hero_iti/DESIGN.md` 的“外形”一节。

## 结论

| | 方向 A | 方向 B |
|---|---|---|
| 一句话 | 女性，银白利落短发，深紫灰贴身短甲，火舌尾的绯红围巾 | 男性，黑发高马尾、发尾绯红，左肩一块暗铁护肩，更宽更长的围巾 |
| 脸 | 半张暗铁面具（赤金包边），绯红发光的眼睛，露出眉眼 | 半张兽颚形暗铁面具（两侧通气缝），双眼一道横过去的绯红亮线 |
| 气质 | 轻、快、干净，“舞者” | 冷、硬、更有压迫感，“独狼” |
| 游戏镜头摆的动作 | Q 低身突进斩（围巾拉成一条直线） | R 落地、双刃胸前交叉（围巾和马尾绕成大弧） |

**我推荐 A。** 理由：
1. **俯视里头顶有一块亮的。** 游戏镜头从上往下看，最先看到的是头和肩。A 的银白头发让头部 35% 的像素亮度超过 0.6，B 的黑发只有 7%（岚 21%、薇萝 8%）。两个方向整体都偏暗（见“量数”），A 至少有一块“比红土亮”的地方，B 在红土上只能靠绯红围巾。
2. **建模和绑骨的风险小。** A 是短发、贴身甲，没有会和腿粘在一起的衣摆，也没有马尾（Tripo 自动绑的骨架里没有马尾的骨头，马尾会是硬的）。B 多了马尾和到膝盖上方的衣摆两样。
3. **最贴设计方案。** “身材修长、动作轻”，围巾是唯一的飘动主角，A 的剪影最干净。

**B 的长处也要说清楚：** 海报里 B 更有冲击力（马尾和围巾两道弧线）；现在人形英雄里女性多（岚、薇萝、赫达、摩珂 4 个，男性只有葛隆、塞伦 2 个，乌戈算半个），选 B 能平衡一点。**如果选 B**，建模前要再改一稿（约 13 积分）：衣摆改到大腿中部、加一块亮的东西（比如面具的赤金包边加宽、护肩倒角提亮），不然在红土上太暗。

读法：两个方向都是“深色剪影 + 一块很艳的绯红”，和薇萝、卡兹、葛隆是一类，跨度在十二个里最小（和薇萝并列）。草地和石板上非常好认（深色对浅色，绯红对青绿）；红土上靠围巾的玫瑰红 / 品红和橙红土地拉开色相，能认出来但不如在绿地上跳。STYLE 3.1 说的轮廓亮边进游戏必须加。

## 怎么出的

- 全部走排队脚本 `tools/jimeng_lock.sh`，任务单是这个目录的 `jobs_1.json` … `jobs_4.json`（提示词全文在里面）。出图记录追加在 `concepts/_raw/log.jsonl`，名字都以 `iti-` 开头，以后要拿这些图当参考图（i2i）直接写这些名字。

## 自己觉得还不够好的

1. **反握没全画对。** 要的是反握（刀刃从小指一侧伸出、贴着前臂），只有 A 的游戏镜头大致是反握；B 的游戏镜头和两张海报都是正手握。我在提示词里把反握写到了“刀柄握在拳里，刀刃从小指一侧伸出”，模型还是常画成正手。第三阶段出动作视频时提示词要写死反握，脚本建武器时握持方向按反握。
2. **动作图里刀会变弯。** A 的游戏镜头和 A 海报里有一把刀弯成了爪刀 / 小镰刀的样子，和岚的新月钩刃有点撞。以武器图（直的短刀）为准。
3. **两个方向都偏暗。** 设计方案定的是“深色贴身短甲”，所以 p90 只有 0.51–0.53，在红土上亮部没比地面亮多少。我已经要了“提亮到中深、不要近黑”，再提就不是深色甲了。进游戏要靠轮廓亮边；如果用户觉得太暗，可以把贴身甲提成中灰紫 / 中石板灰（一次只改颜色，13 积分）。
4. **围巾的建模方式要第三阶段定。** 设定图里两条围巾尾巴是“被风吹起、斜飘在身体一侧”，这是为了让 Tripo 看清它和身体是分开的；但 Tripo 会把它当成一块固定形状的布烘进模型，蒙皮会跟着胯或腿走，跑起来飘不起来。我的建议：Tripo 只用脖子上那圈厚领，两条尾巴单独用脚本建成一串骨链（或游戏里程序化的飘带），这样跑、闪、转身时才真的有张力。
5. A 的手是掌心朝上摊开（跟着参考图里岚的手），不是 A 字要求的掌心朝下（b-sheets 的摩珂也是这样，Tripo 一般能处理）。
6. B 第二稿的衣摆只短了一点，还到膝盖上方（要的是大腿中部）。
7. B 的游戏镜头是双膝跪地（要的是单膝），身上一圈粉色亮描边，有点像选中特效；A 的游戏镜头也有一圈很淡的暖色描边。
8. 海报是便宜模型出的：天空里有一点色带；A 海报的背景是一片亚洲风格的楼阁，不是烬誓庭的红土火山地。只是用来看“够不够帅”，第四阶段做正式海报时要重出。
9. 武器第二稿的刃口光边比第一稿弱，俯视下可能看不清，建模时刃口要按“全把最亮”的强度做。反握短刃的长度达不到 STYLE 说的“武器不少于身高三分之一”，进游戏时靠刃口的绯红亮边和刀光补。
10. 没有背面图：围巾、马尾在背后怎么走，只在动作图里看得到。用户选定方向以后、建模之前，补一张背面（13 积分）。
11. 游戏镜头里的小兵是即梦自己画的（光头、青白布甲），只当比例尺。
12. 都没进 Tripo 试过。
