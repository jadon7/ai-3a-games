# iti-kit：伊缇 · 绯刃的技能代码（第四阶段）

分支 `iti-kit`，提交 `dce4d8b`（合并了 style-b 的小兵放大 `3835ef6` 之后）。这个目录是证据，不进 git。

## 结论

伊缇能选（选人界面中单第三个）、能打、电脑会用、会被电脑排进两队。五个技能照 PHASE4 的表写完，范围和段数没改；特效全是 `ITI_FX` 的占位。
伤害调过三版：第一版她一局 15–19 杀、11 分半推平；最终版 7–11 杀、伤害是同位置老中单的两倍上下，对局 13–16 分钟（同阵容换成乌戈 16 分 21 秒）。
11 级一套 E→Q→Q→Q→R 秒满血法师、射手（大招第 6–8 刀就死，没等到十字新月斩）；坦克一套打掉 46%，两套才死。
