# 伊缇 · 第二阶段重做特效 `iti-fx2`：Opus 自己做“王者那一档”

2026-11-21，Opus 5.5 自己写（没用 Codex）。**同一天按调度意见返工了一轮（假泛光、去粉、R 刀气加宽、Q 横切加大、被动花缩小、R 终结减东西、补红土），这个目录里的录像和连续帧都已换成返工版，改了什么见末尾“返工”一节；“上一轮”的同一时刻对比在 `逐轮对比_返工.jpg`。**只在 `lab/fx_iti/` 的试验页里做，没改游戏代码（`src/`）、没接进游戏、没提交 git；没碰 `art/hero_iti/`、`public/`、`lab/fx_codex/`。

## 结论

**和 Codex 那版比，强在四个词都落到了画面上**（并排图 `并排_Codex_*.jpg`）：

- **炫**：R 按下去整个地面压暗一档、只留人亮着，落点 6 米一圈绯红法阵（即梦出的符文图）；六道两头尖、白芯的长刀气在空中交成一张星形的网；终结是两弯 11 米的新月交叉成 X、中心大星芒、全屏闪一下、压暗一下子收掉。Codex 那版没有压暗、没有法阵，刀网是细红线，终结只有 X 和一圈环。
- **打击感**：每一下命中都是同一套“目标整个闪白 → 顿帧 → 镜头小抖 → 白芯星芒 → 顺刀路溅火花和碎片 → 身上一道刀痕”，Codex 那版只在终结时抖了 0.16 米、顿了 0.032 秒（被动抖 0.08 米），六刀闪砍和三下普攻都没有顿帧和抖，闪白只用了游戏原来那种亮轮廓。R 一次要停 6 次小顿帧 + 1 次 0.12 秒的定格 + 终结时英雄身上再各停一下。
- **张力**：起手有“地上的光往脚下收、光点往刀上聚”，伊缇消失留残影；六刀之间每刀都停一下；终结前定格 0.12 秒（再暗一档、胸前一道 X 白光），然后一下子爆开。Q 三段腾空翻身下劈，一弯竖着的新月跟着翻身劈到地上。
- **范围感**：R 的法阵有一道清楚的亮边，冲击波一路推到 6 米边、推到时边线再亮一下，地面从中心裂到边；Q 三段落地 3 米整片闪一下（边线最亮）、两圈冲击环和一圈带高度的冲击墙推到 3 米边，3 米外放的那个小兵不受伤，范围一眼看得出。
- 被动从 Codex 的“红色剪纸 + 一蓬刺”换成了即梦出的八瓣尖花：白热 → 绽开 → 从里往外碎成尖片，头顶三格记号放到血条上面、叠满整个变白热再钻进胸口。
- **新做了 Q 三叠斩**（Codex 那轮没有）。

**离王者还差什么**（`并排_王者参考.jpg`）：

1. **没有泛光**：王者的光带一层柔和的泛光（后期 bloom），所以“亮”；我们的画面没有后期，只能靠白芯 + 饱和色 + 压暗地面撑亮度，近看偏“矢量”、偏平。
2. **粒子和贴图的细节少**：王者的刀光里有流动的能量丝、序列帧烟火；我们是着色器画的硬边形状 + 几种简单粒子（火花、碎片、余烬、碎石），一帧一帧看干净，但不够“丰富”。
3. **动作没跟上**：占位还是岚的模型和岚的动作（没有翻身、没有双刃交叉的收势），特效是贴着岚的动作摆的。王者的特效一大半是靠人物动作的张力撑起来的，第三阶段的伊缇动作做好以后要重新对刀尖、对时机。
4. **终结那一下还偏“满”**：法阵、刀网引爆、八道尖芒、X、冲击环、英雄闪白同时在 0.2 秒里出现，18 米中镜头下有点挤；27 米游戏镜头下读得清。
5. 粉色偏多：在亮草地上饱和的品红/绯红一叠就偏粉，深绯红只在压暗时最好看。

## 怎么做的

### 试验页（`lab/fx_iti/`）

从 `lab/fx_codex/` 复制了 `index.html`、`main.ts`、`api.ts`、`tools/rec.mjs`、`tools/sheet.py`（`lab/fx_codex/` 没动）。场景、光照、地面、镜头、站位和 Codex 那版一样，方便同一时刻并排。新加了四样屏幕上的东西，接口照游戏写，第四阶段直接接：

| 接口（`FxCtx`） | 做法 | 接进游戏 |
|---|---|---|
| `hitstop(sec)` | 照 `fxlib.hitstop`：sec 秒真实时间里世界时间 ×0.06 | 游戏已有，参数一样 |
| `shake(amp, dur)` | 照 `fxlib.shake/shakeOffset`：平方衰减、三方向不同频率 | 游戏已有。**差一处**：游戏的抖动跟着对局时间走，顿帧时抖也停了；王者是“停住 + 抖”一起，接入时 `shakeT` 改按真实时间累加（一行） |
| `actor.hit(k)` | 游戏的 `hero.hit(k)`（只亮轮廓）+ 再挂一层同骨骼的白色蒙皮网格，0.11 秒退掉——**整个人白一下** | 给 `hero.hit` 加一个 whole 参数，做法照 `main.ts` 的 `makeActor`（和 hero.ts 描边同一个挂法） |
| `dim(k, in, hold, out)` | 新：一张盖满屏幕的三角形排在不透明物体里、地面之后人物之前（renderOrder 1），“乘”的混合把地面压暗；人物 renderOrder 2、特效是透明物体，都不受影响——只留人亮着 | 地形 0、英雄小兵塔 2、这张三角形 1；十来行 |
| `flash(k, dur)` | 新：全屏加法闪一下（大招高光时刻） | 十来行 |

网址参数：`play=r|q|passive`、`cam=top|mid|close|距离,俯角,转角,x,y,z`、`ground=foe`、`q=lite`、`speed=0.25`、`nofx2=1`（关掉压暗、闪白、顿帧、镜头抖，看这四样各占多少分量）。

### 特效零件（`lab/fx_iti/fx/kit.ts`，约 680 行）

- **实例化的四样**（每样一个网格、一次绘制，几百个同时在场也只占一次 draw call，动画全在着色器里按时间算）：
  刀气长线（纺锤形、白芯、绯红身子、淡辉，“刷”地扫过去，能收细成发光的线留在空中、最后引爆碎掉）、星芒（四长四短/八芒大星/光点/闪核）、贴地冲击环（往外推/往里收/范围整片闪）、火花碎片（顺速度拉长的火花、旋转的绯红碎片、余烬、碎石）。
- **单个网格**：月牙刀气（白热刃线 + 三阶硬色块 + 内缘被噪声咬成丝缕，可以扫完停住变成两头尖的新月）、地面贴花（压暗地面 + 叠加发光两层，发光能冷却成暗疤；法阵带代码画的范围亮边）、爆裂花（即梦的花图做公告板：过曝白 → 绽开 → 从里往外碎）、冲击墙（有高度的一圈）、残影（预先克隆一池伊缇的模型，用的时候抄骨骼姿势，绯红菲涅尔）。
- **混合一律“预乘透明”**：一个像素里既有盖住地面的饱和绯红（亮草地上也看得清颜色），又有叠加的白芯。纯加法的红叠在绿草上会变土黄，这是 Codex 那版只能用平涂硬色的原因。
- 三个技能各一个文件：`iti_r.ts`、`iti_q.ts`、`iti_passive.ts`，开头写了分镜和时间点；命中共用 `hit.ts` 的 `strike()`。

| Q | 17（17） | 103（54） | 8 / 4 / 6 | 4 个 |
| 被动 | 11（11） | 58（29） | 6 / 3 / 3 | 0 |

R 的 22 次里：实例化 4 次、新月 2、贴花 2、残影每个 2 次、终结时 6 个目标的“整个人闪白”层各 1～2 次（接进游戏改用 `hero.hit` 的 uniform 就是 0 次）、压暗 1、闪光 1。真正的特效几何只有十二三次。手机档现在只减了粒子，绘制次数没减；要再省可以去掉残影（每个 2 次）和闪白层。

帧率（`tools/fps.mjs`，无界面 Chrome、显卡走 Metal、1600×900、不锁帧，同一页面里先量底数再循环放三段）：不放特效 163～325 帧/秒（无界面浏览器开头几秒显卡还没升频，读数抖得厉害），放 R 时平均 218、最低 148，Q 平均 272、最低 211；手机档 R 平均 231、最低 153。**只能当相对参考，没有在真手机上量。**

## 自己觉得还不够好的

1. **终结 0.2 秒里东西还是多**：中镜头下法阵、引爆的刀网、尖芒、X、冲击环、六个人闪白挤在一起，X 最完整的那几帧（第 1.4 秒前后）才干净。
2. **质感偏平**：没有泛光，刀身是硬边色块，近看像矢量图；新月里的细丝在 27 米下看不出来。王者那种流动的能量丝没做出来。
3. **偏粉**：亮草地上不压暗的时候，绯红和品红一叠就偏粉；红土地面没录（Codex 那轮录过），没验证。
4. **被动的白热核心**：第三下到绽开之间有约 0.1 秒是一团白粉的光球，比王者的白芯大、略糊。
5. **占位模型和动作**：伊缇用的是岚的模型和动作，Q 三段的“翻身”是代码把整个模型绕腰转一圈，落地没有单膝跪地；R 里伊缇闪到每个目标身后只露一个残影。换成伊缇的模型、动作以后，刀尖位置、残影、新月的圆心和时机都要重新对。
6. 血条在特效上面（界面层级，没改），R 中镜头下几条血条会挡住刀网。
7. 试验页没有迷雾、没有对局里的其他特效，接进游戏后团战里叠在一起会不会乱、手机上帧率多少，都没验证。
8. Q 的三段是连着放的演示（间隔 0.55 秒），真实操作里每段之间有间隔，时间点要在第四阶段按技能代码重排。

返工后自己觉得还不够好的：
1. 亮草地、浅石板上，红色光晕叠上去还是会发粉（红 + 浅灰 = 粉），只有在 R 压暗的时候是干净的深绯。要彻底不粉得把光晕的“盖住”比例再提高（会更像一层红膜），没再往下压。
2. 托尔格（大乌龟）这种大体型挨打时，整个人闪白 + 柔光圆是一大团白粉，0.08～0.1 秒。
3. 地裂冷下去在红土上几乎看不见。
4. 光晕是每个形状自己画的，形状之间不会互相“晕”到一起，近看比真泛光硬一点。
