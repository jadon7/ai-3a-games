## 王者的共同做法（看完总结的）

1. **刀气是“长而尖”的光**：李白大招每一剑是一道半屏长、两头尖的纺锤形光，白芯，外面一圈带颜色的辉光，旁边还跟一两道细的副线；不是一条匀宽的带子。
2. **命中那一下最亮、最短**：镜、李白、兰陵王打中人都是一颗白色星芒（四芒或多芒）炸开 + 目标闪白，持续一两帧到十来帧，马上收；星芒周围一圈品色光晕。
3. **范围要有亮边**：镜的领域是一圈很粗的红色亮边、往里渐变变淡；李白二技能先画圈（亮边），再沿着圈扫一道大刀环；云中君大招落地是一圈有厚度、带金色亮边的环。**范围靠边线读，里面的填色很淡**。
4. **落地有地裂和冲击**：云中君落地地面裂开（发光的裂缝 + 碎石块），韩信砸地是一圈红色地裂；冲击环推出去，余韵留一会儿。
5. **位移有残影和拖尾**：澜、镜冲刺身后都拉一道带颜色的拖尾和残影，刀光是一大弯月牙。
6. **颜色**：每个英雄一个主色（李白青白、镜紫白、澜蓝白、兰陵王紫），亮芯一律白；主色饱和，不发灰。王者的光有柔光（后期泛光），所以看起来“亮”——我们的画面没有泛光后期，只能靠白芯 + 预乘的饱和色 + 地面压暗来做出亮的感觉。
