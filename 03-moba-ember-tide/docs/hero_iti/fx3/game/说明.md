# 伊缇 · `iti-fx3` 第二步：特效接进游戏

2026-11-21，Fable 5.2。分支 `iti-fx3`（已 `git merge style-b`，拿到技能代码 `b04f9a5` 以及之后的提交）。
这个目录是第二步的证据。上一级目录（`docs/hero_iti/fx3/`）里第一步的录像是**改之前**在试验页里录的：压暗的颜色、地上的收尾、Q 一二段、大招的镜头都和现在不一样，看现在的样子以这个目录为准。

## 结论

- 伊缇的全部特效已经在真实对局里跑起来了：`fx_iti.ts` 换成了真的实现，技能代码（`heroes/iti.ts`）照原来的约定调，没有改调用顺序。测试场一套连招、5v5 团战里放大招都录了。
- 调度第二步的五条意见都改了（下一节逐条）。
- 回归四项全跑了，都过（见“回归”）。“屏幕演出只给看得见的那一次”单独验证了（对面的伊缇在迷雾里放大招，我这边没有屏幕演出、不顿帧）。
- 老实说还不够的：音效是现场合成的占位级声音，只能说“每一拍有响”，谈不上好听；5v5 里别的英雄的技能特效（团战录像里那几个蓝色的水罩、橙色的火圈）不跟着压暗，大招时画面上几种颜色的光会抢；帧率只在这台电脑的无界面浏览器里量过，机器当时在跑别的任务，数不稳；没有真人手操打过一局，没上过真手机。

## 接进游戏做了什么

- `fx_iti.ts`：只留类型和 `ITI_FX` 这个名字，实现在 `fx_iti_core.ts`。调度写的占位删了。新加两个函数：
  - `rGather(c, p, r, sec)`：大招在中心现身、往下落的那一拍；
  - `refresh(c)`：参与击杀后 Q 回满的那一下（原来是 `heroes/iti.ts` 里标着“特效占位”的 `refreshFx`）。
- `heroes/iti.ts`（技能代码，调度说这一步可以改）：只动了三处——`R_T` 的 `land`、`end`；现身时加一句 `ITI_FX.rGather`；`refreshFx` 换成 `ITI_FX.refresh`。调用顺序（引爆、W 换位、E）没动，我这边照它的顺序适配。
- 开局预热：场上有伊缇，载入时就把零件库、残影池（12 个）、贴图、着色器备好（`world/main.ts` 一行，没有伊缇的对局不走）。
- **屏幕级的演出只给看得见的那一次**（调度定的规则）：压暗、切入、打击帧、推镜头、径向模糊、色差、顿帧、镜头抖，都先判断“这一下的位置在不在玩家的画面里、玩家这一队看不看得见（不在迷雾里）”，不满足就只放世界里的特效。大招在按下的那一刻判断一次，整段用同一个结果。观战时没有迷雾，只按画面判断。
  验证（`迷雾里的大招_只给看得见的.jpg`）：我用岚，对面中路排一个伊缇。把镜头挪到离我 22 米的地方（迷雾里），让她在镜头正中放大招——我这边没有任何屏幕演出，3.4 秒里对局时间和真实时间一样长（没有顿帧），地上的法阵、刀光只露出落在我视野里的那一小截；把她挪到离我 5 米再放——全套都有。“在我视野里但在画面外”这一种靠同一个判断（先看在不在画面里），没有单独截图。脚本是 `tools/iti_fx_fog_check.mjs`。
- 小兵、野怪的整身一闪：`view.ts` 里新加 `fxl.flashUnit`。同一种小兵共用一份材质，挨打的那一个临时换上自己的一份（同一个着色器，不重编），约 0.11 秒后换回。
- 音效：`sfx.ts` 里新加 `itiSfx`（只有伊缇用），15 种，都是现场合成的：挥刀、命中、冲刺、腾空、砸地、闪现、穿心、引爆、残影炸开、按大招、每一刀（越往后音越高）、收刀的蓄、落地前的“叮”、十字新月、击杀刷新。离镜头 30 米外不出声。
- 打包：`vite.config.ts` 的 `KEEP` 加了 `assets/fx/`（打出来的包里有那五张贴图）。

## 镜头抖改成真实时间以后，老英雄的手感

|---|---|---|---|
| 葛隆 Q 撞中英雄，旧 | 0.30 秒（10 帧） | 0.149 米 | 0.019 米（几乎不动） |
| 葛隆 Q，新 | 0.23 秒（8 帧） | 0.215 米 | 0.06～0.26 米 |

## 回归

四项都用**最后的代码**重跑了一遍（第一遍是在“落地引爆让给新月”“花印改焦痕”两处改动之前跑的，结果一样，这里只写第二遍）。原始输出在 `regress/`。

1. `npx tsc --noEmit -p .`、`npx tsc --noEmit -p lab/fx_iti/tsconfig.json`：无报错。
2. `click_test`（26 项）、`touch_test`（31 项）：和技能代码那边交的结果（`docs/hero_iti/kit/regress/*_after.txt`）逐项比，布尔和状态类的全一样，`errors` / `报错` 都是空的。不一样的只有本来就会跳的数——点击：小兵剩的血 494 → 490、拖着走 7.2 → 6.5 米；触屏：几项“掉的血”差几个到十几点、摇杆走的米数 11.7 → 11.5、“点地面后走了几米”9 → 3.6（这一项在以前各轮的记录里就在 2.9～9 之间跳，技能代码那边自己的前后两次也是 9 和 3.6）。
   第一遍跑这两项时两个都报过一串 `Shader Error … VALIDATE_STATUS false`（所有材质、日志是空的），是显卡被别的任务抢了；等了一会儿重跑就干净了，第二遍没再出现。
3. `match_batch.sh`：`h=iti&diff=hard` 17 分 02 秒分出胜负（我方赢，16:8，伊缇 13/4/2），`h=lan` 21 分 33 秒分出胜负；两局 `errors` 都是空的。（第一遍：16 分 27 秒、伊缇 9/2/4；17 分 58 秒。）伊缇在电脑手里两局都是全场击杀最多的，数值是不是太强归数值那边看。
4. `npm run build`：能打出包，`dist/assets/fx/iti/` 里五张贴图都在（打完把 `dist` 删了）。

第二遍之后还改了一处：大招里的顿帧时长（两个数，见“另外发现、改掉的”倒数第二行）。这一处改完只跑了类型检查，加上重录带大招的那几段录像时页面没有报错；第 2～4 项没有为它再跑第三遍。

## 帧率

量法：`tools/iti_fx_fps.mjs`。正常的 5v5 对局开局，十个英雄升到 12 级、摆到中路打团（电脑自己打）；先量 6 秒“伊缇不放技能”当底数，再让伊缇循环放 E → Q → Q → Q → R（每套放完把人摆回去、冷却清零，至少放完两个大招）。**每一帧都记用了多少毫秒**。无界面 Chrome、显卡走 Metal、1600×900、不锁帧。

**这些数只能当相对参考**：量的时候这台电脑上 Blender 一直在跑（占六成 CPU，也占显卡），所有档位都有零星 0.5～1 秒的卡顿帧——**伊缇不放技能的底数里也有**。所以平均数不能用，下面只列中位数（一半的帧比它快），和“十字新月那一下”里最慢的一帧。等机器空下来最好重量一次，命令在表下面。

| 每帧毫秒（中位数） | 团战，伊缇不放 | 伊缇放、屏幕压暗着的帧 | 十字新月那一下（径向模糊、集中线都开着，约 70 帧） |
|---|---|---|---|
| 电脑档，带界面 | 3.4 | 5.8 | 5.1；最慢一帧 16 |
| 手机档 `q=lite`，带界面 | 3.7 | 5.1 | 3.9；最慢一帧 49（有 3 帧超过 33，分不清是特效还是被抢） |
| 电脑档，不带界面 | 1.9 | 3.7 | 3.6；最慢一帧 33 |
| 手机档，不带界面 | 2.2 | 2.7 | 2.1；最慢一帧 40 |

- 看下来：伊缇的特效（含屏幕演出）每帧多花 **电脑档约 2 毫秒、手机档约 0.5～1.5 毫秒**。按 60 帧算每帧有 16.7 毫秒，这点开销不到两成；真手机慢得多，没量过，不敢说。
- 绘制次数（不带界面时读到的整个画面；带界面时主程序读到的是头像那一遍的，不准）：团战里伊缇不放时 142～190（看别人正好在放什么）；伊缇放的时候最高 272（电脑档）、217（手机档）。
- 伊缇特效自己：同时最多 23 个网格（手机档 22）。电脑档的泛光要把这些再画一遍，再加几张全屏片（降到四分之一、三级模糊、合成、抓屏、最后一张）；手机档没有泛光。
- 粒子（火花、线、星芒、环加在一起）同时最多 439（电脑档）、220（手机档）。
- “团战里同时放”量的是：别的九个英雄照常放技能、伊缇同时放一整套。两个伊缇同时放大招没有量——排阵容的规矩是两队英雄不重复，正常一局里只有一个伊缇；用网址硬排两个的话，零件库是一局一份、两人共用，实例上限是按一个大招加一套连招留的余量，可能顶到上限、少画几道线，没验证。

重量的命令（先开测试服务器）：`MOBA_URL=http://localhost:5254/map.html node tools/iti_fx_fps.mjs "h=iti&seed=3"`，手机档在参数后面加 `&q=lite`，要绘制次数再加 `&nohud=1`。

大招被中止的那一遍留了一张连续帧：`连续帧_团战_大招中途被打断.jpg`。特效这边收得干净——压暗、镜头、法阵约 0.15 秒内收掉，人现身，刀网的线冷成焦痕慢慢褪，没有卡在暗的画面上。**为什么会被中止我没查**（她那时是不可选中的；可能是藏起来之前吃到的控制，或者范围技能不看“不可选中”）——这是技能代码那边的事，请你看一眼算不算毛病。

## 还不够好的、没验证的

- **声音**：能分清每一拍，但是占位级的合成音。无界面浏览器不出声，我自己一声都没听过——这 15 种声音的音量、音色、叠在一起吵不吵，完全没验证，需要你或用户在真浏览器里开一局听。
- **别的英雄的特效不跟着暗**：大招压暗只压世界，所有特效（包括队友、对手的）都还亮着。团战录像里别人的蓝色水罩、橙色火圈和伊缇的绯红同时在画面上，抢戏（看 `连续帧_团战_5v5.jpg` 第三行）。要压的话有个便宜的做法：大招期间在“别人的特效”和“伊缇的特效”之间再乘一张全屏的暗片（别人的特效和人物一起暗到六成左右，伊缇的刀光不受影响）——代价是人物也跟着暗一截，和现在“只留人亮着”的样子不一样，所以没擅自做，等你定。
- **单个目标时刀网是一团**：范围里只有一个英雄时，八刀都穿过他，线交在一点上，不是铺开的网（测试场的连招就是这样）；多个英雄时是网（5v5）。
- **顿帧是全局的**：一次看得见的大招累计让整个对局停约 0.5 秒（打满的情况），所有人都跟着停。调度说可以。
- 大招时左下角的头像框是一块红底（人藏起来了，头像那一遍画不到人）——这是技能代码藏人的做法带来的，我没动。
- 没有真人手操打过；没上真手机；帧率的数不稳（见上）。
- 镜头抖的手感是看数字和录像判断的，没有上手试。
