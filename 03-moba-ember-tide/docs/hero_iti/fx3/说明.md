## 结论

**和上一轮（Opus 的王者档，`docs/hero_iti/fx2/`）比，强在：**

1. **世界会变色了。** 上一轮大招只把地面压暗一档；这一轮按 R 整个世界（地面、墙、草、水）乘成暗绯，只留人和刀光亮着，一直压到炸完才慢慢亮回来。红光只有落在暗处才是绯红——上一轮“亮草地上发粉”的根子在这里。平时的重击（Q 三段砸地、W 炸开、E 穿心、被动引爆、Q 一二段出刀）各很短地暗一下。
2. **光晕会互相晕到一起了，而且只在该亮的时候亮。** 加了一遍“只画伊缇特效”的泛光（半分辨率、三级模糊、按绯红重新上色后叠回去），不动场景和别的英雄。光晕强度（形状自己画的那层和泛光）跟着“世界现在多暗”走：大招里给足，亮地面上只留两三成——亮地面上形状是干净的实色（白刃口、绯红身子），不再是一团粉雾。
3. **范围照新的约定全部放大了。** R 11 米（上一轮 6 米）、8 刀（6 刀）；Q 一二段冲 6 米、月牙半径 3.5 米（2 米）；Q 三段砸地 5 米（3 米）；W 炸开 5 米；E 那一刺从身前透出去 7 米。法阵外圈、裂缝的外半截改成代码画的细线（即梦的图拉到 11 米会糊）。
4. **补齐了全部技能。** 上一轮只有 R、Q、被动；这一轮加了普攻两下、W（留影、冲刺、换回、炸开）、E（影步、穿心）、一整套连招的演示。
5. **人是伊缇自己了。** 模型、动作、围巾都是第三阶段的 `iti.glb`；近战小兵是放大 1.3 倍以后的 1.89 米。
6. **代码就是游戏里的那一份。** 特效的实现在 `src/map/game/fx_iti_core.ts`（函数名、参数和 `ITI_FX` 一一对应），试验页用的是真的 `fxlib`、真的屏幕演出，主循环照 `world/main.ts` 的顺序走。第二步把 `fx_iti.ts` 改成从 core 导出就接上了。

**“跳脱”的几处（都是屏幕级的，上一轮没有）：**

**离“秒杀市面”还差什么（老实说）：**

1. **没有声音。** 参照里每一拍都有音效撑着（收刀的“叮”、定格的静、炸开的低频），我们这一轮一个音都没加（`sfx.ts` 不归这个任务）。没有声音，“停”那一拍的张力只有一半。
2. **动作还没对上。** 大招收刀时伊缇在法阵中心是张开手臂落下的姿势（动作表里 `r` 的 2.2～2.45 秒），不是“双刀交叉收势”；Q 三段的翻身是把动作压到 0.42 秒放的。这些要等技能代码把动作时间重排以后，第二步在对局里对。
3. **大招在中镜头（18 米）下偏满。** 11 米的法阵在 18 米镜头下比屏幕还大，炸开那 0.3 秒整屏都是绯红和白；27 米的游戏镜头下读得清。对局里镜头就是 27 米，但拉近看会觉得“一片红”。
4. **暗处的颜色偏粉红而不是深绯。** 白热的芯到绯红的身子之间必然经过一段粉；压暗以后好很多，但中镜头下人物挨打整身闪的那一下、刀气的光晕还是偏粉。
5. **亮地面上的 Q 一二段比大招朴素得多。** 为了不发粉，亮地面上把光晕收掉了，靠很短的压暗撑张力；并排看比上一轮干净、大，但“光更多”主要体现在大招和几下重击上。
6. **切入图是静态的。** 参照里的切入是几十帧的动画；我们是一张图加滑动和速度线，0.5 秒里看不出来，慢放能看出来。
7. **只在试验页里验证过。** 对局里的迷雾、团战里几个英雄的特效叠在一起、镜头跟着伊缇在八个落点之间跳、手机真机的帧率，都没验证（第二步的事）。

## 引擎里新增了什么（逐条）

| 文件 | 新增 | 会不会影响别的英雄 |
|---|---|---|
| `fxlib.ts` | `FxLib.screen?`：屏幕演出挂在这（主程序建好挂上来） | 不会：没人调就没有 |
| `fxlib.ts` | `FxLib.tick(fn)`：登记一个每帧都调的函数（对局时间），伊缇的零件库靠它推时间 | 不会 |
| `fxlib.ts` | `FxLib.lamp(pos, color, power, dur)`：只借用 `flash` 里那两盏很短的点光，不出柔光团 | 不会（和 `flash` 抢同样的两盏灯，规则一样：谁快灭了用谁） |
| `fxlib.ts` | **镜头抖改成按真实时间走**（PHASE4 允许的那一处例外）：`timeScale(真实 dt)` 里推抖动的时钟和进度，`shakeOffset` 的相位也用这只钟；没人调 `timeScale` 的页面照旧跟着 `update` 的 dt | **会，所有英雄**：凡是“顿帧 + 镜头抖”一起用的技能，抖动不再被顿帧拉长、停住的那一下能看到镜头在抖；观战慢放（导播的 `slow`）和 `?speed=` 快进时，抖动按真实时间走，不跟着变慢变快 |
| `hero.ts` | `Hero.hitWhole(k, color)`：整个人闪一下（不只亮轮廓），约 0.11 秒退掉；着色器里多一个 `uHitW`，平时是 0 | 着色器多了一行混合，`uHitW.a = 0` 时结果不变；老技能不调就没有变化。英雄和小兵的着色器会重新编译一次（文本变了） |
| `hero.ts` | `Hero.height`：连头冠的身高，特效按它找胸口、头顶 | 不会 |
| `hero.ts` | `tune()` 多一个可选的第九个参数 `hitW` | 不会（`view.ts` 调 `tune` 的地方没动，小兵用默认的全 0） |
| `world/main.ts` | 建 `screenFx` 挂到 `fxl.screen`；每帧 `screenFx.update(dt)`；镜头距离乘 `zoomK()`（平时是 1）；画完场景以后 `screenFx.post(camera)`；画左上角头像那一遍前后 `offscreen(true/false)` | 没人调屏幕演出时：`post` 里直接返回，不多画一遍（测试场里读到多画 0 遍）；`zoomK()` 是 1。在测试场里手动调了一轮压暗、打击帧、推镜头，调完以后画面和绘制次数（98）回到调之前。没有和“改之前的代码”逐像素比过 |
| `fx_iti_screen.ts` 的压暗 | 每次压暗开始时，把场景里名字叫 `hero`、`units` 的组下面 `renderOrder` 还是 0 的**不透明**网格改成 2（排在压暗那张后面画） | 只改不透明物体的先后，画出来的结果不变（深度测试照常）；在测试场和基地里看过：压暗时英雄、小兵、血条不暗，地面、墙、草、河水都暗。压暗那两张的着色器故意写 `pc_fragColor`，迷雾（`fow.ts`）包材质时不认它、不会给它加“看不见就压暗”的那一段 |

接进游戏时还要动、但这一步没动的（第二步做，先说在这里）：

- `vite.config.ts` 的 `KEEP` 里没有 `assets/fx/`，打包时这几张贴图不会被抄进 `dist`——要加一条 `/^assets\/fx\//`（一行，不归我管的文件，第二步找调度）。
- 伊缇特效的材质挂在 `fxlib` 的组下面，迷雾（`fow.ts`）会给它们包一层“看不见就不画”；泛光那一遍是半分辨率的，包过的材质按屏幕分辨率反推位置会错——第二步要么给这些材质标 `fowKeep`、自己按位置判断，要么泛光那一遍关掉迷雾。
- 小兵没有“整身一闪”（`view.ts` 的小兵用的是默认的 `hitW`）；试验页里小兵是按英雄的方式载入的所以能闪。第二步在 `view.ts` 里新增。
- 屏幕级的演出现在不分是谁放的。对局里要不要只给“自己放的 / 离镜头近的”才出切入和打击帧，第二步定。
- 大招期间镜头：试验页里镜头看着落点不动；对局里镜头跟着英雄，伊缇在八个落点之间跳的时候镜头不能跟着跳。
