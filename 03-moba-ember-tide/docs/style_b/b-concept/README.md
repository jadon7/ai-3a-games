## 怎么出的

- 全部走排队脚本 `tools/jimeng_lock.sh` → `tools/jimeng_gen.py`，任务单在这个目录的 `jobs_1_sheets.json` … `jobs_6.json`（提示词全文都在里面）。出图记录照常追加在 `concepts/_raw/log.jsonl`（名字都以 `sb-` 开头）。
- 参考图都用画布上已有的节点（不上传本地图）：
  - 英雄：岚 `h4-lan-sheet-a`、葛隆 `h1-gorran-sheet-a`（现在游戏里的模型就是照这两张做的）。
  - 环境：`c22-env_me_b`、`c22-env_foe_b`（B 的两张设计稿）。
  - 建筑：`c22-tower_me_s`、`c22-tower_foe_s`、`c22-core_me_s`、`c22-core_foe_s`（2.2 定稿的 A 方向特写，Codex 建模时参考的就是这一路）。
- 模型：试下来 N-2.1（`jm_image_model_gg_bp_21`，13 积分）和 N-Pro（25）效果几乎一样，大部分用 N-2.1；只有路子二的岚第三稿用了 N-Pro（N-2.1 两次都没改出动漫脸），第四稿再用 N-2.1 在它上面“只改颜色”（这种局部改的话 N-2.1 很听）。
- 游戏镜头图的做法：参考图 1 是该路子的建模设定图，参考图 2 是 B 的环境设计稿；武器用文字描述（不拿武器设计图当参考，免得把写实画风带进来）。路子二的游戏镜头里，**场景仍然是 B 的卡通厚涂，只有角色是赛璐璐**——游戏里真做路子二也会是这样。

## 粗量：英雄在亮地面上显不显眼

量法：在英雄身边各取一块草地（或红土）和一块石板路，取各自的中位色；在框住英雄的矩形里，和这两种地面色的距离都大于 60（RGB 欧氏距离）的像素当作英雄，算相对亮度（0–1）的 p10、p50、p90 和 HSL 饱和度。粗量：框里小兵的边、脚下的光圈会混进来，只看大概。

| | 地面平均亮度 | 英雄 p10 | 英雄 p50 | 英雄 p90 | 英雄跨度 | 英雄饱和度 p90 |
|---|---|---|---|---|---|---|
| 岚 现在（厚涂写实） | 0.40 | 0.21 | 0.44 | 0.75 | 0.54 | 0.59 |
| 岚 路子一 | 0.65 | 0.22 | 0.43 | 0.85 | 0.63 | 0.56 |
| 岚 路子二（定稿 `lan-p2-game-v2`） | 0.65 | 0.23 | 0.40 | 0.88 | 0.65 | 0.56 |
| 岚 路子二（作废的 `lan-p2-game`，颜色灰暗） | 0.65 | 0.24 | 0.43 | 0.87 | 0.63 | 0.40 |
| 葛隆 现在 | 0.41 | 0.16 | 0.22 | 0.62 | 0.45 | 0.25 |
| 葛隆 路子一 | 0.44 | 0.14 | 0.28 | 0.43 | 0.28 | 0.40 |
| 葛隆 路子二 | 0.40 | 0.12 | 0.28 | 0.61 | 0.49 | 0.76 |

读法：岚两个路子的亮部都比亮绿地面亮，跨度是地面的六倍，好认。葛隆路子一的亮部没有比红土亮，是“深色剪影 + 冷暖相反”认出来的；路子二多了描线和一圈橙色亮边，p90 回到 0.61。规矩里因此加了一条：深色主色的英雄进游戏要靠轮廓亮边补一圈亮（`STYLE.md` 3.1）。

## 自己挑出来的毛病（没修的）

- **两个路子在葛隆身上差别不大。** 全身盔甲、看不到脸，路子二只多了细描线、平涂和更深的炭灰；在游戏镜头缩小以后几乎分不出。真正能区分两个路子的是露脸、露皮肤、穿布的英雄（岚、赫达、塞伦）。
- **岚的鱼鳍头冠偏短。** 现在的建模图（sheet-a）上就是一根短尖角，新图照着它画；我在提示词里要了“又高又长、向后弯”，N-2.1 和 N-Pro 都没听，只有 Image 2.5 Pro 那张（`lan-p1-sheet-libs.png`）画高了。要不要把头冠加高，是设计问题，用户定。
- **游戏镜头图比真游戏近、英雄画得大。** 图里英雄约 700 像素高，游戏 1080p 下约 150 像素。对比总表里加了一行“缩到游戏里的大小”，按 150 像素缩过，那一行才是真正的可读性对比。
- **小兵是即梦自己发挥的**（我方青白、对方红橙的矮胖步兵），只当比例尺，不是小兵的 B 设计。
- **葛隆路子二的游戏镜头有一圈橙色的亮边加地上的光圈**，有点像选中特效，偏“发光”，进游戏时亮边要更窄更淡。
- **建筑的比例**：小人剪影标的是 2 米，但塔画得只有小人的三四倍高（应该是 9–11 米，四五倍）；Codex 建模照游戏里现在的尺寸，不照图上的比例。
- **烬誓庭的塔塔颈那圈悬浮的晶粒**发光略多；烬誓庭水晶 v2 的主影子仍然投向左边，和小人、火盆柱的影子方向不一致。
- **路子二进 Tripo 的问题没试**：设定图上的描线和硬边阴影会被烘进贴图，见 `STYLE.md` 3.3。
- **岚路子二第四稿的手变成了冷白色**（像戴了白手套）：“皮肤带一点冷调的白”这句让它把手也漂白了，原设定是露出的皮肤；建模前要改回肤色。
- **葛隆“现在”的游戏镜头是在沉月会的绿地上截的**（借用的 `ui2` 截图），新图是在烬誓庭的红土上，对比时地面颜色不同，只比英雄本身。
- **两个路子的武器只在游戏镜头图里有**，没有单独出 B 风格的武器设计图（建模要用的话第二批照规矩单独文生图）。
