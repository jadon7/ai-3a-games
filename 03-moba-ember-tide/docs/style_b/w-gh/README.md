## 做了什么

### 葛隆

1. **设定图**：`gorran-p1-sheet-bright.png` 直接当 `ref.png`。手半握拳、胳膊贴身，和第九轮的建模图一个姿势（那次 Tripo 也没粘），没有改。
2. **Tripo**：`hero_gorran_b` 40 + 绑骨 25，一次就过：砧形肩甲在右肩、T 形面罩、胸口炉栅、皮围裙都在，胳膊和身子分开。胯高和旧模型一样（k = 1.000）。
3. **武器（脚本建，形状照旧、贴图重画）**：`art/style_b/gorran/gear.py`。第九轮的方头锤和炉门塔盾本来就是 B 设计稿里那两件，没有尖刺镂空，形状留着——盾背面的臂垫、握把是照站姿解过的（`_solve`），形状不变这一套接着能用，旧动作里盾怎么举都不变。
   贴图全换：去掉锻打接缝、锈、划痕，只留大块冷暖；倒角一道干净亮边；黄铜铆钉；炉火亮金到橙红。材质 `weapon_b`、`weapon_ember_b`。
   改了两轮：①盾两侧各三段加强条把轮廓切碎了，去掉，主板放宽、边框加厚、拱抬高（B 的盾是一整圈厚边框）；②倒角亮边第一版太白，像描了一道亮线，压一档。
4. **套动作**：8 段（idle、run、attack1、q、w、e、r、death）全部套上，出手时刻差 0 帧，脚的 IK 把陷地 3.7–21.6 厘米修到 ≤0.5 厘米；手插进身体的比例和源一样（e 25.4%，源本来就是）。`runSpeed` 7.3 不变（量出来的比例 1.000）。
5. **颜色**：默认的提亮 1.4、饱和 1.3 下钢甲发白发艳（中间调 92,107,143），在 `heroes/gorran.ts` 的 `look` 里压到 `lift 1.15, sat 0.85`（HB 乘在上面，没动 HB）。
6. **发光**：身份表的发光处是“面罩缝、胸口炉栅、盾栅”。盾栅是脚本建的自带发光，面罩和胸口是 Tripo 贴图里的一块橙色（游戏只认青色纹路自己发光），压了提亮以后不像在烧。`art/style_b/gorran/glow_map.mjs` 在贴图里找又亮又橙的像素（去掉铆钉那样的小点），加一张 512 的琥珀橙自发光贴图，强度 1.6（试过：贴图本身颜色当发光看不出；橙色 1.0 看得出、不够像在烧）。

### 赫达

1. **熔炉单独建**（和第九轮同样的理由）：炉子是一大块硬东西，要整个只蒙在 Spine2 上；Tripo 出成一整块网格的话分不开、会被分给肩膀手臂；游戏代码按“炉子在 Spine2 后面”找炉口（`heroes/hedda.ts` 的 `furnace()`）。
   `art/style_b/hedda/make_ref.py` 从 `hedda-p1-sheet-v2.png` 里抠掉熔炉和烟囱：第九轮用 GrabCut 手画十几个多边形，这次改成“颜色 + 几个区域”——炉子是深钢蓝（B−R 10–30），挨着它的头发、皮肤、衬衫、皮带都偏暖，按颜色就分得开；同色的铁项圈用一个椭圆排除；炉门被火光染暖的那块和光晕整块去掉；右腰皮带后面露出的一条炉身换成皮带的深棕（换成灰底会开一道缝）。
2. **Tripo**：`hero_hedda_b` 40 + 绑骨 25，一次就过（发髻、护目镜、项圈、衬衫、围裙、手套、靴子都对）。和第九轮一样，Tripo 从背带猜出来一个背包。
3. **装炉子**：`art/style_b/hedda/add_forge.py`（照第九轮改）。改了三处：
   - 朝向改用两肩算：B 的模型两脚外八字约 33 度，原来按左脚尖取整到坐标轴会取成 45 度斜向，炉子会装歪（`hero_build.py` 自己按脚取整到 90 度没问题，量过 −122.9 度 → −90）。
   - 背包更厚（离脊柱 0.187，旧 0.136）、偏左（−0.06 … +0.15）：压扁的范围放宽，但主要蒙在手臂上的顶点不碰（722 个）。
   - 炉子第一版照旧整体放大 1.05，从背后看像一只细高的桶、两边露出一大截肩膀；设定图背面炉身差不多盖住两片肩胛，改成只放粗（左右、前后 1.15，高 1.03）。
4. **熔炉和火钳（脚本建，形状照旧、贴图重画）**：`art/style_b/hedda/gear.py`。对过 B 的正面、背面图：圆筒炉身、几道铁箍、背面竖铁条、右后腰透火光的小炉门、左上方斜伸的方烟囱，和第九轮的炉子是一个东西、大小也一样，只把烟囱加粗（半宽 0.025 → 0.03）。
   火钳设定图里没画，形状照第九轮：第九轮的动作（`fix_tongs.py`）是按这把钳子的握点、长度、朝向修过的，钳钩（Q）也从钳口飞出去，形状不变这些都不用重调。所以**没走 Tripo，也没用即梦出武器图**（`HERO_B.md` 把赫达的火钳列在“走 Tripo”，那是没看过第九轮的做法；这把钳子就是几根杆子加一对爪）。
   贴图：深蓝灰的铁只有大块明暗，钳口前端烧成饱和的橙红（自发光）。材质 `weapon_b`、`weapon_hot_b`（钳钩飞出去时游戏按 `weapon` 开头把它藏起来，测过）；炉子 `forge_b`、`forge_fire_b`。
   改了一轮：铁箍第一版一圈圈发白，炉子像箍了白圈的铝桶（第九轮也栽在这），压到比炉身亮一档。
5. **套动作**：9 段（idle、run、attack1、attack2、q、w、e、r、death，源是第九轮修过的 `motions_fix`）全部套上，出手时刻差 0 帧，陷地 4–6.5 厘米修到 ≤0.4 厘米；副手跟主手（`hands`）锁住了两手一起握钳子的帧，副手离握点从 0.75–1.08% 身高修到 0。`runSpeed` 5.0 → 5.03（比例 1.006）。k = 1.022。
6. **颜色**：默认的提亮、饱和就对：衬衫游戏里 225,212,208（设定图 234,221,207），炉子 67,72,92（设定图 50,51,65，亮一点，红土上更跳），没改 `heroes/hedda.ts`。

## 还不够好的、和设定图还差在哪

- 葛隆：
  - 待机时盾是侧着举的（旧动作就这样），设定图里正对镜头的圆炉栅在游戏里多半只看得到侧面；盾还是“上圆下方的门”，比设定图那面更圆的盾方一些。
  - 面罩的 T 形缝发光很弱（贴图里那几块颜色偏暗，发光贴图的颜色阈值只抓到胸口炉栅的大半）。
  - 钢甲亮部比设定图亮、偏蓝一点（171,185,216 对 133,154,180），砧形肩甲顶面在俯视里偏白。
  - 亮草地、浅石板上亮部没超过地面。
  - `look` 改成 1.15 / 0.85 以后，如果把 `gorran.glb` 换回 `v9-painted` 的旧文件，这一行也要一起退回（旧模型按 1.4 / 1.3 调的）。
- 赫达：
  - 俯视里炉盖是一大块深色圆盘，比人还显眼；设定图的炉子有一圈更宽的顶箍、偏一边的炉盖、更多竖铁条和铆钉，这里只做到大形。
  - 设定图里的锈斑我按 STYLE“不要锈迹”没画，炉身比设定图干净、平。
  - 待机时双手握着火钳挡在脸前（旧动作），近镜头里脸看不太清。
  - Tripo 猜出来的背包压成了贴着后背的薄板（权重全给 Spine2），炉子盖住了大部分；极端姿势下背包边缘和后背接缝处有没有拉扯，只看了拼图和测试场连拍，没有逐帧在游戏里查。
  - 套动作量出来“手插进身体”的比例很高（源也一样，idle 100%），是炉子把躯干胶囊撑大了（README 里写过的不可靠），只能横向比。
- 都没量手机档帧率（只截了手机档能正常载入、显示）。
