## 做了什么

1. **设定图**：直接用 `art/style_b/concept/lan-p1-sheet.png`（1792×2400，灰底、A 字、手是肤色，和以前的建模图同尺寸），没有裁、没有重出。即梦 0。
2. **Tripo 出模型**：`hero_lan_b`，`face_limit` 40000、`detailed`，40 额度，4 分钟。一次就过：四肢分开、头冠、珊瑚肩、骨甲、渔网、钩子都在，贴图是干净的手绘明暗。没有重出。
3. **绑骨**：biped、mixamo，25 额度，3 分钟。胯高和旧模型只差 2%（k = 1.022）。
4. **武器（脚本建）**：`art/style_b/lan/gear.py`，骨白新月刃 + 刃口内侧一道青线 + 深蓝缠柄 + 刀背两片小骨鳍 + 柄尾小钩，一把约 1600 个三角形，一张 256 的小贴图。理由：旧刀是写实的尖刺、镂空、裂纹，换材质救不回形状；新月刃形状简单，脚本最干净、不花额度，省下的额度留给重出模型。
   改了三轮：①第一版偏窄偏小、颜色偏黄 → 加宽、骨白调白；②游戏里俯视看刀常是侧着的一条细弧 → 再加宽，`gear` 里 `rot: [0,55,0]` 绕长轴转 55 度（试了 0 和 55，55 的站姿和挥刀都看得到整个新月）。
5. **套旧动作**：`tools/retarget/run_case.py`，9 段动作（idle、run、attack1/2、hook、veil、death、r、r_end）全部套上，2.5 分钟。脚的 IK 把陷地全修到 0（源 2–25 厘米），出手时刻差 0 帧，手插进身体的比例和源一样（只有 veil 6.8%、r_end 10.6%，源本来就是），死亡身体最低 −1.6 厘米（源 −12 厘米）。**没有一段要手修**。`runSpeed` 10.8 → 10.97（量出来的比例 1.016）。
6. **出品**：`public/assets/hero/lan.glb`（1.37 MB，原来 2.26 MB）、`lan.json`、`m/lan.glb`（1.17 MB，原来 1.52 MB）。B 的模型删掉了用不上的法线、粗糙度贴图（`tools/style_b/strip_maps.mjs`）。旧版在标签 `v9-painted` 里。
7. **材质**：`src/map/hero/hero.ts` 加了 B 的处理，按材质名 `_b` 结尾认（`hero_build.py` 加了一个可选的 `body_material`）。做法和每个数的理由见 `HERO_B.md` 的“材质”一节；调了三轮：①照搬厚涂版的提亮饱和 → 电光蓝；②只留一小部分提亮 → 量出来骨白、珊瑚比设定图暗两成；③提亮照旧、饱和度乘 0.7、软交界、顺光窄亮边，颜色量下来和设定图差几个色阶（下表）。
