卡通版验收

你说“git 记录一版，然后风格换卡通的吧”，选的是路子一“卡通厚涂”。换之前的厚涂写实版已经存档（main 分支和标签 v9-painted，也就是线上 moba.dsxzai.com 现在跑的那一版），随时能换回去。卡通版全部做在分支 style-b 上：地图、墙石、建筑、10 个英雄、2 种小兵、6 种野怪、特效、界面、海报和图标都换了，玩法和数值没动。旧动作全部直接套到了新模型上，一段动作视频都没重出。还没发布到线上，等你定。

现在的样子

刚截的（最终代码，1920×1080）：首页、选英雄、载入、对局。

要你定的

发布到线上吗

发布就是把 moba.dsxzai.com 换成卡通版（一条命令）。拿到地址的人下次打开就是卡通版。厚涂版在标签 v9-painted 里，想换回去再发一次就行。进一局要下载的资源比厚涂版小：电脑档 44.6 → 25.4 MB，手机档 35.6 → 22.8 MB。

建议先在本机试一局（http://localhost:5183/），觉得可以就发。

两版要不要都挂在线上

做视频时如果想让观众对比两种画风，可以把厚涂版另挂在一个子域名上（比如 moba-v9.dsxzai.com），卡通版用主域名。这要在你的 Cloudflare 上多建一个站和一条解析记录。

建议需要对比素材再挂，不需要就只发卡通版。

宣传片要不要按卡通版重剪

现在的宣传片是厚涂版的画面。按原来的分镜重录重剪，一个 Opus 任务约 2 小时，不花积分。

卡通版能不能过

你说过以后，我把 style-b 合进 main。合之前厚涂版一直在 v9-painted 里。

花了多少

评估时给第 2 档报的是 Tripo 1300–1600、即梦 2200–4000、并行 3–4 天。实际都比报价少，主要因为旧动作全部套上了，没有重出动作视频，Tripo 的模型也都是一次过、没有重出。

地图

现在和设计稿 B 最大的差距原来是亮度（我方草地 B 是 129,184,87，厚涂版只有 75,102,42），不是饱和度。光照改成分阶光、影子硬而有颜色，地面九个区参照 B 的设计稿重画，墙、石头、台阶、城墙改成圆润干净的整条厚板。墙和石头的位置、挡路范围逐项核对过一点没变，寻路、卡兵、两边对称都不受影响。

建筑

两个阵营的塔（外塔、内塔、高地塔）、水晶、出生点先出 B 设计稿，再交给 Codex 重建，材质照 B 的色板。高度和占地照游戏里原来的，所以塔比设计稿瘦高。被拆、爆炸、挡视线时变透明都照常。

角色

先拿岚和葛隆出了两个路子请你选（你选了卡通厚涂），再给其余 16 个角色出设定图。每个角色：设定图 → Tripo 出模型和绑骨 → 用新写的工具把旧动作套上去（脚自动踩地）→ 进游戏。所有动作的出手时间点和旧版一帧不差，没有一段动作要重做。四足（卡兹、托尔格、奥森和四种野怪）的骨架每只都要先认骨头、修错绑，步骤写成了文档。

特效、界面、海报

特效原来是按暗青绿地面调的，白色和浅青的在亮地面上看不清、焦黑的痕迹像污渍：改成核心亮而有色、边缘同色系深一档、地上痕迹用暖褐。界面从“黑铁加旧铜”换成“深海蓝玻璃加亮金”，布局和操作不动。海报、头像、技能和装备图标按卡通厚涂重出（125 张）。

回归、帧率、还不够好的

检查结果
类型检查、打包都过。上线资源 74.4 → 50.6 MB（电脑档 44.6 → 25.4，手机档 35.6 → 22.8）
鼠标键盘（右键移动、拖着走、技能瞄准取消、钩引、商店、回城、小地图等）和厚涂版一致，无报错。中途有几次钩引没钩中，在机器空闲时复查两遍都钩中，是六个任务同时跑、负载太高造成的
触屏（摇杆、攻击键、技能点按和拖动瞄准、取消、商店、计分板、竖屏暂停等）全过，无报错
全电脑五对五，新老英雄混搭两局 17:58、20:23 分出胜负，无报错
十人团战帧率（正常速度、不锁帧，厚涂版和卡通版轮流量）电脑档 22 对 23，手机档 29 对 35，卡通版持平或略快（当时机器上别的程序占着显卡，绝对数都低，看相对）

我看下来还不够好的

  • 几个英雄在亮草地上不比地面亮（葛隆、乌戈、狼），靠深色轮廓和朝光一侧的亮边才认出来。
  • 卡兹毛色偏冷蓝灰，设定图是暖紫炭灰；卡兹跑步后脚有点滑。
  • 薇萝的红偏玫红，抬弩时弩臂会穿过头胸；塞伦的骨白枪托偏粗。
  • 卡兹的眼缝、奥森的烛火、薇萝的火油罐不发光（游戏只认青色发光，旧版也一样）。
  • 塔比设计稿瘦高，青铜框架偏细；出生点的石像偏小。
  • 特效多数是颜色更饱和、白光少了，幅度中等；摩珂 W 还是透明泡，奥森 E 在亮地面上是一块偏重的深色。
  • 48 像素下有几组图标比较像（托尔格 Q 和 W 都是钟、两把弩、三双靴子）；几张海报景别不统一。

没验证的

  • 真手机上的样子和帧率（只在电脑的 Chrome 里按手机参数跑过）。
  • 每个角色的蒙皮只在拼图和测试场里看过，没有在 Blender 里逐根看权重。

顺带的事

  • 磁盘满过两次，大头是 Adobe 的媒体缓存（20 GB，你剪视频生成的，我没动）；我清过 4.7 GB 残留的临时文件。
  • 关掉了两个早先测试留下没退出的无界面 Chrome。
