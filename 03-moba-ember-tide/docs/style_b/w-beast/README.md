# w-beast：四种四足野怪换成路子一（卡通厚涂）

2026-11-20，分支 `w-beast`。苔背狼、炽鬃野猪、石背巨蟾、岩甲巨兽四只都走通了：Tripo 照 `b-sheets` 的设定图出模型、四足绑骨 → 写映射、摆正 → 用 `tools/retarget` 把旧动作套到新骨架 → 出品进游戏。四只都没有重出模型，没有一段动作要在 Blender 里手调；有三处靠自己写的后处理脚本修（见“四足的做法”）。

## 四足的做法（第二批 `w-quad` 和以后换四足可以照这个）

1. Tripo 出模型（`face_limit` 狼 25000、野猪和巨蟾 30000、巨兽 40000，`detailed`），`--rig-type quadruped` 绑骨。
2. `dump_rig.py` 读 Tripo 的 rigged.glb，`art/style_b/beasts/draw_rig.py` 打印每根骨骼的父、位置、方向、管多少顶点，对着旧模型的映射（`V2R/assets/model/<怪>_rigmap.json` 的 `_说明`）按骨骼角色认一遍。四只的新旧骨骼名都对不上（Tripo 每次不一样：狼的右前腿错开一位，野猪的右肩胛叫 Spine_3、右上臂叫 Spine_4，巨蟾旧的把头尾认反了新的没有，巨兽前腿没有肩胛、后半身是 bone_13..15）。
3. 写 `art/style_b/<怪>/rigspec.json`（每根受控骨骼的角色和左右、脖子尾巴的链、四只脚的末端、面朝哪边），`art/style_b/beasts/make_rigmap.py` 生成 `V2R/assets/model/<怪>_b_rigmap.json`（活动范围照抄旧的；跟踪点只是骨骼头和脚尖，不训练），`prep_rig.py … <怪>_b` 摆正出 `<怪>_b.blend`（creature_build.sh 只认这个）。巨兽的 Tripo 模型是斜着放的，`forward` 用髋中点到肩中点量出来的 (0.47,-0.88)。
4. `dump_rig.py` 读两个 .blend，写 `retarget/case.json`：`kind: quadruped`、`mode: delta`（新旧都是自然站姿，静止姿势很接近，不用 `ref_pose`）、`map` 按角色一根根写、`legs` 四条腿（上段、下段、末端；`src_end` 是旧模型对应的末端）、`ground_chains` 头（巨兽再加尾根、尾巴）。`k`（根位移的缩放）：狼用默认（根骨骼高度之比 1.05），野猪 1.07、巨蟾 1.0 按腿长之比手写；巨兽腿只有旧的六七成长，用 0.6（按腿长之比 0.74 时趴下、压低前身插进地里更深）。
5. `run_case.py` 套、量、出拼图；两处后处理（`art/style_b/beasts/`，原件存在 `motions/ik_unblended/`、`ik_unlifted/`）：
   - `blend_air.py`：巨蟾的重击是整只跳起来再砸下，空中那几帧脚 IK 照源的离地高度放脚，把右后腿拧到背上方（高出背 0.11 个身高，4 帧）；腾空的帧（源里脚离地超过 0.2 个身高）腿换回“只搬旋转”的结果，按脚离地多高平滑插值。
   - `lift_body.py`：retarget.py 只管脚、手、头尾链，不管躯干。巨兽腿短，压低前身（重击的蓄力）和趴下（死亡）时胸口、前臂插进地里 7%（约 27 厘米）；野猪死亡比源多插 4%。那几帧把根骨骼抬上来、腿的两段 IK 把脚放回原处。源自己插进地里的深度（按 k 缩放）不管。
6. 出品 `zsh art/style_b/beasts/rebuild.sh <怪>`：`run_case.py build` 写 build.json → `creature_build.sh` → `mob_b.mjs` 把材质 `hero` 改名 `mob_b`（creature_build.py 没有 `body_material` 选项，共用脚本不改，出品后改名）→ `strip_maps.mjs` → 时间表（旧的 runSpeed × 新旧“该填”之比，再盖 `timing_patch.json`）→ `lite_glb.mjs` 手机档。
   - **`run_case.py build` 写的 runSpeed 在两边身高不同时多乘了一遍 `game_h/src_game_h`**（measure.json 里两边的米已经各按自己的身高换算过了）；狼 1.55/1.45 时 6.53 被算成 6.98。rebuild.sh 自己算，没用它那份。
7. 顺序：retarget →（blend_air）→（lift_body）→ measure → render → build。重跑 retarget 会覆盖 ik 里的动作，后处理要重跑。

## 量出来的数

套动作（`<怪>/retarget/table.md` 的“源 / 加脚 IK”两行，摘要）：四只所有动作出手时刻差 0 帧；踩地时陷地 / 飘都修到几厘米以内（源 1–19 厘米）。巨兽身子最低：重击 1.9 厘米、死亡 0.4 厘米（后处理前 −27、−15 厘米）。

| | 身高（游戏里） | runSpeed（旧 → 新） | 动作 |
|---|---|---|---|
| 狼 | 1.45 → 1.55（背上苔藓蕨叶高了，身长不变） | 6.33 → 6.53 | idle run attack1 death |
| 野猪 | 2.7 → 2.83 | 4.4 → 4.62 | 加 attack2 |
| 巨蟾 | 2.3 → 2.39 | 3.56 → 3.68 | 加 attack2 |
| 巨兽 | 4.1 → 3.9（身长 8.85 → 9.6 米） | 2.2 → 1.6（完全不滑要 1.15，碎步；取 1.6，脚滑约 0.7 米/秒，旧的 0.58） | 加 attack2、roar |

着色（`src/map/game/view.ts`）：材质名 `_b` 的野怪不吃旧的 `MOB_LOOK`，新加 `MOB_LOOK_B`（狼 lift 1.12 sat 1.33 rim 0.42；野猪 sat 1.4；巨蟾 lift 0.82 sat 1.0 rim 0.42；巨兽 lift 0.85 sat 1.45 glow 0.35 rim 0.5）。理由见代码注释和汇报。

显不显眼（`pop.md`，游戏镜头 27 米、营地固定机位，同一帧拍有怪 / 没怪相减；亮度 0–1）：

| | 旧版 p10 / p50 / p90（跨度） | 卡通版 p10 / p50 / p90（跨度） | 地面亮度（跨度） |
|---|---|---|---|
| 狼（草地） | 0.29 / 0.41 / 0.58（0.29） | 0.35 / 0.49 / 0.72（0.38） | 0.71（0.28，旁边有白石墙） |
| 野猪（红土） | 0.25 / 0.36 / 0.47（0.22） | 0.31 / 0.36 / 0.60（0.29） | 0.50（0.05） |
| 巨蟾（草地） | 0.29 / 0.46 / 0.67（0.38） | 0.34 / 0.47 / 0.87（0.53） | 0.72（0.06） |
| 巨兽（河心岛） | 0.28 / 0.39 / 0.53（0.25） | 0.29 / 0.54 / 0.83（0.54） | 0.74（0.20） |

四只的亮部（p90）都比旧版高 0.13–0.30，跨度大一档；野猪的 p90（0.60）比红土（0.50）亮，巨蟾、巨兽的 p90 比草地、岛上的浅石亮；狼的 p90（0.72）和草地差不多，靠棕色的头、腿和绿背的明暗认出来。
