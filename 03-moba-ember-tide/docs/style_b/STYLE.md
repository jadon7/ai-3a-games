# 画风 B「明快卡通」的规矩

`b-concept` 任务写的（2026-11-20）。换画风 B 的所有任务做东西之前先对一遍这一份。
- 环境部分：从 B 的两张设计稿 `art/concepts22/env_me_b.png`、`env_foe_b.png` 量出来，加上评估报告 `docs/round9/stylecost/REPORT.md` 的数。
- 角色部分：B 原来没有角色。这里给两个路子，图在 `art/style_b/concept/`，对比总表在 `docs/style_b/b-concept/compare.jpg`。**用户选定路子以前，第二批不出角色模型。**
- 色值是在设计稿原图上取的 7×7 或 13×13 像素中位数；“亮度”是相对亮度（0 黑、1 白），“饱和度”是 HSL 的 S。

---

## 一、总原则（环境和角色都守）

1. **明快靠亮，不靠饱和。** B 和现在的游戏最大的差别是亮度：我方整屏平均亮度 B 0.66、现在 0.37；B 的饱和度反而更低（0.43 对 0.60）。提亮的时候饱和度不跟着往上推，大面积的颜色饱和度保持在 0.3–0.55，只有重点色（阵营色、发光、英雄的点缀色）超过 0.6。
2. **形体圆、厚、整。** 大形先行：一段墙是一整条厚板，一座塔是几层叠起来的整块，一丛草是一簇。倒角圆，少分块、少镂空、少碎零件。细节只放在重点处。
3. **明暗分块。** 亮面一整块、暗面一整块，交界一小段软边；影子是成块的、有颜色的（我方偏冷的青绿，对方偏暗的紫红），不是黑的。影子的亮度约是同一表面亮面的 0.6–0.75 倍。不要缝里的黑色环境光遮蔽。
4. **贴图干净。** 手绘、低频：颜色变化靠大块的冷暖和明暗，不靠杂点、裂纹、划痕、磨损、锈迹。
5. **发光克制。** 一个画面只有重点处发光：塔顶的晶体、对方的余烬、英雄身上一两处。光晕小、边缘清楚，不往四周泼。
6. **描边。** 环境只在大形的外缘有一道很细的深色勾边（深褐、深灰绿，不是纯黑），设计稿里墙和塔就是这样；**不要黑色粗描边**。角色的描边看路子（第三节）。
7. **不要的东西**（照 B 原提示词）：破败的废墟感，骷髅、锁链、尖刺，满地杂物，到处发光，暗黑哥特风，黑色粗描边。

### 2.3 明暗关系

- 光从左上方来（两张设计稿都是），影子投向右下，清楚但边缘柔。
- 亮面和暗面的比例：大面（地面）几乎全是亮面，明暗变化只靠大块的草色深浅；立体的东西（墙、塔）亮面占六七成。
- 影子有颜色：我方的影子是青绿灰（墙影 `#477352`），对方是暗红紫（`#914630`）。不要灰黑的影子。
- 一张图里最亮的是石材的顶面（我方 0.92）和晶体，最暗的是墙的背光面（我方 0.39、对方 0.23）。地面在中间。

### 2.4 形状

- **墙**：一整条厚板。顶面是一块平整的大石板，倒角圆（半径约墙厚的五分之一）；段与段之间的缝少，三到五米一条；我方是浅灰白石加一条连续的铜绿青铜包边（顶面下沿和底座各一条），对方是几块大方石，四角圆，暗铁箍竖着包在端头和接缝。墙头可以有一点青苔或枯草，**不要堆碎石**。
- **石板路**：大块（0.8–1.5 米），圆角，缝里长草；路的边缘碎成几块散开的石板，融进草地或红土。
- **草地**：一整片亮绿，大块的深浅变化（几米一块），不要细碎的笔触；地表的短草只在边缘和墙脚多一点。
- **高草丛**：一簇簇宽叶，叶尖圆，比人高；比地面暗一档。
- **水**：青蓝透亮，石板路沉在水下连续地过去（用户在 2.2 定过：水要盖过路面）；粼光是少量白点。
- **树**（设计稿里没有）：照同样的规矩，圆润的叶团，颜色比草地暗一档、偏青。

### 2.5 细节的主次

| 级 | 是什么 | 怎么画 |
|---|---|---|
| 重点 | 塔冠和晶体、水晶、英雄 | 形状最精致，有发光，饱和度最高 |
| 次要 | 墙、塔身、石板路、草丛 | 形状干净，有包边、倒角这一级的细节，不发光 |
| 背景 | 草地、红土、水面 | 只有大块的颜色变化，没有零碎的东西 |

### 2.6 建筑（塔、水晶）

设计稿：`art/style_b/concept/tower-me.png`、`tower-foe.png`（一家三档：外塔、内塔、高地塔）、`core-me.png`、`core-foe-v2.png`（水晶加一座配套的小灯柱 / 火盆柱）。

- 保留现在的结构和身份（用户在 2.2 认可过的那座塔的层次）：底座、塔身、塔颈、塔冠分得清楚；我方是白石芯外包铜绿青铜肋片、缝里透出晶体的颜色、塔冠由青铜爪托着青色晶体；对方是玄武岩加暗铁箍、塔冠由暗铁爪箍着橙红余烬晶核。
- 换的是画法和体量：更粗壮、更圆润、少镂空；肋片、爪是几片整块的厚片；去掉细碎的雕花和磨损。
- 三档越往里越粗、层次越多（高地塔多一级台阶，塔冠更大）。
- 对方的塔现在偏瘦（PLAN 里记过“整套里最弱的”），B 里要比我方的更矮胖一点，塔冠放大。
- 发光只在晶体 / 余烬上；对方塔颈那圈悬浮的晶粒要小、要少，不要变成一圈光环。
- 第二批让 Codex 重建时，照设计稿的大形和层次做，材质按现在的六个名字（stone、metal、accent、crystal、glow、water）换成 B 的色板。

## 三、角色

### 3.1 两个路子都要守的

**身份四件不能变：轮廓（剪影特征）、武器、阵营色、主色。** 每个英雄先填一张身份表，出图和建模都对着它查。

| | 岚 · 汐刃（沉月会，刺客，身高 3.3 米） | 葛隆 · 砧卫（烬誓庭，坦克，身高 3.5 米） |
|---|---|---|
| 轮廓 | 兜帽后面竖起的鱼鳍头冠；精瘦；右肩一簇红珊瑚 | 平顶桶盔；**右肩**（握锤的一侧）一块铁砧形大肩甲，砧角平伸出去；宽、厚、像一堵墙 |
| 武器 | 双手各一把骨白色新月形弯钩刃，刃口一道青色细光纹，柄缠深蓝布条 | 右手方头锻锤（短粗柄、锤头一格火光栅）；左前臂一面上圆下方的炉门形塔盾，正中圆形炉栅透火光 |
| 阵营色 | 青色（身侧和手臂的发光纹路、眼睛） | 琥珀橙（面罩 T 形缝、胸口炉栅、盾栅） |
| 主色 | 深海蓝紧身甲 + 骨白护甲，点缀珊瑚红 | 炭黑铁甲 + 黄铜铆钉，褐色皮围裙、暗红内衬 |
| 发光处 | 青色纹路、眼睛 | 面罩缝、胸口炉栅、盾栅（锤头小栅可有可无） |

**在亮地面上要显眼。** 旧规矩是“地面中间调，英雄比地面亮一档”；换到 B 以后地面很亮（我方 0.66），英雄不可能整体比它亮，改成下面几条：
1. **明暗跨度大于地面，而且要有一圈比地面亮的东西**：英雄的亮部（骨白、金属高光、脸、发光、轮廓亮边）要比所在的地面亮（我方 > 0.8、对方 > 0.6）；暗部可以比地面暗。英雄自身最亮和最暗之差（亮度的 p90 − p10），至少是脚下地面的三倍。地面要“平”，英雄要“跳”。
   - 粗量的结果（量法见 `docs/style_b/b-concept/README.md`）：路子一的岚在绿地上，地面 0.65、英雄 p10 0.22 / p90 0.85，跨度 0.63（地面只有 0.10），合格；路子一的葛隆在红土上，地面 0.44、英雄 p90 只有 0.43——**亮部没有比地面亮**，他是靠“一整块深色剪影 + 冷暖相反”被认出来的，在图上认得出，但进游戏要靠轮廓亮边补上那一圈亮。深色主色的英雄（葛隆、托尔格、卡兹这类）都要注意这一条。
2. **主色和地面拉开色相**：我方地面是黄绿（85–105°），英雄的大块主色避开黄绿；对方地面是橙红（12–19°），英雄的大块主色避开橙红。岚的深海蓝在绿地上、葛隆的蓝灰铁在红土上，都是对比色，成立。以后哪个英雄的主色和地面同色相，要在他身上加一圈亮边或换主色的明度。
3. **重点色饱和度高于地面**：阵营色和发光的饱和度 > 0.8，地面不超过 0.55。
4. **暗色主色要提亮，但不能变色**：岚的深海蓝提成海军蓝（不近黑），葛隆的炭黑提成深蓝灰 / 深炭灰。**主色不能提成另一种颜色**（葛隆变成银白骑士就丢了身份）。
5. **游戏里加两样东西**：轮廓亮边（顺光一侧一道窄的亮边）和脚下的圆形投影 / 阵营色圈。路子二再加描边。
6. **英雄比小兵显眼一档**：小兵更矮（只到英雄的腰到胸）、更概括、颜色更灰、没有发光；英雄的饱和度和明暗对比都比小兵高一档。

**27 米的游戏镜头下要一眼认得出**：剪影特征要够大（岚的鱼鳍头冠高出头顶约半个头；葛隆的砧肩伸出肩外约一个头宽）；武器长度不少于身高的三分之一；细碎的小件（渔网、骨钩、小瓶、铆钉）在游戏镜头下只是一点颜色，可以概括但不要变多。

**建模用设定图**（拿去 Tripo，照 `tools/HERO_PIPELINE.md` 和 `docs/round9/heroes/DESIGN.md` 的做法）：正面全身、A 字站姿（双臂斜下约 45 度、手掌朝下）、双手空着、两腿分开与肩同宽、四肢不互相挡、没有披风和拖地长袍；纯中性灰底、没有地面和投影、光线均匀；单个角色居中、四周留白。武器单独出图（拿人物图当参考出武器图会把人也画进去，武器要直接文生图）。背后形状复杂的（赫达的熔炉、托尔格的龟壳）另出侧面或背面。

### 3.2 路子一：王者式卡通厚涂

图：`lan-p1-sheet.png`、`lan-p1-game.png`、`gorran-p1-sheet.png`、`gorran-p1-game-v2.png`。

- **比例**：约六头身，坦克五头身；头和手略大，但不是 Q 版、不是大头娃娃。
- **体积**：大块面的明暗，明暗交界是软的，高光干净利落（金属、骨甲上一道清楚的亮带）。体积感是画出来的（手绘贴图里带光影）。
- **颜色**：比现在亮一档，饱和度中偏高；暗色主色提亮到不近黑（见 3.1 第 4 条）。
- **细节**：写实的磨损、划痕、鳞片纹理、锈迹都去掉；碎零件合并成几块整的形状；每个部件是一块清楚的颜色。
- **描边**：不要。游戏里靠轮廓亮边和投影把英雄从地面上提出来。
- **和环境**：同一种画法（都是卡通厚涂），最协调，和 B 的设计稿就是一家。
- **游戏里怎么做**：贴图本身带手绘的明暗（王者那样），着色器用分阶光但阶数弱（亮暗交界软一点），加轮廓亮边。和现在的管线一样：设定图 → Tripo 出带贴图的模型。

### 3.3 路子二：日式赛璐璐

图：`lan-p2-sheet-v4.png`（v1–v3 留着对比，见 `b-concept/README.md`）、`lan-p2-game-v2.png`、`gorran-p2-sheet-v2.png`、`gorran-p2-game.png`。

- **比例**：约七头身、腿长；坦克照样敦实，不要拉长。
- **线**：干净的细描线，深蓝灰或深褐（不是纯黑），粗细基本一致，只勾外轮廓和主要的结构线。
- **明暗**：平涂底色加一阶硬边阴影（阴影是一块边缘清楚的形状，没有渐变、没有笔触）；高光是边缘清楚的小白块。
- **颜色**：比路子一更通透、更亮；阴影带一点紫（蓝的阴影偏紫，白的阴影是淡紫灰）。
- **脸**：动漫脸（大眼睛、尖下巴、鼻子一笔带过）。戴全盔的英雄（葛隆）看不到脸，靠线和平涂区分。
- **和环境**：角色是赛璐璐、环境是卡通厚涂，两种画法放在一起（很多二次元游戏都是这样）。描边只给角色，角色会更“跳”，好认；但英雄和环境不是一家人，比路子一更不协调。
- **游戏里怎么做**：
  - 贴图只要平涂的底色，**不要把阴影和线烘进贴图**；两阶光由着色器做（评估试验里的分阶光，交界改成硬边），描边用背面外扩或后期描边（评估试验里的 `toonp=outline:0.006`，每个角色多画一遍）。
  - **Tripo 的问题**：Tripo 照设定图出贴图，会把图上的描线和硬边阴影一起烘进去，转到侧面、背面时线和阴影就对不上了。所以路子二拿去 Tripo 的设定图，要另出一张“只有平涂底色、不画线、不画阴影”的版本（每个英雄多一张，约 13–25 积分），或者模型出来以后把贴图重新压成平涂。这一条没有试过。
  - 每个角色多一遍描边的绘制，手机档要量帧率。

### 3.4 两个路子怎么选（我的看法，用户定）

| | 路子一 王者式卡通厚涂 | 路子二 日式赛璐璐 |
|---|---|---|
| 和 B 环境 | 同一种画法，最搭 | 两种画法混在一起，角色更跳 |
| 在亮地面上好不好认 | 好：靠明暗跨度、主色对比和亮边 | 更好：多一圈描边 |
| 和用户记得的“动漫感” | 偏欧美 / 王者的卡通，动漫感一般 | 动漫感强 |
| 管线 | 和现在一样：设定图 → Tripo，贴图带明暗 | 要多一步：平涂底色版设定图，或者重压贴图；着色器要描边 |
| 风险 | 低 | Tripo 烘线烘阴影（没试过）；描边的帧率；十八个角色的线要统一 |

## 四、给第二批的检查清单

出角色设定图时：
- [ ] 身份表的四件逐条对过（轮廓、武器、阵营色、主色），左右没有画反（葛隆的砧肩和锤在同一侧）。
- [ ] 主色提亮了但没变色。
- [ ] 建模图：A 字、空手、纯灰底、无投影、居中留白、四肢不挡。
- [ ] 缩到游戏里约 150 像素高时，剪影特征还认得出。

出环境和建筑时：
- [ ] 平均亮度、草地 / 红土的颜色和 2.2 节的表差不多（用评估的量法量）。
- [ ] 影子有颜色，不黑；没有缝里的黑色 AO。
- [ ] 一个画面只有重点处发光。
- [ ] 没有碎石、锁链、尖刺、满地杂物；没有黑色粗描边。
