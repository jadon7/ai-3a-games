## 葛隆的备选

`b-concept` 说葛隆的亮部没比红土亮。两张备选：

- `gorran-p1-sheet-bright.png`：模型照原图“只改颜色”出的，设计和姿势完全不变，铁甲提成钢蓝灰、倒角高光更清楚。亮度 p50 0.25 → 0.31，p90 0.43 → 0.56（红土 0.50）。**推荐这张。**
- `gorran-p1-sheet-apose-bright.png`：原图的手是半握拳、胳膊贴着身体，Tripo 可能把胳膊和身子粘在一起。我想顺便改成标准 A 字，试了三次都没改成（N-2.1 一次、N-Pro 一次、拿岚当姿势参考图一次）；最后一次（双参考图）至少把手张开了、胳膊离身子远一点，但亮度没变，我在本地只对角色提了中间调（gamma 0.78），p50 0.34、p90 0.52，对比度比上一张平一点。**这张是本地调过色的，不是模型直接出的。**

## 怎么出的

- 全部走排队脚本 `tools/jimeng_lock.sh` → `tools/jimeng_gen.py`，任务单在这个目录的 `jobs_1.json`（17 张）、`jobs_2.json`（8 张重出）、`jobs_3.json`（2 张）。出图记录追加在 `concepts/_raw/log.jsonl`，名字都以 `sbs-` 开头；以后要拿这些图当参考图（i2i），直接写这些名字。
- 模型：N-2.1（`jm_image_model_gg_bp_21`，13 积分），只有葛隆的一次姿势试验用了 N-Pro（25）。
- 参考图（都是画布上已有的节点，即现在游戏模型照着做的那张）：摩珂 `h5-moko-sheet-c`，薇萝 `h2-vero-sheet-a`，赫达 `h8-hedda-sheet-b`，乌戈 `h9-ugo-sheet-b`，塞伦 `h10-seren-sheet-b`，钟龟 `h6-torg-turtle-a`，烛角鹿 `h3-osen-stag-a`，卡兹 `h7-kaz-sheet-b`，近战兵 `unit-melee`（两个兵并排的那张，提示词里写“只照右边那个”），远程兵 `unit_ranged_apose_v1`，狼 `m3-wolf-a`，野猪 `m2-boar-a`，巨蟾 `m1-toad-a`，山魈 `m4-mandrill-a`。
- **岩石巨魔和岩甲巨兽是文生图**：它们现在的参考图在 `video2rig/assets/ref/`，不在画布上；排队脚本只跑 `jimeng_gen.py`（只认画布上的节点），上传本地图要走 `jimeng_i2i.py`，那就绕开了排队锁，所以没用。提示词照 `art/unit/troll/brief.json`、`beast/brief.json` 的外形和那两张参考图写的。
- 提示词的结构照 b-concept：身份逐条写清 → “配色保持” → 路子一画风那一段 → “颜色比参考图明亮一档”（每个角色写清哪块提成什么颜色、哪里最亮）→ “要在黄绿草地和橙红土地上都一眼认得出” → 画面规格。重出的几张大多是拿第一稿当参考图“只改颜色”（N-2.1 这种局部改很听），薇萝第三稿是从原图重画的。
- 山魈那张脚本下载时数据流断了（和 b-concept 遇到的一样），积分已扣，按画布上的素材号手动下载回来，并在 `concepts/_raw/log.jsonl` 补记了一条（带 `note`）。

## 量数：亮了多少、在地面上显不显眼

量法：把灰底抠掉（从四边漫水），角色像素算 sRGB 编码的相对亮度（0 黑、1 白），取 p10、p50、p90；饱和度是 HSL 的 S 的 p90。地面是 `readability.jpg` 用的三块游戏截图：草地 p50 **0.76**（游戏里的草比 B 设计稿的 0.66 还亮）、水晶广场石板 0.78、红土 **0.50**。这是设定图本身的数，进游戏还要乘上光照和 `tune()` 的提亮，只看相对变化。

| 角色 | 现在 p50 / p90 | 卡通版 p50 / p90 | 卡通版跨度 p90−p10 | 卡通版饱和度 p90 |
|---|---|---|---|---|
| 摩珂 | 0.37 / 0.64 | 0.58 / 0.81 | 0.48 | 0.56 |
| 薇萝 | 0.15 / 0.39 | 0.24 / 0.49 | 0.35 | 0.68 |
| 赫达 | 0.17 / 0.42 | 0.23 / 0.62 | 0.48 | 0.44 |
| 乌戈 | 0.23 / 0.47 | 0.38 / 0.68 | 0.51 | 0.29 |
| 塞伦 | 0.30 / 0.66 | 0.41 / 0.78 | 0.59 | 0.50 |
| 葛隆（提亮备选） | 0.25 / 0.43 | 0.31 / 0.56 | 0.41 | 0.32 |
| 托尔格 | 0.22 / 0.48 | 0.38 / 0.63 | 0.42 | 0.43 |
| 奥森 | 0.34 / 0.59 | 0.42 / 0.76 | 0.59 | 0.41 |
| 卡兹 | 0.20 / 0.36 | 0.29 / 0.56 | 0.40 | 0.25 |
| 近战兵 | 0.24 / 0.49 | 0.38 / 0.68 | 0.55 | 0.40 |
| 远程兵 | 0.22 / 0.49 | 0.38 / 0.64 | 0.44 | 0.38 |
| 狼 | 0.28 / 0.47 | 0.44 / 0.71 | 0.46 | 0.27 |
| 野猪 | 0.18 / 0.46 | 0.31 / 0.51 | 0.36 | 0.70 |
| 巨蟾 | 0.33 / 0.48 | 0.51 / 0.72 | 0.43 | 0.33 |
| 山魈 | 0.21 / 0.47 | 0.30 / 0.64 | 0.48 | 0.37 |
| 岩石巨魔 | 0.42 / 0.63 | 0.58 / 0.79 | 0.47 | 0.37 |
| 岩甲巨兽 | 0.32 / 0.49 | 0.47 / 0.78 | 0.51 | 0.74 |

读法：
- 16 个全部比现在亮：p50 提高 0.06–0.21，p90 提高 0.10–0.29。提得最少的是薇萝（p50 +0.09）、卡兹（+0.09）、葛隆备选（+0.06），都是主色本来就深的。
- 跨度都在 0.35 以上，是地面（草地 0.05、红土 0.03）的七倍以上，满足 STYLE 3.1 第 1 条“英雄自身明暗跨度至少是地面的三倍”。
- “亮部比地面亮”（我方 > 0.8、对方 > 0.6）：在游戏里这么亮的草地（0.76）上，设定图只有摩珂的 p90 超过 0.8，**所以 STYLE 里说的轮廓亮边进游戏时还是必须加**。对方红土上，赫达、乌戈、塞伦、托尔格、奥森、摩珂的 p90 都过了 0.6；**薇萝（0.49）、葛隆备选（0.56）、卡兹（0.56）没过**，在红土上是“比地面暗的一块剪影”被认出来的（和 b-concept 说的葛隆一样），靠游戏里的亮边补。
- `readability.jpg` 里看：草地上所有角色都清楚；水晶广场的浅石板上，浅色的几个（狼、奥森的白身子、两个小兵）和地面最接近，但都有深色的部位勾出轮廓；红土上薇萝和山魈的暖色和地面最近，靠明暗拉开。

## 自己觉得还不够好的

1. **托尔格的龟甲改了颜色**：原来是深橄榄灰褐，我为了在亮绿地上拉开，要了“暖沙褐”，它画成了很亮的黄褐色。主色（铜绿的钟和头盔）没变，但整只龟的第一印象变了不少，这是这批里改动最大的一处，用户可能不认。背上的“钟”也还是像一只桶（原设计就是钟口朝上，从侧面看像桶）。
2. **薇萝整体还是偏暗**，在红土上亮部不如地面；脸也比别人写实一点。左肩的短披肩只搭在一侧（原图也是这样）。
3. **近战小兵变成了一个普通的银甲骑士**：为了中性配色，原来的铜绿锈甲、珊瑚、贝壳全去掉了，“海的味道”没了；银甲亮，个头虽小但亮度不比英雄低（游戏里小兵的 `lift` 比英雄低，可以压）。远程兵也一样去掉了发光的纹路。
4. **岩石巨魔、岩甲巨兽是文生图**，和现在的模型只是“同一个东西”，不是照着改的：巨魔的皮肤偏淡紫灰、轮廓线比别的几张粗一点；巨兽的身子更像一只甲壳龟，原来的更像蜥蜴，晶体的发光也比 STYLE 说的“克制”多一点。
5. **葛隆的 A 字没改成**（试了三次），手和胳膊还是贴着身体，Tripo 可能把胳膊和身子粘一起；张开手那张是本地调的色。
6. **卡兹身上的条纹比原来明显**，有点像老虎。
7. **四足用的是侧前方四分之三视角**（照现在 Tripo 用过的四足设定图），不是纯侧面；纯侧面会让远侧的腿被挡住。
8. Tripo 可能难读的地方：乌戈细长带蹼的手指（会粘成一片，DESIGN 里早就说过）；奥森的细腿和鹿角上十几根小蜡烛；赫达背后的熔炉（所以补了背面图）；狼背上的蕨叶。
9. 赫达的烟囱：brief 写“炉子右上方”，原设定图（`h8-hedda-sheet-b`，游戏模型照它做的）里烟囱在**画面右侧**（她自己的左肩后面），我的提示词写成了“画面左侧”，模型照参考图画对了；背面图里烟囱在她的左边、炉门在她的右腰，和正面一致。
10. 摩珂的手是掌心朝上摊开（照原图），不是 A 字要求的掌心朝下。
11. 都没有进 Tripo 试过，“结构清楚”是我看图判断的。
