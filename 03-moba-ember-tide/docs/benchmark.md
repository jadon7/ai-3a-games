# Dota 2 对标清单

用法：后面每个阶段改完画面，把我们的截图和这里引用的参考图并排放，逐条打勾。打不了勾的写清差在哪。
参考图在 `refs/dota2/`，来源链接在 `refs/dota2/sources.md`。下面用短名引用，例如 T1 = `terrain/terrain-01-…jpg`。

只对标水准，不照搬内容：这里列的是“质感从哪来”，不是要复刻 Dota 2 的地图、英雄或界面布局。

## 一、地形

| 编号 | 可检查的特征 | 参考图 | 怎么验 |
|---|---|---|---|
| A1 | 地表是手绘贴图的多层混合：草、泥、石板之间是不规则的笔触边缘，不是直线接缝，也不是均匀噪声 | T1 T7 | 截一块 3 种材质交界的地面，放大看边缘有没有笔触形状 |
| A2 | 路面比两侧草地亮一档、饱和度低一档，不看小地图也能分清哪里是路 | T1 H6 | 截图转灰度，路和草仍然分得开 |
| A3 | 高低地用石砌台阶或石崖表示，坡道两端有地标（火盆、石栏），高地边缘有一圈暗边 | T1 T4 | 俯视下不靠阴影也能看出哪边高 |
| A4 | 树是成团的树冠，不是一棵棵独立的树；一片林子里至少 3 种色相（深绿、橙褐、浅色）；画面边缘的树冠压暗，起到画框作用 | T1 H2 | 数色相；看画面四角是否比中心暗 |
| A5 | 河水是浅的半透明青色，能看到河底的石头，水面有睡莲、枯枝这类漂浮物，岸边有一圈湿的深色过渡 | T3 H1 | 河里能否看到河底；岸线是不是硬边 |
| A6 | 两个阵营的地表在色相、明度、材质上三样都不同（一边是黄绿草加米白石，一边是灰蓝龟裂石加红色点缀），交界处是渐变混合带而不是一条线 | T7 T4 | 把两边各截一块并排，三样逐项对比 |
| A7 | 暗色一侧不是“全黑”：地表保持中等明度的灰蓝，暗的是树和建筑的剪影，亮的是裂缝和窗里的内光 | T5 T6 | 取地表平均亮度，不应低于画面最亮处的 30% |
| A8 | 建筑有一个从远处就能认的轮廓，材质是整块的大色面加少量高对比细节（徽记、旗帜、发光口），塔下有石砌基座接地 | T2 T4 T5 | 把建筑缩到 64 像素高还能不能认出是哪个阵营的 |
| A9 | 地面散布小的叙事物件：碎骨、蘑菇、小花、断枝、涂鸦贴花，密度大约每屏 10 到 20 处，不重复排列 | T6 T7 T1 | 数一屏里的小物件，检查有没有明显的重复图案 |
| A10 | 昼夜是两套光：白天暖而亮，夜间整体偏蓝、压暗，但火盆和发光物在夜里更显眼 | T4 H5 对比 T1 | 同一位置截白天和夜间各一张 |
| A11 | 阵营标识直接做在环境里：旗帜、地面徽记石板、塔的配色 | T2 T4 | 遮掉界面，只看场景能否判断站在哪一方的地盘 |

## 二、英雄

| 编号 | 可检查的特征 | 参考图 | 怎么验 |
|---|---|---|---|
| B1 | 游戏镜头下英雄约占屏幕高度的 6% 到 8%，这个尺寸下仍能靠剪影认出是谁 | H6 H2 | 把英雄截图涂成纯黑剪影，6 个英雄互相能分清 |
| B2 | 每个英雄有一个夸张的识别部件（超大武器、面具、肩甲、头饰），占剪影面积的四分之一以上 | H3 H1 | 说出每个英雄的识别部件，看它在俯视角下是否还在轮廓上 |
| B3 | 英雄整体比地表亮一档、饱和度高一档，夜间和暗色地表上也成立 | H1 H5 | 截图转灰度，英雄和脚下地面有明显明度差 |
| B4 | 每个英雄的颜色不超过 3 个主色块，大块面清楚（例如橙黄皮肤、红黑甲、白面具） | H3 | 把英雄贴图缩到 32 像素，还能数出 2 到 3 个色块 |
| B5 | 贴图是手绘的：明暗和材质质感画在贴图上，不依赖高光反射；金属的高光是画出来的色块 | H3 H4 | 关掉实时光照只看颜色贴图，形体仍然读得出 |
| B6 | 近景有冷暖对比的轮廓光：主光偏暖，背后一道冷色边缘光勾出外轮廓 | H4 H3 | 近景截图里，角色暗部一侧有没有一条亮边 |
| B7 | 发光部件（武器刃、眼睛、火焰）带辉光，亮度明显高于身体其他部分，是全身最亮的点 | H3 H4 | 找全身最亮的像素，应落在武器或识别部件上 |
| B8 | 队伍归属靠头顶信息表达：己方绿色血条、敌方红色血条，名字用队伍色，血条上有等级数字 | H1 H2 H6 | 遮掉模型只看头顶信息，能否分清敌我 |
| B9 | 选中的英雄脚下有白色细圈；小兵靠整体体色区分阵营 | H2 H5 | 看选中圈是否压在地面上、不遮脚 |
| B10 | 近景展示时英雄站在一个简单的圆台上，背景是低饱和的雾和体积光，不抢角色 | H3 H4 | 展示界面背景的饱和度低于角色 |

## 三、特效

| 编号 | 可检查的特征 | 参考图 | 怎么验 |
|---|---|---|---|
| C1 | 每个技能有一个主色，团战里不看图标也能靠颜色认出是谁放的（蓝紫结界、蓝白闪电、橙黄火墙） | V1 V2 V5 | 6 个英雄的大招主色两两不撞 |
| C2 | 范围技能的边界清楚：要么有一圈高亮的边（结界），要么有地面贴花画出范围（火墙的灼烧痕） | V1 V5 V4 | 截图上能用笔沿着特效边缘描出范围 |
| C3 | 特效分层：地面贴花、主体形状、粒子碎屑、辉光，至少 3 层 | V3 V5 | 逐层关闭，确认每层单独存在 |
| C4 | 命中点比过程亮：光束的终点、爆炸的中心是过曝的白，向外衰减成主色 | V2 | 命中帧的最亮处接近纯白，且面积小 |
| C5 | 大范围技能会压暗或改变它覆盖的地表，让技能从环境里分离出来 | V4 V1 | 技能范围内外的地表亮度有差别 |
| C6 | 特效不遮挡玩法信息：技能里面的英雄、血条、状态文字仍然看得见 | V1 V4 V5 | 特效最浓的一帧里，范围内英雄的血条可读 |
| C7 | 密度有高有低：有黑洞、火墙这种高密度的，也有冰雪领域这种稀疏的大范围环境型，不是所有技能都一样“满” | V6 对比 V4 V5 | 每个英雄的 4 个技能里至少有一个是低密度的 |
| C8 | 有实体感的技能用模型加半透明雾，不只是粒子（地刺是真的几何体） | V3 | 暂停时特效主体有体积、有受光 |
| C9 | 状态用头顶文字和图标双重表达（眩晕的旋涡加 STUNNED 字样），引导类技能有读条 | V1 V4 V6 H6 | 每种控制状态都有头顶标识 |
| C10 | 特效的饱和度和亮度高于场景和角色，是画面里最抢眼的一层，但持续时间短 | V5 V2 | 特效帧和无特效帧并排，视线先落在特效上 |

## 四、界面

| 编号 | 可检查的特征 | 参考图 | 怎么验 |
|---|---|---|---|
| D1 | 对局 HUD 集中在底部中间一条：头像、属性、技能、血条蓝条、物品从左到右排，左右两角留给小地图和商店入口，不遮战场中心 | U1 U5 | HUD 占屏幕高度不超过 20% |
| D2 | 面板是深色、低饱和、带细微材质的底（不是纯黑也不是毛玻璃），边缘有 1 像素的亮线或暗线做出厚度 | U1 U5 | 放大面板边缘看有没有描边层次 |
| D3 | 技能图标是手绘的小插画，方形，带快捷键和蓝耗；冷却用压暗加数字 | U1 | 每个技能图标缩到 48 像素还能认 |
| D4 | 血条绿色、蓝条蓝色，条上直接写数值和回复速度 | U1 U5 | 数值在条上居中可读 |
| D5 | 顶部中间是双方头像、比分和时钟；死亡的头像变灰并显示复活倒计时 | U1 U5 | 触发一次死亡看头像状态 |
| D6 | 字体只用一套：标题是大写细字重、字距拉开，数字用等宽 | U6 U3 U2 | 截 3 个界面比字体 |
| D7 | 颜色有固定语义：绿色是己方和增益，红色是敌方，金色是金钱，数值加成用绿色小字 | U3 U4 U5 | 全界面检查这四种颜色没有被挪作他用 |
| D8 | 悬浮提示框的结构：标题、价格或消耗、属性列表、一段斜体的背景描述，分段之间有细线 | U1 U5 | 悬停任意物品和技能，结构一致 |
| D9 | 选人界面：顶部双方栏位加倒计时，中间是分组的头像网格，已选的变灰，右侧是详情和锁定按钮 | U2 | 走一遍选人流程 |
| D10 | 结算：胜负大字用获胜方的队伍色，双方英雄用竖版卡片展示（3D 模型半身），下面是数据表，自己那行高亮 | U4 U3 | 打完一局看结算页 |
| D11 | 击杀信息在右侧纵向滚动，一行是“击杀者图标、武器图标、被杀者图标”；连杀有屏幕上方的大字播报 | U5 T5 T6 | 触发击杀和连杀 |
| D12 | 小地图在角上，底图是地形的简化色块，己方绿、敌方红的图标，建筑是方块 | U1 U5 | 小地图缩到 200 像素仍能看清兵线位置 |
| D13 | 菜单类界面的背景是压暗的游戏场景或深色渐变，内容区域留白多，一屏只有一个主按钮 | U6 U4 | 数主按钮数量 |

## 参考图本身的不足

- 这批图以 2019 年的版本为主（interfaceingame 和 Steam 商店截图），只有 H6、V4、V5、V6 是当前版本地图，而且是从官方技能演示视频里截的帧，不是原生截图。
- 没有 7.33 之后新地图的整图，也缺一张完好的暗色一侧防御塔近景。阶段 2 开始前值得补几张当前版本的实机截图，最好由用户自己在游戏里截。
- V1、V2、V3 用的是换肤地形，只用来看特效，不用来对标地表。
- T6 是死亡灰屏，只看结构不看颜色。T4、T7 上叠了界面面板。
- 没有 5v5 多技能叠加的团战画面，C6（特效不遮挡玩法信息）在这批图上只能看单个技能。
