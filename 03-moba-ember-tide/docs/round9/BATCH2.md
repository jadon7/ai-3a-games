## 第二批是什么

用户看完阶段 8 以后的意见里，这两条放到第二批做（原话在 `PLAN.md` 的“2026-11-20 用户看完阶段 8 后的 12 条意见”一节）：

- 第 7 条：“应该是 5v5，且角色应该允许自己选，不是每个阵营固定角色，应该有打野、辅助、上单、法师、射手”
- 第 6 条：“游戏商店道具太少，参考其他游戏，每个道具会有升级过程，有被动，且放到特定职业上效果更适合”

第一批已经合并进 `phase9`：界面换成“黑铁加旧铜”的设计（`uikit.ts`，选人、加载、计分板都按每队五人设计好了位置，商店已经有“分类 + 列表 + 合成路线 + 详情”的结构，读装备数据里的合成字段）；前摇缩短、右键操作、塔射程、卡兵；迷雾、回城、结束演出。现在同时在跑的：三个特效任务在重做六个英雄的技能特效（只改 `heroes/<id>.ts` 的特效部分和它们自己的 `fx_*.ts`）；四个新英雄的模型和动作在做（`kaz`、`hedda`、`ugo` 已经有模型，`seren` 还在做）。

## 两个任务的文件怎么分（为了合并时少冲突）

| 文件 | `match5` | `items` |
|---|---|---|
| `sim.ts` | 归你（队伍、出生、名册、位置） | 只加“装备被动”要的几个挂钩调用（打中时、受伤时、每秒、击杀时），每处一两行，汇报里逐条列 |
| `bot.ts` | 归你（五个位置的打法、打野路线、选英雄） | 只改每个英雄的出装清单（`BOOK` 里的 `build`）和“买什么”的那一小段 |
| `items.ts` | 不碰 | 归你 |
| `hud.ts` | 顶栏、计分板、小地图上的英雄、击杀播报这些和“每队几个人”有关的 | 只改商店那一段（列表、合成路线、详情、推荐），以及装备格的说明浮层 |
| `lobby.ts` | 归你（选人、加载、结算） | 不碰 |
| `heroes/index.ts` | 归你（名册、位置、能不能选） | 不碰 |
| `main.ts` | 只改对局开始时生成英雄和电脑的那一段 | 不碰 |
| `heroes/<id>.ts`（六个旧的） | **不碰**（特效任务在改） | **不碰** |
| 新文件 | 随便建 | 随便建（比如被动的实现放 `items_fx.ts`） |

两边都要改 `sim.ts`、`bot.ts`、`hud.ts`：照上表只动自己那一块，别顺手重排别人的代码。
