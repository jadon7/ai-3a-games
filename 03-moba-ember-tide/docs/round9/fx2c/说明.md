# 第九轮 · fx2c 的证据（葛隆、薇萝）

| 文件 | 是什么 |
|---|---|
| `参照.md` | 每个技能参照了 LoL / Dota 2 的哪个技能、学它什么；后半是每个技能的分镜（起手 → 出手 → 途中 → 命中 → 余韵） |
| `对比_<技能>.jpg` | 连续帧对比：上一行改前、下一行改后，同一机位、同一对局时刻（每格左上角是对局时间，30 帧一秒），12 帧 |
| `改前_<技能>.mp4`、`改后_<技能>.mp4` | 每个技能改前、改后各一条录像（真实时间，30 帧） |
| `并排_<技能>.mp4` | 改前（左）和改后（右）同步播放 |
| `总表_改后.jpg` | 两个英雄 8 个技能改后的代表帧 |
| `merge_check/` | 把 `phase9` 里手感任务（r9-feel，前摇变短）的几个文件临时放进本分支录的两条（vQ、gE），看新前摇下特效是否还对得上；录完已换回 |
| `regress/` | 回归的原始输出（click、touch 改前改后、整局对战） |
| `tools/` | 录像、拼图的脚本（见下） |

技能名：`gQ` 砧撞、`gW` 淬火、`gE` 余烬地、`gR` 开闸、`vQ` 穿甲矢、`vW` 翻滚装填（含装填后的暴击一发）、`vE` 火油罐、`vR` 连弩齐射。

## 怎么录的

- 测试场（`arena=1`），`cam=` 固定机位，转角 45 度让技能从画面左边往右边放，距离 17～22 米。葛隆先挪到靶子前几米、面朝靶子；薇萝挪到一箭能穿两个小兵的位置。淬火录的时候每 0.3 秒让对面假人打他一下（不然挡不到伤害、看不出盾在挡）。翻滚装填录完翻滚再普攻一下假人，看暴击那一发。摆位都写在 `tools/rec_all.sh`。
- `tools/fxclip.mjs`：把页面里的 `performance.now` 换成脚本推的钟，每推 1/30 秒画一帧、截一张，拼成 30 帧的 mp4。录像是匀的真实时间，和无界面 Chrome 实际跑多少帧无关；改前、改后同一帧号就是同一对局时刻。顿帧（hitstop）也是按这个钟走的，录像里是两三帧几乎不动。
- 改前在主目录 5190 上录（11 月 19 日 23:44～23:56，那时 `phase9` 的代码还是本分支的起点 `29c2262`，手感任务 00:16 才合进去；核对过：改前、改后穿甲矢都在 0.65 秒出手）。改后在本分支 5206 上录。

## 自己写的脚本

- `tools/fxclip.mjs`：逐帧录（见上）。`tools/rec_all.sh <目录> [只录哪几个]`：八个技能的摆位和机位。
- `tools/compare.py`、`tools/grid.py`、`tools/summary.py`、`tools/make_evidence.sh`：拼对比图、并排录像、总表。
- `tools/fps_skills.mjs`：测试场里四个技能冷却清零反复连放，每秒读一次帧率。
- 逐帧的 JPG 拼完图以后删了（八个技能改前改后一共 600 多 MB），要重拼就从录像里抽回来：`ffmpeg -i after/gQ.mp4 -start_number 0 -q:v 2 after/gQ/f_%03d.jpg`，再跑 `zsh tools/make_evidence.sh`。

| 葛隆 W 淬火 | 盾墙是竖直的一片（俯视下人朝左右时只剩一条边）；放开时几道叠加发光的小火舌，基本看不出“喷火” | 盾墙改成往后弯过头顶的炉门（从哪个方向看都有一大片）；每挨一下盾面炸一小团火、溅火星；扇形里的火星被吸回盾里（挡得越多吸得越多）、盾顶冒的烟越来越浓、地上铺一片炉火光；放开时九股火团贴地往外滚，越滚越大，烧成暗红再变成黑烟往上散，扇沿一排火，地上一扇焦痕 |

## 回归和帧率（都在本分支 5206 上）

- `npx tsc --noEmit -p .`：无报错。`npm run build`：打出包（代码 1.2 MB）。
- `click_test.mjs`（21 项）、`touch_test.mjs`（31 项）：改前（把两个英雄文件临时换回 `29c2262`）、改后各跑，所有“对/错”的项一致；只有几项量出来的数不一样（`regress/click_*.log`、`touch_*.log`）：掉血数差十几到两百（打了几下随帧率浮动），`touch` 的“点地面后走了几米”改前两次都是 4.6、改后两次 9.0 / 9.1，“摇杆往右推走了几米”11.2 → 12.1 / 13.5。这两个测试都是岚单人局（`h=lan&solo=1`），葛隆、薇萝的代码不会跑到，原因没查清（怀疑是同一时间机器上有三十多个无界面 Chrome，页面加载快慢不同、点到的时候正好有小兵），没有改测试。改后的第二次 touch 在最后一步“竖屏”时 Chrome 被关掉（`Target closed`），前面 28 项都和改前一致。
- `match_batch.sh`：`h=gorran`（葛隆、薇萝、奥森对岚、托尔格、摩珂，全电脑）一整局 31 分 24 秒分出胜负，`errors` 为空（`regress/match/`）。
- 帧率（`regress/fps.txt`）：`tools/fps_skills.mjs` 测试场里四个技能每 0.4 秒连放 12 秒（大招、火场、冲击叠在一起）：葛隆、薇萝电脑档 12 次都是 60，手机档（`q=lite&touch=1`）12 次都是 60。`tools/fps_fight.mjs` 观战打团（`h=gorran`）：电脑档最低 58、平均 60；手机档 10 次都是 60。无界面 Chrome 锁 60 帧，只看得出“掉没掉到 60 以下”；没量改之前的数。
- 合并预演（`merge_check/`）：把 `phase9` 里手感任务改的 `actor.ts bot.ts play.ts sim.ts main.ts gorran.json vero.json` 临时放进来录了穿甲矢和余烬地，前摇变短以后特效照样挂在出手那一下，没有错位；录完换回。

## 自己觉得还不够好的

- 薇萝 W 翻滚装填：缩小并排看，改前改后差别不算大（拖尾、两蓬土、矢尖的小火、暴击那一下的火团要放大看才明显）。翻滚只有 0.3 秒，形状本身就小。
- 葛隆 W 的盾墙：改成往后弯的炉门以后，人朝画面上下时一大片很清楚；朝左右时还是偏窄的一条弧（加宽了张角，好一些）。放开的那一口火是这次改动最大的。
- 两个火场（葛隆 E、薇萝 E）：火是一团团往上窜的火团，远看还是“一颗颗火球”，不是连成一片的火海；薇萝的油面在亮的地面上有点像一张熔岩饼。没有用序列帧贴图（即梦没用），全是着色器现算的。
- 连弩的弩矢模型放大到 1.65 倍，近看有点像根木棍；几道弹道光叠在一起时头上会发白。
- 砸地、开闸、淬火放开那一下是一大团橙色的火（零点二秒左右最满），截到那一帧时面积偏大，口味上“发光克制”这一条要您看一眼。
- 只在测试场青绿色的地面上看过；烬誓庭那边的红土地上火和地面的反差没专门录（弹道光两边、火墙墙根已经垫了暗的，火团凉下来的暗红和烟本身会挡住地面）。
- 没在真手机上量帧率；顿帧在真实对局里的手感没逐个确认。
- 新零件的着色器在英雄第一帧预热（葛隆、薇萝的 passive），开局第一两帧可能顿一下，没量。
