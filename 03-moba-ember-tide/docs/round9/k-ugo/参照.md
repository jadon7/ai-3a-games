# 乌戈 · 渊灯：每个技能参照了谁、学它什么

只看实机画面学形状、节奏、层次和颜色的用法，不拿任何素材。

| 技能 | 参照 | 学它什么 |
|---|---|---|
| 普攻（冷光珠） | LoL 拉克丝的普攻、辛德拉的普攻 | 弹体是一颗很小的亮芯 + 一圈主色的晕，尾巴短；命中只有一小圈光溅开，不抢技能的戏 |
| 被动（盯光） | LoL 薇恩 W 的银箭标记、千珏的印记 | 标记很小、贴在目标头上、一眼认得出是谁挂的；被消耗时“碎”一下，配一个单独的伤害数字 |
| Q 冷光束 | LoL 泽拉斯 Q（奥术脉冲）、拉克丝 R（终极闪光） | 先在地上铺一条窄长的预警条（敌人看得出往哪打），出手瞬间整条亮；0.1～0.2 秒最亮然后收细消失；芯近白、外层主色、底下有一层暗的；地上留一道很快凉下去的残光 |
| W 诱光 | LoL 阿狸 E（魅惑）、锤石 Q 的锁链 | 弹体小而亮、飞得有点“飘”；命中后目标头顶有魅惑的记号，目标是转过身“走”过来的，不是被平移；一根丝把两个人连起来，断开时散成光点 |
| E 磷潮 | LoL 莫甘娜 W（痛苦腐蚀）、Dota 2 远古冰魄的冰霜漩涡 | 地上一片暗的池子，边缘一道清楚的线（范围一眼看得出），里面会动的东西少而慢；站在里面的人脚边有一点反馈；结束时从边上散掉 |
| R 渊口 | LoL 菲兹 R（巨鲨）、Dota 2 撼地者 / 神灵武士的延迟落点 | 落点预警要清楚、有倒计时感（尖牙往里收，收到头就咬）；巨物从地下冲出来、张开、一口合上，马上沉回去；合上那一下白光很短，后面是水的冲击环和水花，地上留一圈慢慢平复的涟漪 |

颜色：沉月会是青、白、深海蓝、珍珠色；乌戈在里面是唯一偏紫的冷光——主色渊蓝紫 `#7C8CFF`，灯心近白 `#D8E4FF`，垫底的深水 `#141A33`，牙是珍珠母 `#E8E4DA`。
亮的只有灯心和命中那一下；主体是有颜色的半透明；在亮地面上靠“暗底加亮边”读得清，不靠更亮。
