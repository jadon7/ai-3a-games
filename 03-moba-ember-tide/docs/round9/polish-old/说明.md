# 第九轮 · polish-old 的证据（六个老英雄还弱的技能特效）

| 文件 | 是什么 |
|---|---|
| `对比_<技能>.jpg` | 连续帧对比：上一行改前（主目录 5190，`phase9` 现状），下一行改后（本分支 5217），同一机位、同一对局时刻（30 帧一秒），12 帧 |
| `改前_<技能>.mp4`、`改后_<技能>.mp4` | 每个改了的技能改前、改后各一条录像（真实时间，30 帧） |
| `并排_<技能>.mp4` | 改前（左）和改后（右）同步播放 |
| `总表.jpg` | 改了的技能：改前、改后的代表帧并排（同一帧、同一裁剪） |
| `before/` | 在 `phase9` 上重新录的六个英雄全部 24 个技能（`<键>/f_*.jpg` 逐帧 + `<键>.mp4`），用来重新看一遍、挑最弱的 |
| `after/` | 本分支改后的录像和逐帧 |
| `regress/` | 回归的原始输出 |
| `tools/` | 录像、拼图的脚本（`fxclip.mjs`、`rec_all.sh` 摆位机位、`compare.py`、`summary.py`、`make_evidence.sh`） |

技能名：`gQ` 葛隆砧撞、`gW` 淬火、`gE` 余烬地、`gR` 开闸；`vE` 薇萝火油罐、`vW` 翻滚装填；`tW` 托尔格余音；`mE` 摩珂回流；`oQ` 奥森烛焰。

## 怎么录的

- 测试场（`arena=1`），`cam=` 固定机位。葛隆、薇萝的摆位和机位照 fx2c 的 `rec_all.sh`，岚、托尔格照 fx2a 的 `fx2a_jobs.json`（世界坐标换成路向坐标），摩珂、奥森是这次新定的（全写在 `tools/rec_all.sh`）。
- `tools/fxclip.mjs`（fx2c 写的，拷过来改了两处：ffmpeg 单独带 `DYLD_LIBRARY_PATH`、测试场左上角的调试按钮藏掉）：页面里的 `performance.now` 换成脚本推的钟，每推 1/30 秒画一帧截一张，录像是匀的真实时间。
- 改前在主目录 5190 上录（11 月 20 日 05:47 起，`phase9` 当时是 `45a0b15`，和本分支的起点同一份代码），改后在本分支 5217 上录。
- 同一个技能改前改后偶尔差一两帧出手（钟是脚本推的，但第一帧之前那一下页面自己跑的时间不完全一样），对比图上看得出来的是 `gE`、`vE` 早一帧。

## 共用零件（`fx_fx2c.ts`，归本任务）

- 只**新加**了两样，原有的 `puff / puffer / tracer / wall / fence / strip / reticle` 一行没动，新英雄（卡兹、赫达、塞伦、乌戈）用到的 2a / 2b / 2c 零件默认样子都没变，所以没有连带改到新英雄。
  - `sheet`：贴地漫开的一层火（前沿最旺、身后烧成暗红再焦黑、推到头以后一块块蚀掉；整圈或扇形）。材质进池子、网格按细分档进池子。
  - `flameBed`：一片立在地上的小火苗（一张张只绕竖轴转向镜头的火舌片，一次画完；边上密、里面几簇稀的；`ignite` 从中间往外点着，`set` 跟着人走）。按片数进池子。
  - `warm` 里加了这两样的预热。
- `fx_fx2a.ts`、`fx_fx2b.ts` 没动。别的任务的文件（`fx.ts`、`fxlib.ts`、`view.ts`、`skills.ts`、`hud.ts`、新英雄）都没碰。

## 自己觉得还不够好的

- **托尔格 W**：五六道细环去掉了，换成水冠、水墙、湿的一片、跳起来的水珠，缩小看改前改后能分开；但俯视下它仍然是“一圈”（水墙的顶、厚环的白沫边都是圆的），水珠原地跳那一层太细，缩小看几乎看不出；身上钟罩“被敲得一胀一缩”幅度小，缩小看不到。没有做出“钟”这个形状本身的强记号。
- **摩珂 E**：浪矮了、透了、分几股，近看不再是一块板；缩小看（总表那一格）还是一道横着的青色带子，白沫浪唇不够醒目。没有用贴图，浪身还是着色器算的，像水的程度一般。
- **火苗（flameBed）**：是一张张竖着的火舌片，近看能看出是片（边缘偏硬、偏平），颜色比较一致的橙黄；边上一圈很密，在亮的草地上整圈偏亮，“发光克制”这条请您看一眼。里面那几簇稀的有时像散落的橙色小点。
- **葛隆 Q**：只是顺带压了一档（火球少一半、加一扇贴地的火），缩小看改前改后差别不大。撞上那一下目标身上整个发白（受击闪白），那是 `polish-lib` 的活，我没动。
- **薇萝 W**：加了地上的蹭痕，缩小看能认出“滚过的那一条”，但这条痕是一道发黑的带子，近看有点像一块脏印；装填好以后弩上的样子没改。
- **奥森 Q**：火心缩小了，命中那一帧中间仍是一小团亮黄（烛火本来的颜色），形状交给几朵往外窜的烛火，缩小看还是“一团亮的”，只是小了、短了。
