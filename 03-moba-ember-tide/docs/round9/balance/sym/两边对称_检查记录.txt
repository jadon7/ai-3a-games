找到的四个原因，逐个改了以后再跑：
1. 更新顺序：小兵、塔、野怪一直按 ents 的顺序算，每一波 0 队的兵先放进去，两边同一刻出手时 0 队先算、先打死人。→ 每一步正着、倒着轮流过一遍（sim.ts）。
2. 队形：两队都按“自己前进方向的左边 / 右边”排，照河道镜像过去左右是反的，绕塔座时两队的兵贴着不同的一侧。→ 1 队的左右反过来；被挤时往哪边让也按队形那一侧（sim.ts）。
3. 兵线：寻路连出来的两头不一样（上面说的 2 米）。→ 只留 0 队那一半，后一半照河道镜像（sim.ts）。改后三条线 along(0队, s) 和 along(1队, s) 镜像以后完全重合（误差 0）。
4. 墙头的石头：墙两头的大小石头是随机摆的，四份墙各不一样。上路 1 队那一侧（u≈+15，v≈-75）、下路 0 队那一侧（u≈-15，v≈+70）的墙头各有一块 1.5 米的大石头压在兵线的铺地上，对面同一个位置只有小石头（截图：上路河道口_1队一侧.jpg、上路河道口_0队一侧.jpg）。
   兵线里镜像对不上的能走格子共 100 个（0.5 米一格），最大的两块就是这两处。→ main.ts 里伸进兵线的墙头石头和墙墩不进寻路（布局里兵线本来就压过墙，墙身早就不挡，石头也不该挡）。
