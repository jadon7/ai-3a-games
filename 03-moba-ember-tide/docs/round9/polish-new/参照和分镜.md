# 第九轮第四批 polish-new：四个新英雄还弱的技能 · 参照和分镜

只看参照，不拿素材。每条：参照谁的哪个技能、学它什么；改了什么（分镜按 起手 → 出手 → 途中 → 命中 → 余韵）。

## 塞伦（珠铳，沉月会射手）

| 技能 | 参照 | 学什么 |
|---|---|---|
| 普攻 | LoL 凯特琳、厄运小姐的普攻 | 游戏镜头里普攻读得清靠三下：出膛一下、弹道一道有头有尾的线、命中一小撮；弹道要比模型细节粗，命中不要每个人一样的白圈 |
| Q 压满 | LoL 崔丝塔娜 Q、金克丝 Q（火箭） | 开的那一下在武器上；持续期间武器上有小而稳的提示；强化弹比普通弹大一号、溅射有清楚的范围 |
| W 珍珠雷 | LoL 凯特琳 W、烬 E | 陷阱本体俯视一眼认得出（有形状、有轮廓）；生效有一下提示；触发范围给敌人看得见但很淡 |
| E 反冲 | LoL 凯特琳 E、薇恩 Q | 扇形冲击一下就收，人往后滑、脚下拖痕清楚 |
| R 沉月弹 | LoL 伊泽瑞尔 R、韦鲁斯 Q 蓄力 | 蓄力是“往枪口聚”，不是一个正对镜头的圆片；近处打中时几层东西错开时间，不叠成一团 |

- 普攻：出膛一团水汽、一圈小水环（套在弹道上）→ 弹头是一颗珍珠，外面一团小光、底下垫深海蓝，身后 4.6 米长的白芯水线（原来 2.4 米、宽 0.34 → 现在宽 0.68）→ 命中：白光一下、一圈小水环往前张、一团水雾、一把水珠顺着弹道溅出去 → 水线尾巴往弹头收、变细、0.2 秒淡掉。
- Q：拍罐子喷汽，一圈珊瑚色的环顺着枪管推到铳口、铳口一闪，脚下湿一片、一圈珊瑚边的白沫环推开 → 4 秒里铳口一点珊瑚色小光一跳一跳 → 每发更大的弹头、更粗的珊瑚身水线、珊瑚色的出膛环 → 溅射：底下湿一片深色、矮水冠、一圈白沫珊瑚边的环推到 1.8 米。
- W：珍珠滚出去 → 落地时一圈六瓣扇贝壳“啪”地张开（0.22 秒），露出珍珠，底下一摊深色湿印 → 0.62～0.87 秒触发圈从一处绕一圈画出来（细水线、六颗小珠），之后淡到很淡地留着 → 踩响照旧；定身的硬壳彩虹压一半。
- E：立着的水墙从 0.4 秒缩到 0.26 秒，扇形水浪的白沫 0.28 秒推到头就塌 → 两道更宽更深的滑痕（中间一层淡湿印连成一片），一路踢起水珠和低水汽。
- R：蓄力时铳口前一圈立着的三臂水旋越卷越紧，中间珍珠从米粒长到拳头大（正好接上打出去那颗）→ 出手只一圈珊瑚色的环（原来两圈）、脚下环小一号 → 打中英雄：水冠矮一档，珊瑚色的厚环晚 0.05 秒才推出去。

## 乌戈（渊灯，沉月会法师）

| 技能 | 参照 | 学什么 |
|---|---|---|
| R 渊口 | LoL 菲兹 R（巨鲨破水）、Dota 2 潮汐猎人的落点 | 落点预告是“水下有个大东西的影子上来了”，不是贴地画图标；咬合以后马上潜回去、被水花盖住，不留一个罩子 |
| Q 冷光束 | LoL 泽拉斯 Q、维克托 E | 光束是一道干净的直光，亮芯直、身子有颜色；地上的痕迹淡，不和空中那道争 |
| W 诱光 | LoL 阿狸 E、莫甘娜 Q 的拖尾 | 细丝在亮地面上也是有颜色的，靠暗底托住 |

- R：0～1.0 秒暗水越来越深，水底一个横着的椭圆影子从小长大、越来越黑，后半段浮出两片颌的轮廓和中间那道嘴缝，正中的灯从深处亮起来，几段断开的波纹往里收（去掉了地上的 14 颗平面白牙）→ 0.5 秒巨嘴冲出水面张开（颌改成不透明的哑光皮：斑驳、褶、只有口沿一道亮线）→ 1.0 秒咬合，只鼓 0.06 秒就往下扎，0.26 秒没入水里（原来停 0.1 秒、0.42 秒慢慢沉）。
- Q：光束灯口那头不再细成一点（原来收到 0.25，看着像折了一下）、白芯是干净的一道直线、光丝频率减半只在身子上；地上的光痕亮线从 0.42 压到 0.14；灯上的四芒星换成一团圆光。
- W：光丝底下垫一层宽一倍多的深水色，颜色从淡紫改成蓝紫。

| E 炉吼 | LoL 安妮 W、兰博 E 喷火的扇形 | 扇形是一整片往外涌的热，前沿有厚度，不是几根线 |

- R 锁定圈：套上的前 0.4 秒照旧亮，之后温度 0.7 → 0.42、不透明 0.8 → 0.58。
