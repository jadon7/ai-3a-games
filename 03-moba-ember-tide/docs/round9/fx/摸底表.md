# 第九轮 · 特效摸底表（改之前）

方法：测试场（`arena=1&h=<英雄>`，靶子不动），镜头 `dist=19`，每个技能放出去以后按对局时间每 0.08 秒（大招 0.16 秒）停住画面截一张（`tools/fx_frames.mjs`，停画面靠 `__setSpeed(0)`，不受无界面 Chrome 帧率影响），拼成联系表（`tools/fx_sheet.py`）。改之前的联系表：`before_<英雄>.jpg`。

## 零件层面的毛病（所有技能共有，粗糙感主要从这里来）

| 零件 | 现在的样子 | 差在哪 |
|---|---|---|
| 粒子贴图 `SPR`（16 种） | 128 像素一格，画布渐变加几笔路径画的：烟和尘是几个圆形渐变叠起来，火是五个对称的水滴，闪光是一团圆光加十字 | 烟、火、尘的边都是一样圆滑的渐变，放大一眼看出是“程序画的圆”；没有絮状的边、没有浓淡；火花没有亮芯，闪光不是星芒 |
| 粒子的消散 | 所有粒子都是整颗一起变透明 | 烟尘不是一缕缕散掉，而是整团淡掉；发光的粒子从生到死同一个颜色，没有“一下亮”的热芯 |
| 贴花（焦痕、裂纹、水、蜡、黑暗） | 淡出时整片均匀变淡 | 没有侵蚀、溶解，地上的印记“突然消失”的感觉 |
| 命中 | 普攻命中只有玩家自己的普攻有一团圆光加几根白线；别的单位打别的单位基本没有反馈；技能命中各写各的，多数只有一团 `flash` | 没有白芯、没有张开的细环，目标身上没有受击闪白，大招打中没有顿帧 |
| 刀光 | 一条普通半透明的白带子 | 像一片塑料，不发光，没有亮边 |
| 弹道 | 弹体模型加一串粒子；塔和小兵的弹道是两颗光点 | 没有拖尾带子，飞得快时是一个点在跳，看不出轨迹 |
| 伤害数字 | 每跳一个数字新建一张贴图和材质，用完不释放；纯色 | 没有渐变和弹跳的节奏；暴击和普通差别小；还有内存泄漏 |
| 池子 | 贴花、柱、光带、闪光每次新建材质，用完销毁 | 团战时每秒几十次建材质 |
