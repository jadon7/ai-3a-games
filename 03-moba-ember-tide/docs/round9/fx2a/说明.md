# 第九轮 · fx2a 的证据（岚、托尔格）

| 文件 | 是什么 |
|---|---|
| `参照.md` | 每个技能参照了 LoL / Dota 2 / 王者荣耀的哪个技能、学它什么 |
| `分镜.md` | 每个技能的分镜：起手 → 出手 → 途中 → 命中 → 余韵，各段多长、画面上有什么 |
| `对比_<技能>.jpg` | 连续帧对比：上一行改前、下一行改后，同一机位、同一对局时刻（每格左上角是第几帧，30 帧一秒） |

技能名：`lan_Q` 钩引、`lan_W` 潮隐（含破隐那一刀）、`lan_R` 涨潮、`torg_Q` 撞钟、`torg_W` 余音、`torg_R` 沉没。

## 怎么录的

- 测试场（`arena=1`），镜头用 `?cam=` 固定在施法者和靶子中间，距离 11.5～19 米（特效占画面一半以上）。岚的大招这次录全了（起手、五刀、劈下、余韵）。
- 工具 `tools/fx2a_clip.mjs`：对局按 0.25 倍速走，每到 1/30 秒对局时间就停住画面截一张，最后按 30 帧拼成 mp4。所以录像是匀的真实时间，不受无界面 Chrome 二十帧上下、还不稳的影响；改前、改后的同一帧号就是同一对局时刻。顿帧（hitstop）是按真实时间走的，逐帧截的录像里看不出来。
- 摆位、机位、放哪个技能都写在 `tools/fx2a_jobs.json`，可以重录：`MOBA_URL=… node tools/fx2a_clip.mjs <目录> lan "$(python3 -c '…')"`。
- 改前、改后都在本分支的 5204 服务器上录，同一份摆位和机位。改前是把 `heroes/lan.ts`、`heroes/torg.ts` 临时换回第一轮合并后的版本（`29c2262`，即本分支的起点）录的，录完换回来。
  没用主目录 5190 录改前：录到一半 `phase9` 合并了手感任务（r9-feel），前摇变短了，5190 上的出手时刻和本分支对不上，并排放就不是同一时刻。

## 每个技能改了什么（一句话；分镜见 `分镜.md`，参照见 `参照.md`）

| 技能 | 改前 | 改后 |
|---|---|---|
| 岚 Q 钩引 | 骨链 + 几滴水，钩中一圈细环，落地一道很淡的刀光（多半被托尔格的身子挡掉） | 起手水往钩刃上收；出手一道尖闪光；钩头白芯拖尾、地上跟着划出水痕；钩中一道朝回的“咬合”闪光 + 目标脚下水冠；拉过去时一道又宽又亮的闪线从起点连到她身上；落地斜劈的大月牙（画在模型前面）+ 地上刀痕 |
| 岚 W 潮隐 | 一根白色的水柱（像一截塑料管）、一圈环；破隐一道刀光 | 她的身子散成一捧水落下、原地白影子很快淡掉；矮而宽的水冠往外塌、碎成一块块；一圈水汽贴地推开；破隐时先一道扑出来的闪线，再两道交叉月牙 + 目标水冠 + 地上叉形刀痕 |
| 岚 R 涨潮 | 地上一大片带同心水纹的水面（一圈圈白线很乱）；每刀一道细刀光、一根细白线；劈下一根白水柱 | 涨潮有清楚的白沫边（8.5 米范围一眼看出），里面平静的深水；每闪一道头宽尾尖的亮闪线 + 青色残影；每刀一道交替斜向的大月牙，地上留刀痕、越砍越多；劈下：大水冠往外塌 + 地面裂开（先亮后暗）+ 两圈冲击 |
| 托尔格 Q 撞钟 | 一道细白弧 + 打中的人身上一圈圈白环 | 起手钟上聚光；一道很厚的月牙横扫（亮边 + 铜绿身体 + 深色底）；地上扇形厚冲击波 + 断续的弧形刮痕；打中的人脚下水冠、被推开的一路拖水 |
| 托尔格 W 余音 | 三圈很细的白环往外走 | 起手几圈细环往脚下收；钟上“嗡”的两圈正对镜头的环；声壳往外鼓；地上一圈前沿清楚的厚环（后面拖一段压暗的带子）+ 两圈余音；前沿一路掀起水；打中的人脚下小水冠 |
| 托尔格 R 沉没 | 落点一圈细线；落地一根白水柱；漩涡是奶白的宽旋臂；最后一响一根白水柱 | 落点预告：清楚的边线 + 往里收的刻度，一直亮到砸下；落地：大水冠 + 地面裂开；漩涡旋臂收细、更像水；最后一响：声壳 + 大水冠 + 再裂一次 + 厚冲击 |

## 回归和帧率（都在 5204 上，本分支）

- `npx tsc --noEmit -p .`：无报错。`npm run build`：打出包（代码 1.2 MB）。
- `click_test.mjs`（21 项）、`touch_test.mjs`（28 项）：和动手前留底的结果逐项一致（只有掉血数随伤害浮动差几点、走的距离差 0.1 米）。
- `match_batch.sh`：`h=lan` 一整局 18 分 51 秒分出胜负，`errors` 为空（这一局在托尔格 W、R 最后一次改动之前跑的）；改完以后又用最终代码跑了一局 `h=torg`：20 分 35 秒分出胜负，`errors` 为空。
- `fps_fight.mjs`（观战，六个电脑打团，每秒读一次，读 10 次）：电脑档最低 54、平均 59（54 是刚从 16 倍速切回 1 倍速的第一秒，其余 9 次都是 60）；手机档（`q=lite`）10 次都是 60。无界面 Chrome 锁 60 帧，只能看出“掉没掉到 60 以下”。没有量改之前的数，没法说比原来多耗多少。

## 自己觉得还不够好的

- 托尔格 W：缩成小图并排看，改前改后都是“一圈圈环往外走”，差别要放大看（矮水墙、钟上的环、声壳）才明显；声壳在俯视镜头下几乎只剩一圈边。
- 托尔格 R：漩涡的着色器是原来的，只改了旋臂粗细和颜色，加了边上的水墙；2.5 秒漩涡的主体和改前是同一个东西。
- 托尔格 Q：命中时 fxlib 的标准命中会在每个目标身上张开一圈白环（`impact` 里的 `SPR.ring`），三个目标就是三个白圈，有点廉价；这是共用的零件，没动。
- 水冠在一些角度下有点像玻璃、冰碴，不够“水”（没有用贴图，纯着色器算的）。
- 岚 R 劈下、托尔格 R 最后一响那一下中心发白的一团（fxlib 的 flash + 白芯）面积偏大，只持续零点一几秒，但截到那一帧时比较晃。
- 顿帧（hitstop）按真实时间走，逐帧录像里看不出来；真实对局里没逐个确认手感。
- 手感任务合进 `phase9` 以后前摇变短：起手的预兆已经改成读前摇的长短（`windup()`），但没有在合并后的代码上录过、看过。
