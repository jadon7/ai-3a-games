# fx2a · 参照（岚、托尔格）

只看、不拿素材。每个技能一行：参照谁的哪个技能，要学它什么。共同的原则来自 Riot 公开的 VFX 风格指南（[VFX Styleguide](https://nexus.leagueoflegends.com/wp-content/uploads/2017/10/VFX_Styleguide_final_public_hidpjqwx7lqyx0pjj3ss.pdf)、[Clarity in League](https://www.leagueoflegends.com/en-au/news/dev/clarity-in-league/)、[Anatomy of a LoL missile](https://realtimevfx.com/t/anatomy-of-a-league-of-legends-missile-part-2-what-are-we-communicating-with-our-vfx/13062)）：

- 先读得清，再好看：一个技能只有一个视觉焦点（弹道的头、刀光的亮边、落点的中心），其余都压暗、压小。
- 主形状 + 次形状 + 少量点缀，三层；不要一团随机粒子。
- 越强的效果（控制、大招）越大、越亮、形状越尖、节奏越抢眼；“如果什么都重要，就什么都不重要”。
- 不用纯白、纯黑大面积铺；只有命中的那一下用接近白的芯。
- 同类效果用同一套语言（眩晕都是头顶一圈、减速都是脚下一圈）。

这一轮从第一轮的录像里看出的一个具体原因：**岚和托尔格的主色是青，测试场和河道的地面也是青绿**，叠加发光的青色落在青绿的地面上几乎没有反差，所以“改了看不出来”。这一轮的主体改成“深海蓝的半透明身体（普通混合，压暗地面）+ 白沫色的亮边（叠加）”，靠明暗反差而不是靠更亮。

| 技能 | 参照 | 学它什么 |
|---|---|---|
| 岚 Q 钩引 | LoL 派克 Q「穿肠刺」、Dota 2 帕吉「肉钩」、LoL 锤石 Q「死亡判决」 | 焦点在钩头：钩头是一个尖的亮形状，链子本身暗、细；钩中那一下有一个朝回拉方向张开的“咬合”闪光；锤石把自己拉过去时沿着链子有一条拖尾。派克的水：飞行路线下面的地上划过一道水痕 |
| 岚 W 潮隐 | LoL 派克 W「幽潭潜行」、LoL 阿卡丽 W「黄昏密幕」、Dota 2 力丸 / 赏金的隐身 | 进入隐身有一个成形的“幕”：派克是一圈水汽散开、地上一摊水；阿卡丽是一圈烟环。人是“化掉”的，不是直接变透明。破隐那一刀是最重的一下（刺客的爆发点） |
| 岚 R 涨潮 | LoL 易大师 Q「阿尔法突袭」、Dota 2 主宰「无敌斩」、王者荣耀 李白 R「青莲剑歌」 | 每一闪之间有一道又细又亮的“闪线”连着两个落点；每一刀是一道干净的、斜的月牙，交替方向，像在目标身上划了个叉；落点留残影；地上留下刀痕，越砍越多，最后一刀收尾最重 |
| 托尔格 Q 撞钟 | Dota 2 潮汐猎人「锚击」、LoL 诺提勒斯（锚、深海）、LoL 德莱厄斯 Q 的外圈刀刃 | 重武器横扫：一道很厚的弧（前沿一道亮边、后面是有颜色的厚身体），扫过的扇形地上留刮痕；水被甩成一片扇形；打中的人一个重的命中 + 头顶眩晕的标记 |
| 托尔格 W 余音 | Dota 2 上古巨神「回音践踏」、LoL 加里奥 W 的护盾、Dota 2 撼地者的余震 | 声波是一圈有厚度、边缘清楚的环（敌人要一眼看出 6 米的范围），后面跟两三圈细的余音；钟敲响的那一下有一个罩子形的“声壳”往外鼓；护盾是有边缘高光的罩子 |
| 托尔格 R 沉没 | LoL 墨菲特 R「势不可挡」（落地）、Dota 2 谜团「黑洞」（漩涡）、Dota 2 撼地者「回音击」（最后一响） | 起跳前落点先亮出范围（给敌人看）；落地那一下全技能最亮、最大：白芯、冲击环、水冠、裂纹；漩涡有清楚的边、旋臂往里卷；最后一响从中心炸出一圈重冲击 + 声壳 + 眩晕 |
