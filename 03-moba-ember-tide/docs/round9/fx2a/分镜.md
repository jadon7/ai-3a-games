# fx2a · 分镜（岚、托尔格）

时间都是对局时间。出手时刻来自 `public/assets/hero/<id>.json`（没改）：本分支上岚 Q 0.30 秒、W 0.59 秒、R 0.42 秒；托尔格 Q 0.38 秒、W 0.66 秒、R 0.48 秒。
手感任务（r9-feel）合进 `phase9` 以后前摇变短（岚 0.2 / 0.1 / 0.25，托尔格 0.25 / 0.15 / 0.25），起手那一段用 `windup()` 读前摇，跟着变短；下面写的“起手”时长是本分支上的。
共同的做法：主体底下垫一层深海蓝（普通混合，压暗地面给出轮廓），上面一层叠加的亮边；只有命中/落地那一下接近白、而且只有零点一几秒。
零件都在 `src/map/game/fx_fx2a.ts`：`blade` 月牙刀光、`streak` 闪线、`crown` 水冠、`mark` 贴地印记（刀痕/水痕/裂纹/湿印/涨潮/预告/刮痕）、`dome` 声壳、`spear` 尖闪光、`converge` 收拢的水珠、`splash` 泼出去的一圈水。
