# 《烬与潮》界面设计说明（第九轮）

一句话：**潮水里捞上来的黑铁，镶一圈旧黄铜。** 底色偏青、偏冷，铜边偏暖。阵营色只用在讲阵营的地方，不拿来做装饰。

## 1. 看了什么，拿了什么，没拿什么

| 参考 | 拿过来的（结构和惯例） | 没拿的 |
|---|---|---|
| Dota 2（`refs/dota2/ui/` 六张，D1–D13） | 对局 HUD 底部正中一条；顶栏两队头像加比分时钟；说明框“标题 / 消耗 / 正文 / 斜体背景描述”分段；结算两队表格 | Dota 那种很平、几乎没有装饰的面板；英文大写细字 |
| LoL（客户端、选人、载入、对局 HUD） | 选人：左右两列是两队栏位、中间英雄网格和筛选、底部锁定；锁定有演出；载入：每人一张竖卡、上下两排、底下提示加进度条；HUD 的冷却转盘和转好时亮一圈；商店的“分类 + 列表 + 合成路线 + 详情” | LoL 的金色海克斯科技六边形纹样；蓝紫配色 |
| 王者荣耀 / LoL 手游 | 手机横屏：左下浮动摇杆，右下大攻击键、技能键绕成一段弧、大招最大；左上小地图，金币点开商店；取消圈 | 王者那种满屏高饱和发光、厚重渐变按钮 |

三家不拼：结构照行业惯例（玩家已经会用），**皮是自己的一套**：黑铁 + 旧铜 + 珍珠铆钉 + 潮/烬两色。

| 铜 | 主 `#c9a25e`，亮 `#f0d9a0`，暗 `#6b5330` | 描边、标题装饰、选中、主按钮 |

| 阵营 | 沉月会 潮青 `#6fe0d6`（配珍珠白）；烬誓庭 余烬 `#ff8f46`（配黄铜） | 只出现在阵营标签、英雄卡底边、标题字 |

## 3. 字

- 标题（界面名、英雄名、胜负、播报）：宋体粗体（Songti SC → 思源宋体），字距 0.16–0.34em，像刻在铜上的字。
- 正文：黑体（Avenir Next / 苹方 / 思源黑体）。数字一律等宽。
- 字号层级（1920 宽）：胜负 118 / 首页主按钮 21 / 英雄名 44 / 界面标题 30 / 面板标题 17–20 / 正文 12.5–14 / 说明小字 10.5–11.5。手机横屏整体按 `--u`（屏高 390 时 16 像素）缩。
- 标题字 “烬与潮” 是专门做的一张图（`public/assets/ui/kit/wordmark.webp`）：宋体粗体 + 黑描边 + 铜边 + 浮雕高光，“烬”余烬渐变、“潮”潮青渐变，下面一条铜线和菱形，副标 EMBER · AND · TIDE。做成图是为了在没有宋体的机器上也一样。

## 4. 面板、边框、按钮

- **面板**：锻铁纹理（即梦出的一张，镜像拼成无缝，`kit/panel.webp`）上压一层从上往下的暗；外圈“铜边”是一张 SVG 九宫格（外暗线、旧铜线、内暗线、四角折角加珍珠铆钉），挂在 `::after` 上，不占布局。
- **大面板**（商店、计分板、菜单、设置、结算、选人信息条、小地图）四角再压一朵即梦出的铜花角（`kit/corner*.webp`，潮水卷草纹 + 珍珠铆钉）。
- **分隔**：即梦出的铜线加潮/烬双色小圆章（`kit/divider.webp`），用在英雄栏顶边、菜单和计分板标题下、大字播报下。
- **等级章**：即梦出的铜铁圆章（`kit/medal.webp`），用在英雄头像角上的等级和手机的攻击键外圈。
- **按钮**：切角铁牌（`clip-path` 八边形，1 像素铜边）；**主按钮是一整块亮铜**，悬停时一道高光扫过；一屏只有一个主按钮（开始对局 / 锁定 / 购买 / 继续 / 再来一局）。小的功能键是圆形铁钮（设置、菜单、关闭）。
- **图标格**（技能、装备、头像）：1 像素黑线 + 1 像素铜线，选中换亮铜加一圈柔光。

## 5. 图标

24 格线描，1.7 粗、圆头，`currentColor` 上色，全部是代码画的（`uikit.ts` 的 `ICON`）：
- 职业 6 个（坦克盾、斗士双斧、刺客匕首、法师星芒、射手弓箭、辅助心加十字）；
- 分路 / 位置 5 个（方块是地图，亮的那段是走的线：上单、中路、下路；打野爪痕；游走盾星）；
- 属性 6 个（攻击、法强、护甲、魔抗、攻速、移速），杂项 20 来个（菜单、设置、声音、全屏、锁、眼、靶、塔、钟、王冠……）。
技能、装备、增益、金币、回城仍用原来的插画。

## 6. 动效节奏

同一条曲线 `cubic-bezier(.2,.75,.25,1)`（先快后慢）。只动位置、缩放、透明度、颜色，不做会让整页重排的动画。

| 事件 | 时长 | 怎么动 |
|---|---|---|
| 悬停 / 按下 | 120 ms | 亮一档、上浮 2 像素 / 下沉 1 像素缩 1.5% |
| 面板打开（商店、菜单、说明框） | 140–200 ms | 淡入 + 从 98.5% 放大 |
| 换界面（首页 → 选人 → 载入） | 260–600 ms | 淡入；首页三块错开 0.1 秒依次上浮 |
| 锁定 | 约 1 秒 | 卡片放大回弹 + 盖“锁定”章，别的卡变灰，背景立绘推近，自己栏位亮两圈，名字横幅从左飞进 |
| 载入英雄卡 | 每张错 70 ms | 依次上浮，再各扫一道高光 |
| 技能冷却 | 每帧 | 圆锥压暗 + 一条亮边沿着转；转好时外面扩出一圈铜光（550 ms） |
| 升级 | 900 ms | 等级章放大到 1.35 再回来，发一下光 |
| 进账 | 1.1 s | 金币框上飘一个“+多少”（≥15 才飘，被动的细水长流不飘） |
| 掉血 | 450 ms 延后 250 ms | 血条后面一截浅色慢半拍跟上；回血直接跟 |
| 击杀条 / 大字播报 | 320 / 450 ms | 从右边滑进 / 从 125% 缩回 |

### 计分板 / 菜单 / 结算
- 计分板：标题条（比分、时钟）+ 两队各一段（队名 · 击杀 · 剩几塔），每行：头像、名字 + 称号 · 职业（阵亡写几秒复活）、等级菱形、战绩、补刀、金币（对方的看不到）、六格装备。
- 菜单：铜花角面板，“继续”是主按钮，下面声音、重开、全屏、回主菜单，最底下一行键位说明。
- 结算：胜负大字（获胜方色，带光），铜线，比分和用时；两队各一张表：头像、名字 + 最佳章、等级、战绩、补刀、经济、对英雄伤害条、六格装备；自己那行铜色高亮。按钮：再来一局（主）/ 回主菜单。

## 8. 为下一批留的位置
- 顶栏、选人栏位、载入卡、计分板、结算表都按“每队五个人”排得下，数据是三个时自动只排三个（都是按列表生成的，没有写死个数）。
- 分路图标已经有五个位置（上单、打野、中路、下路、游走）；现在只用三条线。
- 商店：分类 / 列表 / 合成路线 / 详情四块已经分好，合成路线读 `from`，“可以合成”读反向关系；装备多了列表可以滚，搜索框已经能用。
- 英雄难度暂时写在 `uikit.ts` 的 `DIFFICULTY`（英雄数据里没有这一项）。

## 9. 第九轮 ui2 的改动（对局中，清单和证据在 `docs/round9/ui2/`）

- **对局里的队伍色改成 LoL 的习惯**：自己绿、队友（我方）蓝 `#4fa6f5`、对方红。头顶血条、脚下的圈、小兵和塔的血条、顶栏头像下的血条、小地图、击杀条、比分都按这个。对局外（选人、结算）的“我方”还是绿，没动（`lobby.ts` 不归 ui2）；观战的叫法改成蓝方、红方。法力在头顶血条里偏靛蓝 `#3048c8`，和队友的天蓝血条拉开。
- **桌面底栏**按 1920×1080 设计、整体按 `--k` 缩放（`createHud` 里的 `fit`）：头像 150×192 + 栏 176 高，技能格 76，R 右边两个小格（回城 B、商店 P）放在召唤师技能的位置；经验是等级章外的一圈铜环。
- **手机**：技能键、攻击键是“玻璃底 + 细铜圈 + 外面一圈半透明暗环”（王者荣耀的路子），攻击键不再用铜章当底。
- **头顶血条**（`hero/hero.ts` 的 `lifeBar`）：方形等级牌 + 血条 + 法力，上面一行英雄名；自己的整条描铜金边。脚下：自己亮绿粗圈 + 正前方一段亮弧（朝向）。
