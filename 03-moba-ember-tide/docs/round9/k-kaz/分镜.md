# 卡兹 · 焚爪：参照和分镜（第九轮 k-kaz）

颜色：主色熔岩红 `#D8432A`，亮处熔铁橙 `#FFB070`（只在芯、刚划开的那一下），暗处黑铁 `#2A2624` / 炭黑；烟 `#2E2724`，土 `#8A7D68`。
火团用 fx2c 的 puff，取偏低温的一段（heat 0.5～0.8），比葛隆的橙红、暗、烟多。识别点是“三道爪痕”：普攻在目标身上、扑杀和焚猎落地在地上、锁定火圈里三道往里指的刻度。

| 技能 | 参照（只看不拿） | 学它什么 |
|---|---|---|
| 普攻 | LoL 雷恩加尔、沃里克的普攻命中 | 三道平行的爪痕在目标身上一闪就收，比刀光短、比刀光密 |
| Q 扑杀 | LoL 雷恩加尔草丛扑跃、卡兹克 E | 蹲身蓄势 → 一跃 → 落地一圈土环；落地点留痕，扑中有顿帧 |
| W 裂爪 | LoL 德莱厄斯 Q（大杀四方）的圆形刀光 | 一道有厚度的环形刀光（外沿亮、里面暗），地上留一圈刮痕；两段一来一回 |
| E 炉吼 | LoL 雷恩加尔 W 战吼的声浪、Dota 2 龙骑士喷火的扇形 | 扇形里前沿最亮、后面拖两道声纹，扇形边线清楚（敌人看得出范围），被吼到的冒烟 |
| R 焚猎 | Dota 2 军团指挥官“决斗”的地面圈、LoL 沃里克 R 的扑和压制、雷恩加尔 R 头顶的猎物标记 | 锁定要一眼看出“谁被盯上”：猎物脚下一圈跟着走的火圈 + 一道连线；起跳前有明显的蓄力预兆 |

## 分镜

- **普攻**（0.2 秒）：出手 → 目标身前三道斜的爪痕（正对镜头，画在模型前面）0.05 秒从上划到下，中间一道熔铁橙的芯、外面熔岩红、边上一圈压暗；之后 0.15 秒变细收掉。几点火星顺着出手方向崩出去。左右爪交替，斜的方向交替。
  - 第三下点燃（被动）：爪痕上窜起一小团火、崩一把火星；之后 2 秒目标身上一小簇火舌 + 细黑烟，每 0.5 秒飘一点余烬。没有常驻特效。
- **Q 扑杀**：起手（0.25 秒）后腿下蹲（动作），面甲眼缝亮一下，脚边扬一点灰 → 起跳：后脚蹬起一蓬土、脚下一圈土环 → 空中（0.33 秒）：身后一道很短的火痕（fx2c 的弹道光，尾巴追着胸口）+ 一串火星，跳出去三成、六成半时各留一个暗红的影子（起跳那一刻就留影子会和身子叠在一起，整只猫看着发粉） → 落地：一圈立着的土墙 + 贴地的土环（半径 1.8）、一圈扬土；面前地上三道斜的大爪痕（划开时最烫，1.7 秒里凉黑、一块块蚀掉）；扑中：目标身上一道大爪痕、白芯、顿帧 0.04、轻抖 0.06。
- **W 裂爪**：起手（0.25 秒）两只前爪亮起，拖出两道熔岩红的拖尾一直跟到第二爪 → 第一爪：一道 270° 的厚弧贴着地面从右扫到左（0.11 秒扫完；压暗的带子里三道并排的熔岩红爪痕，扫过去的那一头收成尖，外沿一道熔铁的亮边；fx2a 的叠加月牙在青绿地面上发白，第二轮改成自己的预乘透明弧），地上一圈弧形刮痕（烧红 0.3 秒后变暗），弧上甩出一圈火星；打中的每个目标一道切线方向的火星 + 一个小白芯 → 0.31 秒后第二爪从左扫回右（同样一套，刮痕稍大一圈）→ 回血：身上一团很淡的暖光、往上飘几点余烬。
- **E 炉吼**：起手（0.25 秒）面甲下透出炉火光，火星往嘴边收 → 吼：嘴前一闪（不亮）；贴地扇形热浪 0.3 秒推到 5.5 米（前沿最亮，后面两道细声纹，热区压暗、扫过留几道顺风的焦痕；扇形两边一道淡边线）；一层只带一点温度的暗烟贴着扇形往外涌、越涌越散；被吹起来的灰烬和火星（第一轮的立着的烟墙、嘴前两圈环、一口橙色热气在青绿地面上都发粉发白，去掉了） → 命中：被吼到的身上冒一小股黑烟，脚下一个断成三段的暗红烙印慢慢转（3 秒，就是易伤的时长）。
- **R 焚猎**：起手（0.35 秒）伏低（动作），脚下一圈火从一处点着、绕一圈烧满（半径 1.6），火圈上窜火舌；耳簇和眼缝两点亮，火星往身上收 → 起跳：脚下那圈火被蹬得往上一窜（矮火墙），扬土，→ 空中（0.54 秒，动作里有一段滞空）：身后一道火痕、每 0.13 秒一个暗红的残影、一路小火团烧成黑烟、火星 → 落地（最重的一下）：一闪、抖 0.1；一圈火墙 + 一圈土墙往外推，落点一块焦痕（裂缝里烧红）、面前三道大爪痕；目标脚下很矮的火柱（0.3 秒烧成烟）和一圈火舌；目标身上一道大爪痕、白芯、顿帧 0.06 → 锁定 6 秒：目标脚下半径 2.5 的火圈跟着走（墙根烧黑、火苗此起彼伏、三道爪刻度慢慢转，最后一秒淡出），火圈上偶尔窜火舌；卡兹到目标之间一道很淡的暗红热气线 → 锁定中击杀：目标身上爆一团余烬（火团 + 火星 + 黑烟），卡兹身上一道暖色的螺旋回血光 + 一圈环。

## 改了几轮

1. 第一轮：熔岩红叠加在青绿的地面上发粉（炉吼的扇形、焦痕、裂爪的月牙），扬土像一团团棉花，扑落地把头插进目标里。
2. 第二轮：贴地的图案和爪痕改成发光的地方也压暗地面（预乘透明里 a 加上 0.6 倍亮度）；裂爪改用自己的三道爪痕弧；扬土变淡变小；扑落在普攻够得着的地方。
3. 第三轮：焦痕的裂缝公式写反了（整片亮、缝是黑的），改对；炉吼去掉立着的烟墙和嘴前的环；焚猎空中的残影太密、叠在身上整只猫发红，拉开变淡；灼烧的火舌被托尔格的龟壳挡住，按身高抬高。
4. 第四轮：扑跃身后加一道火痕（fx2c 弹道光），起跳的影子推后；裂爪的爪尖收尖；个头按调度定的 2.8 米重录。
