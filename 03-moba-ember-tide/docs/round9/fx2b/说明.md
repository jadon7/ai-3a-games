# fx2b · 摩珂、奥森技能特效第二轮的证据

| 文件 | 是什么 |
|---|---|
| `参照.md` | 每个技能参照了谁的什么、改后的分镜 |
| `对比_<英雄>_<键>.jpg` | 每个技能一张：上一行改前、下一行改后，各 10 帧（按对局时间取，左上角是按键以后第几秒）。测试场、固定机位，改前改后同一个机位、同一个瞄准点 |
| `录像/<英雄>_<键>_改前.mp4`、`_改后.mp4` | 每个技能改前、改后各一条，真实速度，30 帧每秒（按对局时间停帧截的，帧的时长按对局时间算，所以不受无界面 Chrome 帧率的影响） |
| `录像/<英雄>_<键>_对比.mp4` | 左改前、右改后，同一段并排 |
| `总表.jpg` | 两个英雄 8 个技能改后各挑一帧 |
| `raw/` | 原始帧（`before_*` 是在主目录 5190 服务器上截的 phase9 现状，`after_*` 是本分支）和每帧的对局时间 |

怎么截的：`tools/fx2_cap.mjs`（测试场 `arena=1`、`cam=` 固定机位、`vig=0`，左上角的调试按钮藏掉），`tools/fx2_evidence.py` 拼图和合成录像。
摩珂 Q、W 的机位带了 `hide=brush`：测试场里己方的靶子站在草丛里，草会把被奶的人整个挡住（改前改后一样处理）。

## 回归（本分支，测试服务器 5205）

| 项 | 结果 |
|---|---|
| `npx tsc --noEmit -p .` | 无报错 |
| `click_test.mjs` | 和动手之前（分支起点 56847f2，临时开在 5215 上跑的）一致；第一遍“点小地图后还跟着英雄”是 true，截图看是前面的 Esc 打开了菜单挡住了小地图（测试本身的时序问题），重跑一遍和起点一致（false），“自己水晶没了以后”起点和本分支都偶尔取不到“失败”（时序） |
| `touch_test.mjs` | 和起点一致：全部是 true、报错为空（掉血、走了几米这类数值每次略有不同） |
| `match_batch.sh` | 跑了两轮（moko、osen 各两局）：都分出了胜负，errors 为空 |
| `npm run build` | 能打出包 |
| 帧率 `fps_fight.mjs`（观战团战，1920×1080） | 电脑档 最低 60 / 平均 60；手机档（`touch=1&q=lite`）最低 56 / 平均 60 |
| 帧率（测试场里连放奥森、摩珂的 R E W Q W Q，1920×1080） | 电脑档 平均 59～60，四次里两次有一下掉到 50（再测一遍同样的连招两轮都是 60，没复现）；手机档 最低 60 |

注意：主目录 5190 上的 phase9 在 00:16 合并了手感任务（前摇、右键操作），所以 5190 上跑的点击回归和本分支不可比；“改前”的录像和帧都是在 00:16 之前截的（和本分支起点是同一份代码）。
