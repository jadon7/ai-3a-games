# 手感测量（第 2 条）：改之前、改之后

测量脚本 `tools/feel_measure.mjs`（测试场 `arena=1`，英雄满级；对局按 0.5 倍速走，在规则的每一步之后逐帧采样，时间都是对局时间，分辨率约 0.008–0.017 秒）。
原始数据：`base/measure_before.json`（改之前，分支起点 90fea31 的代码）、`after/measure_after.json`（改之后）。表由 `tools/feel_table.py` 生成。

## 目标值（照 LoL / 王者荣耀的惯例定）

| 项目 | 目标 | 怎么做到的 |
|---|---|---|
| 移动 | 下命令下一帧就动，没有加速过程；按停下一帧就停 | 原来就是这样（量出来 ≤0.02 秒），没改 |
| 掉头 180 度 | ≈0.1 秒，转的同时就在往新方向走 | 转身速度 13 → 26 弧度/秒（出手时 22 → 45）。位移本来就不等转身 |
| 普攻前摇 | 攻击间隔的 15%–25% | 默认 20%（`preK`，最短 0.1 秒）。出手前快放、出手后原速收招 |
| 普攻后摇 | 出手以后能被移动取消；前摇里被打断这一下不算、攻击计时退回 | 原来就能取消；新增“取消前摇退回计时” |
| 每秒伤害 | 和原来一样 | 出手间隔仍是 1/攻速（连打 6 秒平均间隔改前改后一致） |
| 技能前摇 | 普通 ≈0.25 秒，大招 ≤0.4 秒，位移、开关 ≈0.1 秒 | 每个技能在 `public/assets/hero/<id>.json` 里写 `pre`（秒）；出手前快放（最多 2.6 倍，再快就从片段中间起播，0.06 秒过渡接上），出手后原速 |
| 技能后摇 | 出手以后能被移动、普攻、别的技能打断 | 新增：出手后的收招不再锁人 |
| 排队 | 前摇、冲刺、技能接管、眩晕时按的移动 / 普攻 / 技能不被吞掉，一能动就执行 | 新增一格队列（后按的顶掉先按的；技能 1.5 秒内有效）；引导技能的前摇里点的移动作废（不然一出手就被自己点的那一下打断） |
| 鼠标 | 右键按下就走（不等松开） | 右键移动 / 攻击，按住右键拖着走；左键只确认技能和拖镜头 |

各技能写进 json 的 `pre`：岚 Q 0.2、W 0.1、R 0.25；托尔格 Q 0.25、W 0.15、R 0.25；摩珂 Q 0.25、W 0.15、E 0.3、R 0.35；葛隆 Q 0.12、W 0.15、E 0.3、R 0.35；薇萝 Q 0.3、E 0.3、R 0.25（W 原来就 0.07，不动）；奥森 Q 0.25、W 0.3、E 0.25、R 0.4。

## 说明几个看着奇怪的数

- “按下到第一下伤害”：弹道、落点技能要飞或者要延时，所以比出手晚；摩珂 E、葛隆 R、薇萝 R 改之前的这个数比出手还早，是上一个技能留在地上的伤害区（火油、余烬）先打到了靶子，不是技能本身。
- “不下命令时被锁住多久”是“什么都不按、动作自然播完回到站立”的时间，收招动作还是播完整的；真正决定手感的是下一行“一直点移动多久开始走”，改之后都 ≈ 出手时刻。
- 岚 R（2.27 秒）、托尔格 R（1.31 秒）、葛隆 W（引导 2.5 秒）、薇萝 R（引导 3 秒）是技能本身的持续时间（连斩、跃起落地、举盾、齐射），不是前摇，没缩。引导技能点移动会打断引导（LoL 的规矩），所以“一直点移动”那一列它们很早就开始走了。
- 岚的“技能前摇里点小兵，打了”是“否”：钩中以后岚会被拉过去并自动普攻钩中的那个目标，盖掉了排队的普攻，属于技能本身的设计。
- 鼠标那两行是真实时间（对局 1 倍速）：按下停 120 毫秒再松开。改之前左右键都要等松开（≈130 毫秒）；改之后右键按下的下一帧就走（≈15 毫秒），左键不再走路。

## 跑步动画和地面速度（滑步）

`tools/foot_slip.mjs`：直线跑 1.5 秒，看脚踩地那几帧脚在地面上还在走多快（滑步比 = 脚的速度 / 移速）。踝骨（mixamo 的 Foot、四足的腿末节）中位数：岚 −0.05、托尔格 −0.03～0.10、摩珂 0.03（另一侧 0.31，样本少）、葛隆 −0.06～−0.01、薇萝 −0.01、奥森 −0.05～0.07。脚尖骨骼有滚动、波动大，不算。
结论：现有的 `runSpeed` 基本对得上（多数在 ±10% 内），这一轮没改。

## 镜头跟随

跟随的收敛速度从 7 提到 16（时间常数 0.14 → 0.06 秒），跑动时镜头落后人约 0.4 米（原来约 0.9 米）。
