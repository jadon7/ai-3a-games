烬与潮 · 阶段 2.8 · 水面、光影和收尾

旗和火盆加上了，地图收尾

先做了你要的旗帜和火盆，然后是 2.8 的收尾：粼光铺到了所有水面，查了一遍发光的东西，把绘制次数降下来，全图巡检了十二个位置并修了查出来的两处问题。这是地图阶段的最后一关。手机只在电脑上模拟了屏幕尺寸，没有上真机。

全图

旗帜和火盆

六个口子，每个口子两面旗、两个火盆。旗立在两根门墩的顶上，随风轻轻摆；火盆坐在台阶底下两侧护墙的方墩上。

我方

深青底、金边、一弯新月的燕尾旗。火盆是青铜盆里几颗小晶体，是灯不是火（发光只用阵营色，我方是青色）。

对方

暗红底、铁边、一团火的燕尾旗。火盆是铁盆里一堆余烬加一小簇火苗，火苗会忽大忽小。

发光

只有盆里那一点亮，外面一圈很小的光晕，没有加照亮周围的灯。

粼光铺到所有水面

你最早说过河面上细碎的反光好，希望更多水面有。河道和两个 Boss 潭本来就是这一套；这一关把出生点的水池、流下台阶的水道、水晶脚下那圈水槽也换成了同一套。对方那边是余烬槽，不是水，没有粼光。

发光预算

你说过光污染严重。现在整张图会发光的东西只有下面这些，都只用阵营色（我方青、对方橙红），没有全屏的辉光。

发光的东西数量怎么亮
防御塔顶的晶体和塔身缝里的芯18 座晶体自己亮，外面一个小光晕
水晶，和它四角的小灯柱2 座同上，光晕大一号
出生点（我方是拱门上的晶体，对方是火盆坑）2 处一小块
口子上的火盆12 个盆里一点亮，对方有火苗
真正照亮周围的灯4 盏每一帧分给离镜头最近的四处，其余不照亮周围

地面、植物、墙、杂物都不发光。水面的粼光是反光，不是发光。

做了什么

  • 每件建筑原来是几十个小网格，现在不转的部分按材质并成几个，全图的绘制次数少了四成。
  • 给水面算水深的那张图换了一种存法：原来的存法在不少手机上不能用。
  • 触屏可以两指捏合缩放。
  • 页面一打开先显示“正在搭地图”，不再是一两秒的黑屏。

全图巡检

用游戏镜头在十二个位置各看了一遍：三条路的塔位、河道两头、两个 Boss 潭、两方野区。查出两处问题，都修了。

整个地图阶段留下的问题

这是地图的最后一关，把 2.3 到 2.7 各关我自己列过、到现在还没解决的问题汇总在这里。

画面上的

  • 对方的三档塔不够厚重，对方水晶的铁爪偏瘦。
  • 晶体是纯色的切面体，没有内部的层次。
  • 城墙外的树是圆鼓鼓的叶团，比设计稿简单。
  • 地面的清晰度比样板间低一档；野区的土路是染的，不是画的。
  • 地图里没有大块的树影。
  • 广场上的徽记铺地没做；石头脚下的蕨和小花没做。
  • 没有昼夜。

要等后面阶段的

  • 挡路的范围：台阶两侧的护墙、塔的台基、水晶的灯柱、出生点的石像、倒木和树桩，都没有和布局逐个核对。阶段 4 做寻路前要同步。
  • 没有英雄和小兵：台阶怎么走、草丛能不能藏人、对方深色广场上角色看不看得清，都要到阶段 3 才能验证。
  • 旧的两版地图代码（src/world/）还在项目里，没有删。

没验证的，和花费

  • 真手机没有测，只模拟了屏幕尺寸。
  • 快速拖动镜头时，近处的地面细图来不来得及加载，没有测。
  • 内存占用没有量。
  • 真实浏览器只在较小的面板里测过（1320×628，60 帧）。
  • 这一关没有用即梦、Tripo、Codex。
  • 代码没有提交（项目不是 git 仓库）。
