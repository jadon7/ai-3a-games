整张图的墙、台阶和山，立起来了

这一关把整张 156 米的地图第一次用正式的做法搭出来，只看一类东西：墙、山体、高低和它们之间的连接。地面先用平涂的布局图顶着（2.5 才画），草丛和树没有（2.6），防御塔、水晶、出生点是白色的占位模型（2.7）。画面里立着的白色小人是两米高，用来看比例。最后一节是你中途交代的 Codex（GPT 6.2 Astra）建模试验。

逐项看

有设计稿的放设计稿对照；没有设计稿的（城墙、山崖、Boss 潭）我照 2.2 定的规矩和王者荣耀的结构做，下面写明。

一、基地高地的挡墙和口子

  • 挡墙从外面看三米八：墙脚石、两层大料石、一道齐着广场地面的腰线、女儿墙、出檐的压顶。从广场里面看只有齐胸高。
  • 口子是八级台阶，每级高 0.3 米，和兵线一样宽。两侧是一级一级矮下来的护墙，收在方墩上；墙线上立两根八角门墩，带铜箍和嵌铜片。
  • 和设计稿的差别：设计稿的墙更白、门墩上有旗、台阶底下有半圆的铺地。旗和铺地分别是 2.7、2.5 的事。墙在这个角度背光，所以显暗。

二、野区的墙，铺到了全图

  • 样板间里认可的那套墙（弧形墙身、墙脚石、两层错缝料石、压顶、八角墩柱、青铜卡子、大石头、残墙）铺到全图，每方 26 段，一共 52 段。
  • 营地窝在弧形墙围出的凹口里，地面是踩秃的土。墙脚有一溜矮草，墙顶有苔和阔叶草。
  • 草丛这一关没有，所以设计稿里墙边的高草现在是空的。

三、地图边缘的城墙和墙外的山

  • 城墙三米六高，绕地图一圈，隔十来米一根墩柱；上高地的地方和基地的角上是大墩。两方各用自己的石材。
  • 墙外的地面一路往上。城墙后面隔一段冒出一组山石，高矮错开、平顶长苔，从墙头上露出来。
  • 河道两头（左上角、右下角）不砌墙，换成前矮后高的两排山崖把角堵住。
  • 这一项没有设计稿，是照规矩做的。山石现在只有形状和一种石头材质，没有岩层的纹理。树在 2.6。

四、Boss 潭和河边

  • 潭比河道深，中间是露出水面的石台；两岸各一道弧形墙把它围成一个坑（墙在画面外）。
  • 河道两头挨着边路的地方，有三级弧形石阶从路边走进水里。
  • 石台现在是一块平的灰石，表面的画法要等 2.5。

五、出生点的台子

  • 只做了高低：比广场高三级弧形台阶的台子，背靠地图的角，角上一座大墩。
  • 设计稿里的拱门、雕像、水池、水槽都是 2.7 的建筑，这里是白色的占位。

Codex 建模试验（GPT 6.2 Astra）

你中途说让 Codex 并行建个模看看。我给它的任务是：照同一张定稿的设计图，自己建我方外塔（不许用图转 3D）。它用了大约 18 分钟，改了 4 轮，交了一个 12.6 万三角形、3.8MB 的模型。下面第一张是它自己渲染的对照，后两张是我把它的模型放进样板间，和我用代码拼的那座塔在同一个机位、同样的光下截的。

  • 形状上它明显更接近设计图：外翻成钩的爪、撇开的钟形底、雕出窗洞的石芯、带晶窗和卷纹的叶形肋，这些我那一版都没有做出来。
  • 放进游戏里的问题：石头是光滑的一整块白，没有石块的缝和手绘的笔触，和周围长苔的旧石头不是一家；卷纹是细线，游戏镜头下看不清；水晶偏蓝，我们定的是青色；塔身比我的细，远看存在感弱一些。
  • 我的判断：形状用它的，材质换成我们这一套（石块分缝、手绘石材、铜绿、青色），是目前最好的组合。2.7 做三档塔和水晶时可以照这个分工来。

还差在哪，没验证的

还差的

  • 地面是平涂的布局图，近看发糊，石板像拼布。这是 2.5 的事，这一关请不要按地面来判断。
  • 山石只有大形，没有岩层和裂纹的画法；城墙外面没有树，显得秃。
  • 高地的墙比设计稿暗、比设计稿素：没有旗、没有排水口这类小构件。
  • 野区的起伏很缓（高低在一米上下），俯视时几乎看不出来，压低镜头才明显。
  • 对方一侧沿用我方的造型，只换了石材和颜色，没有单独设计。
  • Boss 的石台是一块平的灰石。

没验证的

  • 帧率：应用内浏览器里默认镜头实测 60 帧（2232×1164）。拉远看全图只在无界面的 Chrome 里测过（1600×900，60 帧，约 123 万三角形）。手机没测。
  • 没有英雄和小兵走过台阶：台阶是八级硬台阶，脚下的走法到阶段 3 才能验证。
  • 口子两侧的护墙、河道两头的山崖、河边的石阶，都比布局里“能走的范围”多占了一点地方，没有逐米核对。阶段 4 做寻路前要把布局同步。
  • 页面一进来要算两秒左右的地形和墙，没有做加载提示。
