# 地图画面的规矩（阶段 2.2）

对着 Dota 2 的 7 张地形截图（`refs/dota2/terrain/`）和王者荣耀官网的峡谷全景图逐类看了一遍，写成下面的规矩。
后面 2.3 到 2.8 做任何素材之前先对一遍这份清单。用户的原话和上一版的教训在 `PLAN.md`。

## 一、地面

参考里：
- 地面是一张连续的画。草是底，石板是一块一块铺上去的，缝里长草。
- 路的边缘不是一条线：石板越往外越稀，最后几块散在草里。土路是软边。
- 明暗很收敛，没有突然变黑或变亮的斑块；大范围有很缓的冷暖变化。
- 重点位置有一块整的装饰铺地（阵营徽记），只有一块。

我们的规矩：
1. 全图一张地面，草或土是底，石板、土路都从底里长出来，边缘碎开。
2. 兵线过河的地方，路沉到浅水下面继续，水面连续地盖过去（用户点名要的）。
3. 地面上要有近看才有的小细节（草叶、石缝、细碎的高光），远看是整的。
4. 杂物和地面同一个色系，明度贴着地面，只放在墙脚、路边、建筑脚下，不撒在空地中间。

上一版错在：小块贴图平铺再叠一层手绘，地砖和草各是各的；杂物是另一套画风，贴在空地上。

## 二、墙

参考里：
- 王者：一段段窄长的矮石墙，圆润的大石块垒成，墙顶长草，彼此隔得很开。
- Dota 2：矮石栏的形状是雕出来的，一段墙两种材质（浅石加陶色的帽），端头有柱墩、火盆或旗子收住。

我们的规矩：
1. 墙是薄的一片，厚 2.2 米、高 3 米左右，不做成山。
2. 基地高地和地图边缘用砌出来的整墙。野区用砌墙的残段加圆润的大石块组合：石块压着墙的两头、填在缺口里。（用户定的。）
3. 一段墙最多两种材质。墙顶和石头上可以有矮草和苔，不做成一团灌木。
4. 端头要收：柱墩、包边、压着的石块，重要的口子上放旗或火盆。

上一版错在：用实心的树林和山体挡路，占了三分之一的地图，还让人以为能钻进去。

## 三、植被

参考里：
- 能藏人的草丛是成丛的高草，和地表的短草一眼分得开。
- 树是大叶团，亮面暗面各一块，颜色有变化（绿、粉、黄），长在够不着的地方当背景。
- 蕨、小花只在石头和建筑脚下点几处。

我们的规矩：
1. 看起来能藏人的植被，就必须真的能藏人。能藏人的只有草丛。
2. 草丛比人高、成丛、形状整，颜色比地面深一档。
3. 树只在城墙外面和够不着的地方，大叶团、两个面，不做一片片的碎叶。
4. 我方一侧的植被是青绿色，对方一侧是红褐色。

上一版错在：树叶又碎又亮；野区成片的树像草丛但进不去。

## 四、关键建筑

参考里：
- 防御塔是一个雕像一样的整形，浅石加一颗阵营色的核，脚下一圈圆形铺地。占地很小。
- 泉水是同心圆的浅石池，形状大而简单，只有水在发微光。
- 细节集中在少数几处（徽记、核、帽），其余是干净的大面。

我们的规矩：
1. 每个建筑是一个大形加一个发光的重点。
2. 要有层次：底座、身、颈、冠分清楚。外壳（青铜肋片、铁肋片）包着石芯，缝里透出核的颜色。雕饰要细。（用户认可的样子是 `art/concepts22/ref_liked_tower.png`。）
3. 材质不超过三种。我方：浅灰白石、铜绿青铜、青色水晶。对方：深灰玄武岩、暗铁和赤陶、橙红余烬。
4. 三档防御塔是一家的，由矮到高、由简到繁，俯视时一眼分得出。
5. 水晶是终极目标，要比塔隆重得多：高约 13 米、底座约 12 米；地面图案、多级台基、半包着核的托座、悬浮的环或碎片、四角的小灯柱，一层层往上。
6. 出生点和基地一角一起设计：背靠地图角上的大型建筑，用台阶、水槽和铺地跟水晶广场连成一体，不做成孤立的圆盘。
7. 建筑和地面要有对应关系（用户特别提醒的）：塔脚下一圈同心圆地砖，水晶下面放射状的铺地，出生点的台阶和水槽。这些是地面的一部分，画地面的时候跟着建筑的位置一起画，缝里一样长草、边缘一样碎开，不是事后贴上去的一个圆。

上一版错在：图转 3D 直接出的模型，形碎、细节平均分布、风格偏旧。

## 五、水

参考里：
- 河水清、浅、能看见河底，颜色是通透的青蓝。
- 石阶直接走进水里，水边是软过渡，有睡莲、水草和几块石头。
- 水面有细碎的反光。

我们的规矩：
1. 水清澈见底，浅色。
2. 细碎的粼光铺到所有水面（用户点名说好的），出生点的水池也用同一套。
3. 路沉到水下继续，不用堤或桥把河切断。
4. 岸边软过渡，草丛和少量石头贴着岸。

上一版错在：只有一段河面有粼光；岸线泡沫画成了一条白线。

## 六、光

参考里：
- 白天是柔和的日光，影子清楚但不黑，画面通透。
- 发光的只有：泉水、塔和水晶的核、少数火盆。火是很小的一点。
- 没有满屏的光晕。雾只在边缘和低处有一点。

我们的规矩：
1. 发光有预算：出生点、水晶、防御塔的核，加上基地口子上的少数火盆或灯。地面、植物、普通杂物一律不发光。
2. 发光只用阵营色：我方青色，对方橙红色。
3. 辉光半径小，只让核本身亮，不把周围染一大片。
4. 影子是画面层次的主要来源：墙、塔、草丛都要有清楚的落影。

上一版错在：地面裂纹、植物、杂物都在发光，颜色又多又亮。
