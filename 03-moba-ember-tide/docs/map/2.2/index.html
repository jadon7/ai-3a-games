防御塔：一家三档

把你认可的那座塔裁出来当参考图交给 Codex，让它沿用同一种语言画出外塔、内塔、高地塔。由矮到高、由简到繁，灰色小人 2 米高。下面两张特写是即梦按同样的描述画在场景里的高地塔。

水晶：终极目标

我看了 Dota 2 的遗迹、英雄联盟的水晶枢纽、王者荣耀的水晶。它们的共同点：比塔大两三倍；地面图案、多级台基、托座、核、悬浮物一层层往上；核被建筑半包着，从缝里透光；周围有小柱或雕像呼应。按这些重新设计，造型是自己的。

出生点：和基地一角一起设计

出生点不再是一个单独的圆盘。它背靠地图角上的城墙和大型建筑，用台阶、水槽和铺地跟十几米外的水晶连成一体。每方两个方案：一个是抬高的平台，一个是嵌在地面里的浅池。

六类规矩

左边是 Dota 2 截图里的局部。完整的文字版在项目的 docs/map/2.2/rules.md，后面每个小阶段做素材之前先对一遍。

地面

参考里

  • 地面是一张连续的画，草是底，石板一块块铺上去，缝里长草。
  • 路的边缘不是一条线。
  • 明暗收敛，没有突然变黑变亮的斑块。

我们的规矩

  • 全图一张地面，石板和土路从底里长出来，边缘碎开。
  • 过河的地方路沉到浅水下面，水面连续盖过去。
  • 杂物和地面同色系，只放墙脚、路边、建筑脚下。

墙

参考里

  • 王者：一段段窄长的矮石墙，墙顶长草，隔得很开。
  • Dota 2：石栏的形是雕出来的，端头有柱墩、火盆或旗。

我们的规矩

  • 墙是薄的一片，厚 2.2 米、高 3 米左右，不做成山。
  • 基地高地和地图边缘用砌出来的整墙；野区用砌墙的残段加大石块组合。
  • 一段墙最多两种材质，端头要收。

植被

参考里

  • 能藏人的草丛是成丛的高草，和地表的短草一眼分得开。
  • 树长在够不着的地方当背景。

我们的规矩

  • 看起来能藏人的植被，就必须真的能藏人。能藏人的只有草丛。
  • 草丛比人高、成丛、形状整。
  • 树只在城墙外面，大叶团，不做碎叶。

关键建筑

参考里

  • 塔是一个整形加一颗阵营色的核，占地很小。
  • 泉水是同心圆的浅石池，只有水在发微光。
  • 细节集中在少数几处。

我们的规矩

  • 一个大形加一个发光的重点，底座、身、颈、冠分清层次。
  • 外壳包着石芯，缝里透出核的颜色，雕饰要细。
  • 三档塔是一家的，由矮到高、由简到繁。
  • 水晶比塔隆重得多；出生点和基地一角一起设计。

水

参考里

  • 水清、浅、通透，能看见河底。
  • 路直接走进水里，岸边是软过渡。
  • 水面有细碎的反光。

我们的规矩

  • 清澈见底，浅色。
  • 细碎的粼光铺到所有水面，出生点的水池也用同一套。
  • 不用堤或桥把河切断。

光

参考里

  • 日光柔和，影子清楚但不黑。
  • 发光的只有泉水、塔和水晶的核、少数火盆。
  • 没有满屏的光晕。

我们的规矩

  • 发光有预算：出生点、水晶、塔的核，加基地口子上的少数火盆。地面、植物、杂物不发光。
  • 只用阵营色：我方青色，对方橙红色。
  • 辉光半径小。层次靠影子。

这一稿请你看的

  • 三档防御塔的层次和精细程度够不够，两方各自像不像一家。
  • 水晶每方两个方案选哪个，够不够隆重。
  • 出生点每方两个方案选哪个，和基地结合得够不够。
  • 野区墙体加石块的组合对不对。
  • 我的建议：水晶两方都用 A，托座都是往上合拢的形，是一家；出生点两方都用方案一，抬高的平台从俯视镜头看更醒目，水槽把它和水晶连得更紧。

这些图是什么、不是什么

  • 都是 AI 出的设计稿，用来定方向，不是游戏里的画面。
  • 游戏里能不能做到，2.3 的样板间见分晓。关键建筑的精细建模在 2.7。
  • 场景图里建筑之间的距离和灰盒不完全一致，以灰盒为准。
  • 对方一侧的赭红地面铺满半张图以后会不会太艳，要到样板间里看。
