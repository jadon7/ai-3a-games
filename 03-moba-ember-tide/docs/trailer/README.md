## 怎么做的

### 录素材：逐帧的虚拟时间录制（`tools/trailer/cap.mjs`）

没有用项目里现成的实时录屏（`tools/rec_clip.sh`）：无界面 Chrome 实时录屏只有二十帧上下。`cap.mjs` 在页面一打开就把
`performance.now` 和 `requestAnimationFrame` 换掉：开录以后，脚本每次把页面的时间往前推 1/30 秒、让游戏画一帧、截一张图，
直接拼成 30 帧的 mp4。截图慢（1920×1080 大约每秒 8 帧），但每一帧都是准的，画面是真正平滑的 30 帧，慢放也平滑。

开录之前和 `rec_clip.sh` 一样，先按 16 倍速快进到条件成立。主要选项（详见脚本开头的注释）：
`cond` / `cond2` 开录条件、`pre` 开录前执行的 js、`at` 录到某秒执行 js（放技能）、`hold` 每帧按住 Q/E/A/D 一小段时间（空镜的匀速转动和平移）、
`speed` 录的时候对局几倍速、`log` 每帧记一个表达式（找击杀、找打架）、`real` 开录前按真实时间执行的步骤（预热技能特效的着色器）。

几个只在录像脚本里做、没有改游戏的调整：

- 观战镜头：网址带 `cam=0,0,0,46` 把俯角从 56° 压到 46°（导播只管位置、距离、朝向，不管俯角）；再把 `__director.update` 包一层，
  导播给的镜头距离乘 0.72，英雄在画面里大一些。
- 水晶那一镜：直接替换 `__director.update`，让镜头一直看着血最少的那座水晶、匀速转；网址 `cam=` 的第五个数把看的点抬到离地 4 米。
- 测试场：隐藏左上角的调试按钮；英雄升满级；每个技能先按真实时间空放一遍再录。

### 重新录全部素材

```sh
# 服务器要在 5190 上（MOBA_URL 默认就是 http://localhost:5190/map.html）。一段一段录，不能并行（抢显卡会白屏）。已经录好的会跳过，带 FORCE=1 重录。
zsh tools/trailer/rec_all.sh      # 空镜 e_*、观战 h0/h1/h2/h_end、技能 s_*、手机 m_phone
zsh tools/trailer/rec_more.sh     # Boss b_beast/b_troll、拆塔 t_tower、兵线 l_clash、敌方水晶空镜 e_coreE2、水晶 h_end2…h_end9、带爆炸的拆塔 t_tower2
zsh tools/trailer/rec_three.sh    # 打野 j_boar、薇萝 s_vero2
```

观战是电脑对打，每次录出来的对局都不一样，换了素材要重新挑入点（`python3 tools/trailer/seglog.py docs/trailer/raw/h1.log.json`
按“导播在看什么 / 击杀数 / 剩几座塔”分段；`python3 tools/trailer/sheet.py <视频> <输出前缀> <间隔秒>` 出带时间的联系表）。

成片实际用到的素材：`e_aerial e_tide e_ember e_river h0 h1 h2 b_beast j_boar s_torg s_lan s_gorran s_moko s_vero2 s_osen t_tower2 h_end9 m_phone`。
录了但没用的：`e_coreT e_coreE e_coreE2 h_end h_end2…h_end8 b_troll t_tower l_clash s_vero`（原因见下面“没用上的素材”）。

### 平面和剪辑

```sh
python3 tools/trailer/cards.py    # 英雄立绘卡（逐帧 PNG）、标题、字幕、技能小字、落版、手机外框 → docs/trailer/raw/cards/
cd tools/trailer && python3 edit.py   # 按 edl.py 的剪辑表切段（docs/trailer/raw/seg/）、叠字、接片，出 trailer.mp4 和 trailer_web.mp4
```

剪辑表在 `tools/trailer/edl.py`，每一行一个镜头：素材、入点、时长、和下一个镜头之间叠化几秒（0 = 硬切）、叠层、压暗。
转场只有硬切和叠化；游戏画面没有加任何后期推拉，镜头的运动都是游戏里录出来的。

## 没用上的素材和原因

- `j_camp`（等导播看小野怪营地）：导播几乎不专门看小野怪，十五分钟等不到，改成单人对局里自己去打（`j_boar`）。
- `s_vero`（薇萝大招 连弩齐射）：箭很细，在画面里看不清，换成火油罐（`s_vero2`）。
- `t_tower`（导播在看的塔只剩两成血）：塔倒的一下只有一秒多就被别的东西挡住，换成 `h2` 里的一段。
- `l_clash`（第三波兵在中路相撞）：只有一个英雄和几个兵，画面太空。
- `b_beast`、`b_troll` 都没录到 Boss 倒下；`b_troll` 整段没用，巨魔用的是 `h2` 里的一段。
- `h_end`…`h_end6`：游戏加爆炸效果之前录的水晶（三十秒内没打下来 / 开录时已经碎了 / 镜头不在水晶上 / 水晶上半截出画 / 碎得没有过程）。
- `h_end7`：开录后进攻方撤了，水晶停在 139 血没碎；`h_end8`：爆炸拍到了，但碎的是沉月会的水晶，和前一镜（拆烬誓庭的塔）对不上，换成 `h_end9`。
- `h2` 里的旧推塔（第 7.8 秒起）：游戏加爆炸之前录的，换成 `t_tower2`。
- `e_coreE`：前景被橙色的树挡住；`e_coreT`、`e_coreE2` 录了没用上。

## 录素材时发现的游戏问题（没有改，记在这里）

1. （2026-11-19 已修：现在会炸开，结尾两镜已重录）防御塔、水晶被拆掉时没有倒塌或爆炸的过程：一帧之内模型直接换成残座，只有一圈碎屑和一个冲击环。水晶作为一局的结尾，画面上不够“爆”，
   片子里只能在它碎掉的那一下切走。
2. （开发方复核：英雄会回到待机动作，确实停住的是小兵）分出胜负以后整局立刻定格（英雄停在半个动作里、特效也停住）。平时有结算界面盖着看不出来，`nohud=1` 的观战录像里很明显。
3. （2026-11-19 已修：镂空现在跟着导播的镜头走）观战（导播）时，挡住英雄的建筑镂空只对“自己的英雄”（网址里 `h=` 的那个）生效；导播去看别人的时候，墙和塔会把人整个挡住
   （在 46° 俯角下 `h1` 第 24–28 秒整整四秒只看到一堵墙；默认 56° 俯角也可能出现，只是少一些）。
4. （2026-11-19 已修）导播会长时间停在一个英雄单挑 Boss 的画面上（`h2` 里有一段 35 秒都是托尔格一个人打岩甲巨兽），观战的节奏会很拖。
5. 导播几乎不看打小野怪（打分比对线还低），观战里看不到打野。
6. 用 `cam=` 参数时，分出胜负后镜头不会移到碎掉的水晶上（代码里有意跳过了，属于参数的副作用，不算错，记一下）。
