和 Dota 2 并排

我自己看出来的差距

  • Dota 2 的英雄更粗壮、色块更大，一眼是两三块颜色。岚是瘦长的身材，细节多（腰间的网、皮带、挂钩），缩小以后偏碎。
  • Dota 2 的英雄比地面亮。岚穿的是深色，身体的明度和地面差不多，靠蓝色和地面的色差、骨白的刀和护甲、青色的纹路来区分。
  • 贴图是生成的，近看腰间的网和皮带有些糊。
  • 头冠和设计稿一样高，但在俯视镜头下不够显眼。要不要再拉高，等你看了定。

为了看得清做了什么

  • 身高定成 2.7 米（地图比例用的小人是 2 米）。
  • 头放大 18%，手和刀放大 30%。俯视镜头下头和武器是最先被认出来的。
  • 深色的衣服提亮了一些；加了一盏只照英雄的补光。
  • 背光一侧有一道冷色的亮边，把轮廓从地面上托出来。
  • 青色的纹路自己会亮，没有另外加灯。

队伍怎么分

  • 脚下一个细圈、头顶一条血条：我方绿，对方红。
  • 血条现在只是占位，正式的到阶段 4 做。

怎么做的

模型和骨骼

用设计稿直接转成 3D，再自动绑上骨骼（65 根，标准的人形骨架，后面的动作管线可以直接用）。模型约 3.9 万个三角形。

钩刃

单独转的 3D。背面多生成了一片贴着的碎块，脚本里按刀身的中线把它切掉了。两把刀挂在左右手的骨骼上，手指握拳、拇指压住。

站姿

不是一根一根调骨骼，而是写明“脚踝在哪、手腕在哪、刀指向哪”，由脚本算出各关节的角度。带一个 3.2 秒的呼吸循环，首尾接得上。这只是临时的站姿，正式的待机动作在下一步做。

阶段 3 接下来怎么走

小阶段做什么你看什么
3.1（这一步）模型、钩刃、骨骼、站姿，放进地图像不像设计稿，游戏镜头下看不看得清
3.2 动作训练这个角色专用的动作识别（约 1 小时），做待机、跑步、普攻、两个技能、死亡六段动作一个动作预览页
3.3 进游戏点地面移动和寻路、动作之间的衔接、木桩、普攻和两个技能在地图上跑、打木桩、放技能

没验证的，和花费

没验证的

  • 只在不显示窗口的浏览器里截图看过（1920×1080，60 帧），没有在你平时用的浏览器窗口里看。
  • 这个模型还没有过动作管线：训练识别、读回动作准不准，都是 3.2 的事。腰间的网和前后的布片会不会影响识别，现在不知道。
  • 跑步这类循环动作接不接得顺，计划里一直标着没验证，也要到 3.2。
  • 手机没有测。

近看的小问题

  • 握刀的手指和刀柄有一点穿插。
  • 站在水里时，小腿以下没有做水花和湿边。
  • 站姿只有一个，左右手的刀一高一低是写死的。

花费

  • Tripo：模型 40、钩刃 40、绑骨 25，共 105。余额 595。

  • 没有用即梦和 Codex。
  • 代码没有提交（项目不是 git 仓库）。
