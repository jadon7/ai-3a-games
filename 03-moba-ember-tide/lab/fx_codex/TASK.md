## 要做的两个特效

### 一、R · 绯月千刃（连锁闪现 + 十字新月斩），整段约 1.5 秒

技能：指定一个落点，伊缇消失、不能被选中约 1 秒，在落点 6 米内的敌人之间来回闪砍，最多 6 下（优先英雄），最后回到中心，一道**巨大的十字新月斩**炸开（中心 3 米内伤害更高）。

试验页里：落点是原点 (0,0)；伊缇（占位）站在 (-5.2, 2.9)；靶子是两个敌方英雄（摩珂 3.3 米高、托尔格 2.8 米高）和四个近战小兵（1.45 米高），都在 6 米内（`main.ts` 的 `SPOTS`）。

我想要的分镜（时间、大小是目标值，你可以在这个范围里调得更好看；**整体要帅、有张力**）：
1. **起手（0～0.12 秒）**：双刃上一点绯红的亮（预兆），人一缩消失（`cast.setHide(1)`），原地留一个绯红的半透明残影，一道细的闪线射向第一个目标。
2. **连闪（约 0.12～0.95 秒，6 下，每下 0.12～0.15 秒）**：每一下伊缇在目标身边（身后或侧面）出现一瞬（可以只出现残影，人不必真的显形），砍一刀：
   - 一道绯红的新月刀光（半径 1.6～2.2 米，细而锐，刃口一道暖白，身子绯红到品红，外沿拖细丝），方向每下都变；
   - 目标身上一个硬边的命中星（两三阶色），`target.hit()` 闪白；
   - 前后两个落点之间一道直的闪线（暖白芯、绯红边，很细），**留在地上不马上消失**——6 下打完，地上是一张绯红的“刀网”，把张力憋住；
   - 每个落点留一个绯红残影，0.25～0.35 秒淡掉。
3. **蓄（约 0.95～1.05 秒）**：伊缇回到中心显形（`cast.setHide(0)`，可以播 `r_end` 动作），一瞬间往里收（刀网的线、碎光往中心吸，或者中心一点亮起来、周围压一层深绯的暗——不是黑），给爆发一个停顿。
4. **十字新月斩炸开（约 1.05 秒）**：
   - 两弯交叉成 X 的巨大新月刀气，每弯弦长约 9～11 米（从中心往两边各伸 4.5～5.5 米），0.1～0.15 秒内从中心扫开 / 长大；**有厚度**：暖白的芯、绯红到品红的身子、外沿细丝；斜着立起来一点（和地面成 20～40 度），这样俯视镜头下既看得出新月形、又有立体感；
   - 刀网在这一刻一起引爆（每条线亮一下、碎掉）；
   - 地面：一圈有厚度的冲击环（0.25 秒内从 0 扩到 6 米，两阶色的硬边带子，不是一圈模糊的光）；沿着十字方向的裂痕（暖褐 / 深绯的底，里面一道绯红的亮线，0.4 秒内冷下去）；
   - 少量赤金火星（点缀，不要一大片）；
   - 只有炸开的那一下（≤0.1 秒）中心最亮，范围小（半径 ≤1.5 米），**不要满屏泛白**；镜头抖一下（`ctx.shake`），可以加极短的顿帧（`ctx.hitstop`，≤0.06 秒）。
5. **收（1.15～1.6 秒）**：刀气不要匀速淡出，要碎掉 / 从边上被啃掉（硬边的溶解）迅速收；地上的裂痕和焦痕留到 2 秒左右慢慢淡完。

### 二、被动 · 烬痕引爆，炸开 0.5 秒以内

技能：伊缇的技能打中敌方英雄叠一层烬痕（最多 3 层，4 秒）；叠满 3 层的那一下引爆，目标身上炸开一朵**绯红的花形爆裂**。

试验页里：摩珂移到原点当目标，伊缇站在它左边，连砍三下（每下 0.4～0.45 秒），每下叠一层，第三下引爆。
1. **烬痕记号**：目标头顶三个小记号（比如三片小花瓣 / 三个菱形，排成一行或一个小三角），每叠一层亮一格：没亮是暗的槽（深绯的描边），亮了是绯红实色加一点暖白芯，亮起来那一下有一个小的弹跳。俯视 27 米下要看得清（每个约 0.25～0.35 米），**不能挡住头顶的血条**（血条在身高 + 0.62 米处，宽约 3.3 米、高约 0.7 米，是一张正对镜头的图；记号放在血条上面、或者血条和头之间都行，你在游戏镜头下看着定）。4 秒没有叠满就自己淡掉（演示里不用演）。
2. **花形爆裂**（第三下命中后立刻）：
   - 0～0.06 秒：目标胸口一个暖白的核心一闪（小）；
   - 0.03～0.2 秒：5～8 片尖瓣从目标身上（胸口高度，或者从脚下往上斜着）快速放射出去，最长约 1.8～2.4 米；**硬边的两三阶色块**（外层深绯、中间绯红 / 品红、芯暖白），瓣和瓣之间长短、角度错开，不要对称得像图标；
   - 0.2～0.5 秒：瓣碎成硬边的色块，缩小、往外飘一点、被啃掉；脚下一个小的硬边冲击环、几颗赤金火星；目标闪白，镜头小抖一下；
   - 三个记号在引爆时一起炸掉（被花吞进去）。

## 画风规矩（必须守）

- **颜色**（sRGB）：暖白芯 `#FFF3E6`；亮绯 `#FF4D7A`；绯红 `#E3134B`；品红 `#D9207F`（色相的变化，用一点）；深绯 `#7E0F2F`（暗的一阶、描边、垫底，代替黑色）；赤金火星 `#FFC34D` / `#FF9640`（只做点缀，不超过粒子数的一成五）。地上的痕迹用暖褐 / 深绯（比如 `#5E2420`、`#6E1A2C`，不透明度不超过 0.5），**不用黑**。
- **亮地面上怎么混合**：身子（有颜色的部分）用**普通混合**盖住地面，读得出颜色和形状；只有接近白的芯和刃口用叠加发光。游戏里的写法在 `src/map/game/fxb.ts`（`PREMUL` 预乘混合 + `bOut_`：越接近白越按叠加、越暗越有颜色越按普通混合），你可以照着写、也可以 import 它的 `PREMUL`、`deep`。**不要大面积叠加发光**：叠在亮草地上就是一片白。
- **发光只在核心那一下**：一个画面里接近白的部分要小、要短。主体是有颜色的半透明或硬边色块。不要满屏泛白，不要一圈圈模糊的光晕。
- **两三阶硬色块**：参考视频 `ref_03`～`ref_08` 那样，色块之间是清楚的边（着色器里用 `step` / 很窄的 `smoothstep` 分阶，再用噪声把边啃得有一点不规则），不是从中心到边缘一整片柔和的渐变。
- **干净**：形状成形（新月就是一道干净的新月，冲击环就是一圈有厚度的带子），少而精。用户最反感**杂、碎、光污染**；但这次也明确要“足够帅、有张力、有视觉效果”——帅靠形状、节奏、对比，不靠堆数量。
- 和场景搭：游戏是王者荣耀式的明快卡通厚涂（`docs/style_b/STYLE.md` 有完整的画风说明，可以看）。

## 性能（游戏里要用，手机也要跑）

- 一次特效（R 整段 / 被动整段）同时存在的绘制次数：电脑档峰值 ≤ 40，手机档（`ctx.lite`，网址 `q=lite`）≤ 20。试验页左下角和 `window.__lab.stats()` 会显示“特效占了几次绘制”（`fxCalls`、`peakFxCalls`），录像工具也会记下来。
- 粒子：电脑档同时 ≤ 300 个，手机档减半。粒子用一个 `THREE.Points` 或者一个实例化网格一次画完，不要一个粒子一个网格。
- 材质、几何体、贴图在模块里建一次、反复用（按需建好放在模块级的缓存里），**每次放技能不要新建着色器**（第一次编译着色器会卡一下）；`dispose()` 要把这一次放进场景的东西都拿掉，缓存的可以留着。
- 残影如果用模型的克隆（`three/examples/jsm/utils/SkeletonUtils.js` 的 `clone`），要提前建好、反复用，不要每一下现克隆。
- 贴图可以用代码画（着色器里算、或者画布画），不要用网上的素材；也不要调用任何在线生成服务。

- `fx/iti_r.ts`：R 的特效。拆成游戏里会分别触发的几块，比如 `blink(from, to)`（一下闪砍：残影、刀光、闪线、命中星）、`finale(center)`（蓄 + 十字新月斩 + 地面），每块返回 `FxHandle`（`update(dt)` 返回还在不在播、`dispose()` 收掉）。
