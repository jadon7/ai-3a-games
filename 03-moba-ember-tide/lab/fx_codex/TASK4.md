# 第四轮（最后一轮）：去掉“粉膜”和“贴纸感”

第三轮的 X 在游戏镜头下一眼就看出来了，蓄力的细环、四道光芒、贴地尖芒也都对，节奏好（谢谢）。`refs/fb4_*.jpg` 是我这一轮截的。
还剩两个毛病，这一轮只改这两处，其余保持第三轮的样子。**改一到两版就交**，不用做满四版。规矩、站位、时间框架、接口、性能上限照旧。

## 总原则：深绯边只放在背光的一侧

现在几乎每个形状外面都包了一圈细的深色描边，里面是一整块平涂的粉红，看起来像剪纸、贴纸（被动最明显）。卡通特效里的“能量感”来自：**能量源那一侧亮、没有描边；背离能量源的一侧才压深绯**。
- 刀：刃口一侧亮（暖白→亮绯），不描边；后沿压深绯。
- 花爆的团：中心最亮，往外一阶阶变深，最外一圈深绯；**里面的色阶边界用噪声啃得不规则**（像 `ref_04`、`ref_05` 的硬色块），不要一圈圈同心圆。
- 尖刺：根部（靠近爆点）暖白、不描边；往尖端变深，尖端和两侧压一道细的深绯（≤ 0.03 米）。

## R：两弯刀太宽、半透明的部分盖成一层粉膜

`fb4_R_第三轮_1.23秒_中镜头和游戏镜头.jpg`：两弯刀后面那两档半透明（0.6 和 0.3）连同尾流层很宽，再加上冲击环里面一层淡粉的底，1.17～1.40 秒中间那一大片人物（托尔格、伊缇）都被罩成粉色。目标：
1. 每弯刀弧中段**看得见的总宽度 ≤ 1.3 米**（含半透明档）；三档改成：实 45%（≥ 0.9）/ 0.5 占 30% / 0.2 占 25%；尾流层只在两头靠近刀尖的地方留一点（不透明度 ≤ 0.15），中段不要。
2. 冲击环里面的淡粉底去掉，只留那条带子。
3. 速度线减到 3 道，只画在实的那一档里；半透明档里不要有深色的细线（现在看起来像划痕）。
4. 量一下：1.20 秒中镜头那一帧，刀身没压到的地方人物和地面要保持原色；刀身压到的地方，实档能挡住，半透明档能透出下面的颜色。

## 被动：爆团像一张平的红色剪纸

`fb4_被动_第三轮_1.17到1.37秒.jpg`：1.17 秒的团是一整块平涂的绯红，只有中间一小块白，外面一圈细黑边；尖刺也是单色加描边。目标：
1. **爆团三阶硬色块**：中心暖白约占半径的 35%，亮绯 `#FF4D7A` 到 65%，绯红 `#E3134B` 到 92%，最外 8% 深绯；三条色阶边界都用噪声啃（振幅约半径的 8～12%），所以白和亮绯是几块不规则的色块，不是同心圆。暖白那一块可以按 `bOut_` 带一点叠加。
2. 爆团峰值半径从 0.9 收到 0.75 米；实心（把目标整个盖住）的时间 ≤ 0.06 秒，之后马上从中心破洞，0.15 秒时目标的身体要重新露出来。
3. 尖刺：根部 20% 暖白（不描边、可以带一点叠加）、中段亮绯、尖端绯红，尖端和两侧一道 ≤ 0.03 米的深绯；不要整根单色加一圈描边。
4. 头顶记号、引爆时机、地面的溅痕和小环保持第三轮。
