# 第三轮返工：让十字斩“像刀气、有冲击”，让花爆“有一团肉”

第二轮进步很大（谢谢）：“蓄”看得出来了（深绯的圆压下去、中心一点亮），两弯刀成了真正的新月、有分阶有尾流，冲击环是一条干净的带子，炸完地上有焦痕，被动从“叶子”变成了一蓬尖刺。`refs/fb3_*.jpg` 是我这一轮截的。
这一轮只改下面几处，其余保持第二轮的样子。规矩、站位、时间框架、接口、性能上限都和前两轮一样（现在 R 13 次绘制、28 个粒子，还有很多余量，可以用）。

## R

1. **刀还像一条不透明的粉红塑料带子，不像刀气**（`fb3_R终结_第二轮_中镜头_1.17_1.27_1.37秒.jpg`）。整条宽度上差不多一样实、一样粉，内部没有东西在动。目标：
   - **不透明度跟着宽度走、分三档硬边**：刃口这一侧 40% 宽实（不透明度 ≥ 0.9），往后一档 0.6、再往后一档 0.3，最后散进细丝；三档之间是硬边（像动漫里刀光的分层），不是一整片均匀的实色。
   - **刀身里加流动的速度线**：4～6 道顺着弧的细线（0.03～0.06 米宽，长短在弧长的 30%～70% 之间，亮的用 `#FF7A9A`、暗的用深绯 `#7E0F2F`，交替），扫的那 0.1 秒里沿着弧往前跑（UV 滚动），扫完以后慢下来。参考 `ref_10` 刀身里一道道的细纹。
   - **刃口更亮一点**：暖白刃口在弧中段加宽到 0.12～0.16 米，外面接一道 0.1 米的亮绯过渡；这一道可以按 `bOut_` 的方式带一点叠加（只这一道），让刀“有能量”。其余部分保持普通混合。
   - **主色往绯红靠**：现在整体偏粉（半透明盖在浅石板上发粉）。刃口那 40% 的实色区用绯红 `#E3134B` 为主，亮绯只做过渡。
2. **游戏镜头下只看得出“一弯刀”**（`fb3_R_第二轮_游戏镜头_后两行.jpg` 的 1.13～1.33 秒）：右下那弯又长又实，另一弯被压在下面、又细又淡，左边只露一截。目标：两弯分量一样（宽度、不透明度、长度一致），两条弦的夹角 80～95 度，交点离中心不超过 0.5 米；两弯同时扫（最多错开 0.04 秒），**在 1.15～1.25 秒的任何一帧里都要一眼看出是一个 X**。
3. **炸开时加一圈放射的地面尖芒，给冲击感**（参考 `ref_11` 的放射，但用我们的颜色和硬边）：1.05 秒起，8～10 根贴地的细长尖三角，从中心 1 米射到 4～6 米（长短错开，避开两弯刀的方向），根部暖白、身子绯红、尖端和两侧深绯；0.05 秒射出、0.12 秒从根部往外收掉。只这一下，不留。
4. **中心闪光像一张贴纸**（1.10 秒那颗白色四芒星是平的）。目标：四道细长的光芒（每道长 2.0 米、根部宽 0.12 米、渐细到尖），中间一个 0.5 米的暖白核心，外面一圈绯红；0.03 秒放大、0.05 秒收掉，转 10～15 度。只有核心和光芒的芯叠加发光。
5. **“蓄”中心那个白点像一个白球**（1.03 秒）。改成一颗小的四芒闪光（0.4 米）加一道往里收的细圆环（半径 2.5→0.3 米，0.12 秒，亮绯细线），读出来是“往里吸”。深绯压痕保留。
6. 闪砍阶段、冲击环、地裂、焦痕、收刀都保持第二轮的样子。

## 被动

1. **花爆没有“一团肉”**：现在是一圈细刺加一颗平的白星，像海胆。参考 `ref_04`、`ref_05` 里刺的周围有一大团硬边的色块。目标：在胸口加一团**正对镜头的动漫风爆炸团**：外形被噪声啃成不规则的硬边，三阶色（中心暖白 → 亮绯 `#FF4D7A` → 绯红 `#E3134B` → 外沿 0.05 米深绯 `#7E0F2F`）；0.06 秒内半径 0→0.9 米；然后从中心往外破出一个越来越大的洞（硬边），0.28 秒时整团被吃完。尖刺从这团里射出来。平的白星去掉（这团的白芯就是闪光）。
2. **尖刺**：竖直朝上的太多，像几根天线。仰角大于 65 度的最多 2 根，其余多在 20～50 度；根部宽度错开（0.15～0.4 米），三根最长的粗一些（根部 0.35～0.4 米），让爆裂有分量；在最长处停的时间缩到 ≤ 0.08 秒（现在约 0.2 秒不动，显得僵）；爆开后 0.40 秒内全部收完。
3. **第三下命中到炸开太慢**：现在第三下以后记号化成线往胸口走，约 0.15 秒以后才炸。改成 ≤ 0.08 秒（线 0.06 秒射进去）。射进去的三道线要有暖白的头、绯红的身子，现在是三根平的红条，像界面出错。
4. 头顶的三格火苗记号很好，保持。
