# BODY CAM · 清剿（随身记录仪视角的枪战游戏）

把之前那条 CG 枪战短片做成了能玩的版本：同一间扫描出来的废弃厂房、同一套手臂和手枪、同一个敌人模型和倒地动作，
画面也按短片的"记录仪成片"标准做——鱼眼镜头、自动曝光、运动模糊、卷帘快门、噪点、压缩感的调色。

第二版把一间屋子扩成了一栋小楼：**大厅 → 走廊 → 两间小房间**，敌人从院子里跑过来，从三个方向的门窗打进来。

第三版把这栋楼加成了**三层**：走廊东头多了一个楼梯间，往上是二楼（一条走廊 + 两间房，换了一种漆色），往下是地下室（窗全封死，没有光，只能靠枪灯）。玩家和敌人都能上下楼，别的楼层的房间里还有人蹲守。

第四版按试玩反馈改了四处：走廊通小房间的门洞里那块"看得见却能穿过去"的墙面拿掉了；敌人数量降到原来的约三分之一；倒地改成按物理算（每次都不一样，不会穿进墙里）；敌人交战时会挪位置、躲子弹、换弹，不再站桩。

第五版改的是手上的东西：多了一把 **M4A1 步枪**（按住连发，30 发）；Q / E 探身的幅度加大；手和枪离镜头更近、看得清了，两肩固定在身上、手肘会跟着枪的位置自己弯；换弹不再有"跳帧"；开枪时能看到套筒往复、抛壳、枪口上跳，打空会挂机；扔闪光弹时左手会离枪去扔。

第六版加了一个**池核（Poolcore）场景**：地下室走廊的北墙上多了一道门，门后是一片铺满白瓷砖的泳池空间——门厅的浅水池、三连拱、立着圆柱的深水大池、一条淹了水的长廊、几间小室。开始界面上可以选"开局：池核"直接从那里开始。

## 怎么开始

1. 双击 `启动游戏.command`（会开一个终端窗口并自动用浏览器打开游戏）。
2. 浏览器建议用 Chrome 或 Edge，全屏玩（Mac：⌃⌘F）。
3. 点"开始"，鼠标会被锁在画面里；按 Esc 松开并暂停。

也可以手动启动：在这个文件夹里运行 `python3 serve.py 8770`，然后浏览器打开 `http://localhost:8770/`。
（必须通过这个小服务器打开，直接双击 index.html 不行。）

## 操作

| 按键 | 作用 |
| --- | --- |
| W A S D | 移动 |
| 鼠标 | 转头。没有准星：子弹打向枪口指的方向 |
| 左键 | 开枪。手枪一下一发；步枪按住连发 |
| 1 / 2 | 换成手枪 / 步枪（滚轮或 X 在两把之间切）。换弹中途换枪，换弹作废 |
| 右键（按住） | 举枪瞄准：枪摆到镜头正前方，照门照星在画面中心，更准、走得慢 |
| Q / E | 向左 / 向右探身：身子横出去半米、歪过去约 18°，贴着门框只露半个身子（旁边有墙就探不了那么多） |
| C | 蹲下 / 站起（躲到窗台、杂物后面；敌人更难打中你） |
| 空格 | 跳（能踩上矮的杂物堆） |
| Shift | 冲刺（枪会放低，冲刺时不能开枪） |
| R | 换弹（手枪 17 发，步枪 30 发）。弹匣里还有子弹时只换弹匣；打空了套筒 / 枪机会挂在后面，换完要多一步放回去，慢一点 |
| G | 扔闪光弹（每段 2 枚）：左手离枪去扔，出手前这半秒开不了枪；会反弹，1.5 秒后炸；被晃到的敌人几秒内开不了枪，你自己看着它也会白屏、耳鸣 |
| F | 开 / 关枪灯 |
| L | 切换 白天 / 弱光 |
| H | 隐藏 / 显示左下角的提示 |
| M | 静音 |
| Esc | 暂停 |

贴着墙站时枪会自动收回来压低（这时开不了枪），退后半步就恢复。步枪长，离墙更远就得收。

## 两把枪

| | 格洛克 17 | M4A1 |
| --- | --- | --- |
| 打法 | 半自动 | 按住连发（约每秒 10 发） |
| 弹匣 | 17 发 | 30 发 |
| 后坐 | 每枪枪口明显上跳，很快回正 | 单发跳得小，连发会一发叠一发越打越高，要往下压或者打短点射 |
| 瞄准 | 照门两点 + 准星一点（夜光，关了灯也看得见） | 觇孔 + 准星柱 |
| 狭窄处 | 贴墙 0.8 米内才收枪 | 1.1 米内就得收枪 |
| 枪灯 | 枪管下方 | 护木右侧 |

两把枪威力一样（躯干两枪、头一枪），弹匣数量不限。

## 场地

一楼（进门的这一层）：

```
              ┌──────────────── 大厅（影片里的那间）────────────────┐
   院子  ═ 西门 ═                                                    │
              └──┤南门├─────────────────────────────────────────────┘
   院子  ═ 外门 ═  走廊（比较暗）                         │ 楼梯间  ▒ 窗
              └────────────────┤门├──────────────────────┴─────────┘
                          窗 ▒ │  小房间 C（黄墙）  │
                               ├──┤门├─────────────┤
                          窗 ▒ │  小房间 B（绿墙，有碎砖堆）│
                               └──▒ 窗 ────────────┘
```

- **楼梯间**在走廊东头，是两跑折返的楼梯：每上（下）半层有一个转身的平台，中间隔着一道墙，转角看不到另一跑上的人。东墙高处有一扇窗，白天楼梯间上半截是亮的。
- **二楼**：楼梯上去是一条和一楼一样长的走廊，尽头是窗；走廊南边同样的位置有两间房（绿墙的 C、蓝白墙的 B），三扇窗都能看到院子。大厅上面没有二楼。
- **地下室**：楼梯下去同样是走廊 + 两间房，窗用板封死了。越往下走越暗，到底下基本全黑、没有颜色，只有枪灯照到的地方看得清（按 F 开关枪灯）。
- 你只能在楼里活动；院子是敌人的。左下角会在你踏上另一层时提示当前楼层。

### 池核

从地下室走廊中段北墙上的那道门进去（门里透出来的光会照亮门口一小片走廊）；或者在开始界面点"开局：小楼 / 池核"切到池核，下一局直接出生在池核的门厅里。

```
   ┌────────┬──────────────┬───────────┬──────────┐
   │        │ 小室：下沉方池 │ 柱厅（浅水）│ 暗室      │   ← 只有水下的池灯，没有采光井
   │ 淹     ├───┤拱├───────┴──┤拱├─────┴──────┬───┤
   │ 水     │                                    │ 东 │
   │ 的     ╪      大池厅：深水池（居中一段下水台阶， ╪ 边 │
   │ 长     ╪      三根圆柱立在水里）              ╪ 窄 │
   │ 廊     │                                    │ 道 │
   │        ├─┤拱├────┤拱├────┤拱├──────────────┴───┘
   │        ╪      门厅：正对门是一方浅水池
   │        │
   └────────┴──────────┤门├── 地下室走廊
```

- 没有窗：光从天花板上的采光井来（白天很亮，弱光模式下只剩一点冷光），每个池子的池壁上还有水下的池灯——弱光模式下整片水是自己发着青光的。
- **水**：浅水没过脚踝，随便进出；深水池一米深，从岸上可以直接跳下去，但上岸只能走南边那段台阶（敌人也一样，他们不会跳下深水）。水越深走得越慢。
- 踩水有水声和一圈圈涟漪，子弹打进水里会溅水花，弹壳掉进水里是"咚"的一声。枪灯照在水面和釉面瓷砖上有反光。
- 你在池核里时，敌人除了从院子一路绕下来，也会从池核深处你看不到的角落里冒出来；别的楼层蹲守的人听到动静同样会找下来。

池核是纯代码搭的（不是扫描）：0.5 米一格的平面图生成网格，瓷砖是着色器按米画的，光照在加载时用碰撞网格打射线算一遍（直射带阴影 + 三次反弹，第一次打开要多等约 3 秒，之后浏览器里有缓存），水面的倒影是用一台镜像相机另外渲染的。
- 一楼大厅的西门、走廊的外门是敌人进楼的两个入口；一楼的三扇窗（C 西窗、B 西窗、B 南窗）外面也会有人往里打。二楼和地下室只有楼梯这一条路能上下。
- 走廊、楼梯间、二楼和地下室的走廊，都是用小房间扫描里的墙、地面、天花、门框"克隆"拼出来的，亮度按 Blender 里烘焙的结果缩放，所以质感和扫描房间一致。二楼和地下室的两间房是同一套扫描上下各放一份，换了色相和亮度。

## 敌人

- **人不多**：每一段只有一到三个人（前几段一两个，打到后面才有三个），同一时间在外面活动的通常只有一个。人少了，每一个都要认真对付。
- 每个敌人都从院子远处、你看不到的地方出现，**跑**过来（低姿持枪），你能透过门窗看到他们接近、听到脚步声。
- 两种打法，按你当时所在的房间分配：
  - **贴门窗的**：跑到门边或窗边的墙后，探身 → 瞄准 → 点射 → 缩回。探了几次、或者探出来看不到你，就改成冲进来。
  - **冲进来的**：沿着门、走廊一路找过来，摸进屋时枪口会左右扫；进你所在的房间之前，有时会先在门框边停一下、探头看一眼。
- **交战时不站桩**：
  - 打完一个点射就往旁边、斜前或斜后挪一两步再打，身子朝要去的方向斜着走，上身拧回来接着瞄；有时单膝跪下打一阵再起来换位置。
  - 远了一两发慢慢瞄着打，近了才连着打一串；一个弹匣打空要放低枪换弹（这两三秒是你的机会）。
  - 开枪时上身会被后坐顶得一震，枪口随呼吸慢慢游走；原地转身会倒脚。
  - **你的子弹贴着他飞过去、或者打在他身边的墙上，他会缩头**，多数会跟着闪到一边、或者蹲下、或者缩回门后——压着打是有用的。
  - 挨了一枪没倒的会被打得一个趔趄、弓一下腰，缓过来多半先换个地方。
- 只有真的看得见你（头或胸口没有被墙、窗台挡住）才会开枪；每个敌人头两枪一定打偏。
- 躯干两枪、头部一枪倒地。
- **倒地是算出来的，不是放同一段动作**：身体按中弹的部位和方向倒，打头直接瘫下去，打身体多数先踉跄一下；倒的过程会被墙、门框、台阶挡住——靠墙的会顺着墙滑下去，楼梯上的会顺着台阶滑倒，不会穿进墙里。
- **蹲守的**：两个人以上的那几段，其中一个会直接守在你不在的那些楼层的房间里或走廊尽头，枪口对着门口来回扫。你一露头他就打；听见同一层的枪声、挨了打、被子弹擦到、或者等久了，他会自己出来找你——所以也会有人从楼上下来、从地下室上来。
- 你上了二楼或下了地下室，院子里来的人会沿着楼梯追上去（下去）；楼梯间只有这一条路，守住转角平台很有用。
- 一段打完画面会"剪一刀"跳到下一段，反应更快、打得更准。没有血腥内容。

你中三枪阵亡，几秒不挨打会慢慢恢复（画面四周变暗表示受伤）。

## 画质与帧率

- 输出固定 16:9，最高 1920×1080；内部先按 1.0–2.0 倍分辨率渲染广角画面，再重投影成鱼眼。
- 倍率会按帧率自动升降（目标不低于 60fps）。想固定可以在网址后加参数，例如 `?scale=2`（最清晰）或 `?scale=1`（最省）。
- 其它网址参数：`?mode=dusk` 直接进弱光模式；`?fps` 左上角显示帧率和内部分辨率；`?nolock` 开始界面多一个"不锁鼠标直接玩"的按钮；`?tex=4k` 用小一半的贴图（显存紧张时）。
- 需要支持 WebGL2 的独立显卡或 Apple 芯片。M3 Max 上（无头 Chrome 实测 60 秒巡场）中位 16.7ms 一帧（60fps），倍率多数时间在 1.75，能升到 2.0。
- 加载时会先在镜头前放一个敌人渲染一帧（编译着色器、上传贴图），所以第一个敌人出现时不会卡一下。
- 三层的房间不会同时画：隔着楼板看不到的那几层（两间小房间每层一份、大厅）会关掉，在楼梯上走到两层中间时上下两层都画。

## 和短片的对应关系

| 短片里的东西 | 游戏里怎么做的 |
| --- | --- |
| 扫描场景自带的日光 + 可被动态光照亮的漫反射层 | 同一张贴图当自发光，窗户按亮度阈值提亮；窗外和门外洒进来的光预先在 Blender 里烘焙成光照贴图 |
| 门外的全景照片和地面投影 | 同一张 HDRI，同一个投影点 |
| 等立体角鱼眼（17.3mm / 36×20.25mm，对角约 146°） | 先渲染广角透视，再在后期里按同一套镜头公式重投影 |
| 自动曝光、泛光、镜头脏污、色差、暗角、噪点、调色曲线、降噪加锐化 | 逐项照搬短片后期脚本里的参数，曝光环路在 GPU 上算 |
| 枪口火光的卷帘快门条带 | 火光只照亮画面里随机一段扫描行，火焰贴图同样只在这段里出现 |
| 枪灯三层光锥、枪口火光的亮度 | 用短片里"有火光 / 无火光"的成对原始帧标定过 |
| 敌人的持枪和倒地动作 | 从短片场景里把 IK 持枪、动捕倒地、脚部贴地的结果烘焙成骨骼动画；新增的走、跑、待机、跪姿是同一批动捕重定向过来的，只用下半身，上半身始终是持枪姿态 |
| 后坐、受惊甩头、呼吸、手持抖动、枪比视线慢半拍 | 镜头的部分用的是短片镜头轨道里同一组冲击曲线和噪声参数；枪自己的后坐第五版改成了弹簧（绕手腕 / 枪托上跳、往后一顿、再回正） |
| 持枪手臂（短片里整体定格在一帧瞄准姿态） | 第五版起手和枪比短片里离镜头近；两肩钉在身体上，上臂和小臂按手腕的位置反解；换弹用素材自带的动画，在时间上抹平过。`?demo` / `?shots` 比对时仍按短片的整体摆法 |
| 声音 | 同一套合成方法生成的单个音效，实时过"记录仪麦克风"链路：混响 → 自动增益 → 削波 → 窄频带 |

大厅里唯一和短片不一样的地方：南墙那扇关着的门打通了，通向走廊。

## 自检用的模式（开发时用的，留着方便对比）

- `?start=pool`：直接从池核开局（等同于在开始界面上选）。
- `?demo`：按短片的镜头轨道回放，可和成片逐帧对照。
- `?shots=40,96,150&tag=xx`：把指定的短片帧渲染出来存到 `_shots/`，配合上一级目录的 `scripts/cmp.py` 生成并排对比图。
- `?auto=20&cap=1`：脚本自动打 20 秒，每秒存一张图；加 `&rec` 逐帧保存；`&seed=3` 固定随机数；`&god` 无敌；`&tour` 让脚本把一楼、二楼、地下室都走一遍（走完一圈约 110 秒）。
- `?bot`：实时自动试玩。
- `?views=x,y,朝向,俯仰[,举枪,探身,蹲,网格层];...`：按给定机位截图。网格层按半层分：0 地下室、1 下面那个楼梯平台、2 一楼、3 上面那个楼梯平台、4 二楼。
- `?ent=下半身片段,上半身片段,距离,转身`：在镜头前放一个敌人看动作。`?nav`：把五层可行走网格存成图。`?rag=机位x,y,朝向,俯仰,层;敌人x,y,层,转身角,部位,子弹偏角;...`：放几个敌人各中一枪，隔几帧截一张，检查倒地（`&noragdoll` 换回原来那段动画作对照）。`?phantom`：全场扫一遍"看得见却能穿过去"的墙面，结果在 `_shots/phantom.txt`。`?noguard`：不放蹲守的敌人。`?mute`：一开始就静音。`?nofoe`：不出敌人（看场景用）。
- `?vmt=枪,x,y,朝向,俯仰,层;动作@秒;...&T=总秒数&cap=每几帧存一张`：手臂和枪的动作逐帧检查（固定 60fps）。枪写 `pistol` 或 `rifle`；动作有 `fire`、`hold` / `release`、`reload`、`empty`（弹匣只留一发）、`ads` / `unads`、`sw`、`bang`、`leanL` / `leanR` / `unlean`、`fwd` / `run` / `stop`、`crouch`、`jump`、`light`、`pitch-40` 这类。配合 `scripts/vm_sheet.py` 把存下来的帧裁剪拼成一张图看。

池核的平面图、材质、烘焙都在 `src/pool.js` 里（改 `_layout()` 里的那几行 `fill(...)` 就能改户型），水声是 `scripts/game_sfx_pool.py` 合成的。
关卡是 `scripts/level_build.py`（Blender）搭的，敌人动作是 `scripts/game_enemy.py` 导出的。两把枪的动画分段是用 `scripts/vm_clip_scan.py` 量出来的（不经过 Blender，直接读 glTF）。
