# 《铁尘 IRON DUST》设计方案

第三人称重型机甲战术动作游戏 · Godot 4.7 (Forward+ / Jolt)
关键词：工业感、兵器感、尘土、做旧、厚重。

## 1. 流程
标题 → 作战选择 → 机库（选机 + 装备配置）→ 任务简报 → 出击 → 战果结算。
标题、作战选择、机库、暂停界面按 O 进入设置。

## 2. 版权边界
高达 UC 系列机体（含外传主角机）是受版权保护的具体设计，本作**不复刻其外形、名称、配色与标志性特征**。
机体为原创的写实军用风格"战术机架 (Tactical Frame)"；裙甲、推进器、臂盾、蓄力/照射武器、超频等只取类型惯例，不照搬任何一作的设计或界面。

## 3. 技术方案
| 项 | 做法 |
|---|---|
| 场景 | 地形、建筑、天空全部由代码生成；`main.tscn` 只挂一个脚本。地形在岩石区被“阶地化”（平台面 + 陡坎），陡面用侧向投影的层状崖壁贴图；`world._build_rocks()` 程序生成层状岩台与岩脊（战场内带精确碰撞，战场外的大型岩台只作远景）。建筑由 `buildings.gd` 生成：四种塔楼风格（壁柱檐口的石砌楼、圆形核心筒之间架楼板的“核心筒 + 楼板”、插接舱体塔、悬挑的穿孔巨板；均可按损毁程度削角、露出楼板）；巨构组合 `megablock`（多个核心筒 + 不同高度的桥接体量 + 球体簇桅杆 + 肋盘 + 穿过底层的高架）；可进入的巨型装配厂房（龙门吊、塔吊、筒仓、管廊、输送带）；以及只作远景剪影的天际线平台城 `skyframe`；碰撞盒分散挂在多个静态体上 |
| 机体建模 | **Blender 脚本分零件建模**（`tools/blender/`），导出 `models/<机体>.glb`。每个关节是一个空节点，零件网格挂在驱动它的关节下；Godot 端 `mech_model.gd` 读取关节并做程序化动画。本方四机由 `mk_parts.py` / `build_mechs.py` 生成，敌方四机由 `mk_foe.py` / `mk_foe_top.py` / `build_foes.py` 生成。缺少 glb 时回退到代码拼装的同名关节模型。设计语言：中型与重型机的腰腹主轴、颈部、髋关节由装甲覆盖（轻型机保留少量外露骨架）；装甲之间是带梯形凸台的真实接缝；全身遍布指示灯（重点在背包、裙甲、小腿等追尾镜头可见处）；膝后与脚踝露出作动筒 |
| 装备 | 三个装备库：`equip.glb`（原有 21 件）、`equip_f.glb`（狙击步炮、缆供照射炮、钩锁发射器与钩头、三联长枪、护卫盾）、`equip_e.glb`（刺刀榴弹步炮、臂装火箭、双爪、刺盾）。按挂点实时挂载，机库里换装即换模型 |
| 材质 | `armor.gdshader`：涂装 / 掉漆 / 污渍 / 积尘，叠加实拍 PBR 细节层（三平面投影的反照率、法线、粗糙度）。顶点色 R = 遮蔽、G = 积尘、B = 棱边磨损（Blender 烘焙，掉漆沿真实棱边出现）。机体、载具、武器使用**不带投影分缝**的 `Tex.armor`，装甲线条只来自模型几何；带分缝铆钉网格的 `Tex.plating` 只用于登陆舰这类巨大平面。地面 `terrain.gdshader` 混合沙地 / 碎石 / 龟裂 / 混凝土四套实拍贴图。贴图为 Poly Haven 的 CC0 素材，清单见 `textures/CREDITS.md`，由 `tools/fetch_textures.py` 下载打包；画质设为“低”时关闭细节层 |
| 腿部 | 双骨 IK：脚掌在世界坐标里落地生根，按实际移动方向、速度和地形迈步；骨盆高度、侧移、扭转由落脚点反推 |
| 裙甲 | 6 片独立铰接护片，角度 = 大腿抬起量 + 弹簧二级运动（推进、下落、落地、受击都会甩动） |
| 推进器 | 喷口是独立关节，可偏转指向推力方向；尾焰用 `plume.gdshader` 网格 + 粒子 |
| 物理 | 机体为 `CharacterBody3D`；弹道逐帧射线检测；光束即时射线 |
| 画面 | `sky.gdshader`：渐变天空 + 太阳 + 受光积云（日间蓝天 / 黄昏金红两套配色）；指数雾 + 体积雾（已调淡，画面通透）、级联阴影、SSAO、Bloom；`ink.gdshader` 勾线后期（沿深度台阶和法线折痕描深色线，随距离淡出，画质“低”时关闭）；`post.gdshader` 做轻微色差 / 暗角 / 颗粒 / 受击与超频色调 |
| 音频 | `sfx.gd` 启动时合成全部音效 |
| UI | HUD 与菜单均为 `Control._draw()` 自绘 |

### Blender 关节约定（Godot 坐标：+Y 上，前方 −Z，右臂 +X）
```
pelvis ─ skirt_FL/FR/SL/SR/BL/BR（裙甲，原点在铰链）
       ─ hip_L/R ─ knee ─ ankle ─ sole      （腿；knee 下挂 noz_leg）
       ─ waist ─ head / pauldron_L/R（肩甲，带 noz_sh）
               ─ sh_L/R ─ el ─ mount_hand / mount_arm / mount_blade
               ─ mount_back_L/R、noz_front_L/R
               ─ back ─ noz_back_*、binder_L/R（翼状推进器）
vent_n：超频散热片，绕本地 X 打开；noz_*：本地 −Y 为喷射方向
```
重建模型：`tools/blender/mk_run.ps1 build | equip | verify`（机体与装备）、`blender -b -P tools/blender/build_air.py`（飞行器与设施）。

## 5. 战斗系统
- **厚重机动**：惯性加减速、限制转向速率、上身独立扭转；脚步真实落地，前进 / 后退 / 横移 / 原地转身各有步法，斜坡上脚掌贴地。
- **推进与飞行**：Shift 持续推进（起步有下蹲蓄力，全身前倾，裙甲后掀）；Q / 双击方向快速推进；空格起跳后按住持续升空；空中按住 Shift 平飞（保持高度）；C / Ctrl 急降。喷口随推力方向偏转，推进槽耗尽过热。
- **火控**：准星附近软锁定、自动提前量；导弹需锁定计时。
- **稳定值 / 硬直 / 倒地**：受击累积冲击，满则硬直；硬直中吃格斗 → 倒地。
- **蓄力武器**：按住蓄能、松开发射（聚能轨道步炮、重型磁轨炮）。满蓄伤害约 ×4，命中即硬直并带爆炸。
- **照射武器**：熔切照射器，按住持续输出光束，热量满则过热强制冷却。
- **可损毁臂盾**：只挡盾面朝向（左前方）弧度内的射击和爆炸，有独立耐久；随耐久下降分三段碎裂，碎光后失效。格斗不受盾阻挡。
- **技能核心（V）**：随时间蓄能，造成 / 承受伤害会更快，蓄满后启动。
  - 弱点扫描（红隼）：标记 560m 内全部敌人 12 秒，隔墙可见，全队对被标记目标伤害 +35%。约 40 秒蓄满。
  - 突击冲锋（堡垒）：最长 4.5 秒的持续冲刺，可小幅转向，受伤 -60%、不会硬直；撞到的敌人受 1500 伤害并硬直、被撞开。再按 V 提前结束。约 32 秒蓄满。
  - 电子干扰（伯劳）：7 秒内敌方无法锁定自己，来袭导弹失去制导，速度 +12%。约 36 秒蓄满。
  - 超频（三台通用）：强袭（射速、伤害）、机动（速度、推进不耗槽）、壁垒（减伤、不硬直、回盾）。蓄能慢（约 170 秒），结束后推进器强制过热冷却。
- **武器切换**：右手两把武器，约 0.5 秒。X 来回切换；滚轮上 = 主武器、下 = 副武器（连滚多格也只切一次）。按键会缓冲：格斗、硬直或上一次切换途中按下，动作结束后自动执行。
- **站定射击**：榴弹炮、磁轨炮、狙击步炮、缆供照射炮必须落地停稳才能开火。按住扳机机体会自动刹停并下蹲，准备时间 0.3–0.5 秒；空中无法开火。
- **后摇与喷射取消**：重武器开火后有 0.4–0.9 秒后摇（期间不能再攻击、移动减速）；格斗挥击命中后同样有收招。按 Q 快速推进或起步推进可以立刻取消后摇，代价是推进槽。
- **钢缆钩锁**：左臂装备，格斗性质——无视臂盾、命中即硬直，并把自己高速拉向目标，可接格斗打倒地；打中地形或建筑则牵引自己过去。空格 / Q 脱钩。
- **下挂榴弹与枪刺**：榴弹型步炮按 B 发射下挂榴弹；持这把枪时格斗变成枪刺突刺。
- **格斗**：突进、连击、命中顿帧。
- **维修套件**：R，回复 40% AP。

## 6. 任务
### 01 锈蚀回廊（小队突击，12 分钟）
沙漠炼油基地：摧毁 3 座榴弹炮台 → 歼灭增援小队 → 击毁王牌机。

### 02 降下作战（大规模阵地防御，16 分钟）
黄昏的对轨炮阵地。天空中是再入轨迹、探照灯和“满月到残月”的防空弹幕（粉色光盘逐渐亏成残月，成串向上延伸），远处雾霭里还有两艘登陆舰在降下；废墟城区里立着四座 160–250 米的阶梯式巨型建筑。我方有 3 座对轨炮、6 座高炮、僚机 2、守备机 3、坦克 6。
1. **迎击空降先遣**：四波攻击机（每波 4–5 架）扫射阵地；四波运输机（每波 3 架，共 12 架、约 28 台机架）飞抵空降区悬停投放（悬停时可击落，货物一并损失）。
   城区西侧矗立着 548 米高的轨道缆塔「ANCHOR 07」（底座、扶壁、环形甲板都有碰撞，可以落上去）。
2. **轨道空降舱**：20 个空降舱成对落向同一座炮，减速、着陆、展开、放出机架（落地前可击毁）。对轨炮开始充能，登陆舰本体从雾霭中降下。
   对轨炮充能到 30% 时，敌方轨道炮击自上而下扫过缆塔：切割装药逐层起爆 → 上段沿铰点倾倒、折断 → 下段逐层坍塌成瓦砾堆，全程约 30 秒，砸到的建筑被压扁，塔下的单位受到伤害。倒塌后留下残桩和可行走的瓦砾堆。
3. **击坠登陆舰**：对轨炮每 16 秒齐射一次，但火力不足以单独打完四台引擎（各 13000 AP）；玩家要向北推进或升空亲自输出，同时舰上继续投放空降舱。四台全灭后登陆舰坠毁。

难度设定：落地的敌机架约七成会直扑对轨炮（只在被贴近或被打时才还击），AP 与伤害各 +25%；对轨炮 AP 20000；高炮只负责对空且打不到登陆舰引擎；友军伤害倍率 0.3–0.5。
失败条件：机体被击毁、对轨炮全灭、登陆舰降到着陆高度、超时。

## 7. HUD
航向带；准星 + 锁定框 + 导弹锁定环；蓄力环 / 照射热量弧 / 超频环；速度 / 高度读数；推进槽弧；

AP、稳定值、臂盾耐久、超频槽；武器弹药、蓄力条、热量条、待切换武器；防御目标 DEFEND 标记；各类警告与横幅。

## 8. 操作
WASD 移动 · 鼠标瞄准 · 左键右手武器（蓄力 / 照射按住）· 右键重武器或左手副炮 · E 肩部挂架 · F / 中键格斗 ·
X / 滚轮切换右手武器 · V 技能核心 · G 左臂装备（右键被肩部武器占用时）· B 下挂武器 · Shift 推进 / 空中平飞 · Q / 双击方向快速推进（可取消后摇）· 空格跳跃 / 升空 · C / Ctrl 急降 ·
R 维修 · T 切换目标 · Esc 暂停 · M 静音 · F11 全屏
机库：Q / E 换机体 · W / S 选挂点 · A / D 换装备 · Enter 出击 · O 设置
X、V、F、Q、R、T、空格这些“按一下”的键由按键事件直接触发，低帧率下轻点也不会丢。

### 设置（O）
显示模式（窗口 / 无边框全屏 / 独占全屏）、窗口分辨率（按显示器大小列出）、渲染精度（50–100%，低于 100% 用 FSR 放大）、画质（低 / 中 / 高）、垂直同步、帧率上限、视野（60°–90°，默认 70°）、镜头距离（近 / 标准 / 远 / 很远，默认 40 米，镜头高度随之变化）、鼠标灵敏度、主音量。保存在 `user://settings.json`。
界面按 1920×1080 设计、等比缩放，宽高比不同的屏幕会向宽或高方向扩展（16:10、4:3、21:9 都不裁切）。
显示器上报刷新率低于 50Hz（远程桌面、虚拟显示器）时，默认关闭垂直同步并把帧率上限设为 120，否则游戏会被锁在那个刷新率。

## 10. 自动测试
`_shots/run.ps1 -TestArgs '<参数>'`：
`--menus` 菜单流程；`--move` 步态与推进；`--mech` 新机制；`--drop --mission=1` 降下作战全流程；
`--frame=N` 指定机体；`--lo=R1:lance,S1:rail` 覆盖装备；`--cfg=quality:0,scale:2` 覆盖设置；`--script=时间=命令;…` 临时脚本。
`--perf` 关闭垂直同步并打印每帧耗时、卡顿帧和各模块脚本用时；脚本命令 `speed:6`、`watch` 可以加速挂机跑完一局并定时输出战况，用来调难度。
`run.ps1 -Res 2560x1600 -Extra '-f'` 可以指定窗口大小或全屏来检查界面适配。
