# 《铁尘 IRON DUST》游戏设计文档（GDD）

版本 0.6 · 2026-11-25 · 引擎 Godot 4.7（Forward+ / D3D12 / Jolt）· 平台 Windows PC

本文档描述游戏**当前已实现**的设计，数值取自 `scripts/defs.gd` 等源文件。未实现或未验证的内容集中写在第 14、15 章，正文其余部分不混入设想。技术实现细节另见 `设计方案.md`。

## 1. 概述

### 1.1 一句话
驾驶 18 米高的重型战术机架，在沙漠基地和轨道登陆战场上作战的第三人称机甲动作游戏：机体沉重、武器有后摇、每一步都踩在地上。

### 1.2 定位
| 项 | 内容 |
|---|---|
| 类型 | 第三人称机甲战术动作，单人任务制 |
| 单局时长 | 12–16 分钟 |
| 视角 | 追尾第三人称，镜头位于机体后上方约 40 米 |
| 输入 | 键盘 + 鼠标 |
| 目标体验 | 重量感、武器感、大战场感 |

### 1.3 设计支柱
1. **厚重**：加减速有惯性，转向有速率上限，上身独立扭转；落地、起步、受击都有全身反馈。
2. **兵器逻辑**：每件武器有明确的使用条件和代价（站定、蓄力、过热、后摇），而不是只有伤害数字的差别。
3. **承诺与取消**：强力动作会把机体“锁住”一小段时间；用推进取消后摇是核心技巧，代价是推进槽。
4. **可读的大战场**：敌我、目标、弹道、威胁都能在远处读出来；战场规模靠运输机编队、空降舱、登陆舰和巨构来建立。
5. **可定制**：四台机体 × 七个挂点，载荷决定机动。

### 1.4 参考与版权边界
- 玩法语言参考机甲对战与高机动机甲动作类作品的类型惯例（稳定值与硬直、推进取消、站定射击、臂盾、追尾镜头）。
- HUD 参考空战与机甲游戏的信息布局惯例。
- 美术参考“写实系机器人”的结构语言：分面装甲、梯形接缝、指示灯、外露作动机构；建筑参考新陈代谢派与粗野主义的巨构语言。
- **所有机体、建筑、名称均为原创设计**，不复刻任何既有作品的具体造型、名称、配色或标志性特征。用户提供的参考图只作风格参考。
- 贴图素材为 Poly Haven 的 CC0 资源，清单见 `textures/CREDITS.md`。

## 2. 世界观与叙事

### 2.1 设定
荒漠化的大陆上，两股势力争夺仅存的工业设施与对轨防御阵地。玩家是“砂砾小队”的队长（呼号 砂砾 1），由指挥所“铁砧”调度。敌方使用圆润外壳、尖刺肩甲、单眼传感器的机架，并拥有轨道舰队。

### 2.2 叙事方式
没有过场动画。剧情全部通过任务简报、战斗中的无线电字幕和横幅推进：

| 角色 | 作用 |
|---|---|
| 铁砧（指挥所） | 下达目标、预警、教学提示 |
| 砂砾 2 / 砂砾 3（僚机） | 战况播报、情绪反应 |
| 亡灵（敌方王牌） | 第一关最终阶段的对手，有台词 |

## 3. 游戏流程

```
标题 → 作战选择 → 机库（选机 + 配装）→ 任务简报 → 战斗 → 战果结算
                        ↑__________________________|（重试 / 返回机库）
```
- 标题、作战选择、机库、暂停界面按 **O** 进入设置。
- 战斗中 **Esc** 暂停，暂停界面列出全部操作。
- 配装保存在 `user://loadouts.json`，设置保存在 `user://settings.json`。

### 3.1 结算评级
胜利时计算分数：`100 − 受损百分比×0.25（上限 150%）− 用时占比×40 + 击坠数（上限 12）+ 任务加成`。

| 评级 | 分数 |
|---|---|
| S | ≥ 80 |
| A | ≥ 66 |
| B | ≥ 52 |
| C | 其余 |
| D | 任务失败 |

“降下作战”的任务加成 = (存活对轨炮数 − 3) × 9 + 10。

## 4. 操作

### 4.1 战斗
> 0.6 起空格与 Shift 的功能对调，并新增解除锁定键，见 18.1。

| 输入 | 功能 |
|---|---|
| W A S D | 移动（相对镜头方向） |
| 鼠标 | 瞄准 / 视角 |
| 左键 | 右手武器（蓄力、照射、站定武器需按住） |
| 右键 | 右肩重武器；没有肩部武器时为左臂装备 |
| E | 左肩挂架（导弹需锁定） |
| G | 左臂装备（右键被肩部武器占用时） |
| B | 下挂武器（榴弹） |
| F / 中键 | 格斗（可连击） |
| X | 切换右手主 / 副武器 |
| 滚轮 | 上 = 主武器，下 = 副武器 |
| V | 技能核心 |
| Shift | 持续推进；空中为平飞（保持高度） |
| Q / 双击方向 | 快速推进；后摇中按下 = 取消后摇 |
| 空格 | 跳跃；空中按住持续升空 |
| C / Ctrl | 空中急降 |
| R | 维修套件（回复 40% AP） |
| T | 切换锁定目标 |
| Esc / M / F11 | 暂停 / 静音 / 全屏 |

### 4.2 机库
Q / E 换机体 · W / S 选挂点 · A / D 换装备 · Enter 出击 · Esc 返回。鼠标可点击机体卡片、挂点行和左右箭头。

### 4.3 输入处理规则
- X、V、F、Q、R、T、空格等“按一下”的键由按键事件触发，低帧率下轻点也不丢。
- **输入缓冲**：武器切换缓冲 0.9 秒，技能缓冲 1.6 秒。在格斗、硬直或上一次切换途中按下，动作结束后自动执行。
- X 是来回切换；滚轮指定具体武器，连滚多格也只切一次。

## 5. 核心战斗系统

### 5.1 资源与状态
| 资源 | 说明 |
|---|---|
| AP | 装甲值，归零即击毁 |
| 稳定值 | 受击累积“冲击”，超过机体的稳定上限即硬直；2.2 秒未受击后每秒恢复 45 |
| 推进槽 | 0–1；耗尽则过热，过热期间不能推进、跳跃、格斗 |
| 臂盾耐久 | 独立耐久，被打碎后本局不再恢复（壁垒超频除外） |
| 技能槽 | 随时间蓄能，造成 / 承受伤害加速 |
| 维修套件 | 第一关 2 个，第二关 3 个 |

状态机：`正常 → 硬直（1.35 秒）→ 倒地（2.3 秒）→ 正常`，另有 `格斗中`、`击毁`。
- 硬直中受到的伤害 ×1.2；硬直中被**格斗**命中会倒地。
- 倒地中受到的伤害 ×0.8；起身后有 1.5 秒保护（伤害 ×0.5，不累积冲击），硬直结束后保护 0.5 秒。

### 5.2 移动
| 动作 | 规则 |
|---|---|
| 步行 | 加速度 62，停止 52；转向速率受机体限制 |
| 持续推进（Shift） | 目标速度 = 机体推进速度；起步额外冲量并消耗 0.04 推进槽；持续消耗按机体 `drain`（空中 ×1.25） |
| 快速推进（Q） | 瞬间达到机体 QB 速度，持续 0.22 秒，消耗 0.2 推进槽，冷却 0.6 秒 |
| 跳跃 | 初速 23 m/s，消耗 0.06 |
| 升空（按住空格） | 上升加速度 72，最高 25 m/s，升限 330 米（接近升限时衰减），每秒消耗 0.2 |
| 空中平飞（空中 Shift） | 保持高度 |
| 急降（C / Ctrl） | 下坠加速度 95，最大 62 m/s |
| 推进槽恢复 | 停止使用 0.7 秒后按机体 `regen` 恢复（空中 ×0.4） |
| 过热 | 推进槽归零后进入过热，时长为机体 `overheat` 秒 |

腿部使用反向运动学：脚掌按实际移动方向、速度和地形落地，前进、后退、横移、原地转身各有步法。大腿上方 6 片裙甲随腿部动作和推进、下落、落地、受击甩动。

### 5.3 火控
- **软锁定**：准星附近（屏幕半高 0.42 范围内）、720 米内、有视线的敌人自动锁定；T 切换。
- **自动提前量**：对锁定目标按弹速计算；有弹道下坠的武器自动抬高。
- **导弹**：需持续锁定达到武器要求的时间（1.0–1.3 秒）才能发射。

### 5.4 武器机制类型
| 类型 | 规则 | 代表 |
|---|---|---|
| 连射 | 按住即射，打空自动装填 | 突击步炮、转管机炮、冲锋机炮 |
| 蓄力 | 按住蓄能、松开发射；蓄力低于 18% 按普通弹发射；满蓄伤害与冲击成倍并带溅射 | 聚能轨道步炮、重型磁轨炮 |
| 照射 | 按住持续输出，每 0.1 秒结算一次伤害；热量满则过热强制冷却 | 熔切照射器、缆供重型照射炮 |
| 站定 | 必须落地停稳；按住扳机自动刹停并下蹲，达到准备时间后开火；空中无法开火 | 榴弹炮、磁轨炮、狙击步炮、缆供照射炮 |
| 齐射 | 一次按键打出整组 | 导弹、火箭 |
| 钩锁 | 格斗性质：无视臂盾、命中即硬直、把自己拉向目标（最高 115 m/s）；打中地形则牵引移动；空格 / Q 脱钩 | 钢缆钩锁 |
| 下挂 | 随主武器携带，独立弹药，B 键发射 | 下挂榴弹 |

### 5.5 后摇与喷射取消
- 带 `rec` 的武器开火后进入后摇（0.4–0.9 秒）：期间不能开火和格斗，步行速度降到 35%。
- **取消方式一**：按 Q 快速推进，立刻清除后摇。
- **取消方式二**：起步持续推进，清除后摇并额外消耗 0.08 推进槽。
- **格斗取消**：挥击命中后（命中帧后 0.1 秒起）按 Q，立刻脱离收招。
- 取消成功时准星上方闪出 CANCEL，并有音效。

### 5.6 格斗
- 按 F 向前突进；有锁定目标且在突进距离内时自动追踪。
- 命中帧在动作的 47% 处；命中判定为前方约 70° 扇形、武器攻击距离 + 3.5 米。
- 连击伤害倍率：1.0 / 1.15 / 1.4。
- 格斗无视臂盾，冲击值极大（必定硬直），命中时有 0.09 秒顿帧。
- 每次出招消耗 0.09 推进槽；过热时不能格斗。

### 5.7 臂盾
- 只挡**盾面朝向**（机体朝向 + 上身扭转 + 约 26° 偏左）弧度内来的射击和爆炸。
- 溅射伤害对盾 ×0.7；被盾挡下的攻击只累积 20% 冲击。
- 随耐久下降分三段碎裂（62%、30%、0），碎光后失效。
- 格斗、撞击、钩锁不受盾阻挡。

### 5.8 技能核心（V）
技能槽蓄满后启动；蓄能速度 = 1 / 冷却秒数，造成伤害（每 7500 点 +1 格）和承受伤害额外加速。

| 技能 | 机体 | 持续 | 蓄满约 | 效果 |
|---|---|---|---|---|
| 弱点扫描 | 红隼 | 12 秒 | 40 秒 | 标记 560 米内全部敌人：隔墙可见，全队对其伤害 +35% |
| 突击冲锋 | 堡垒 | 4.5 秒 | 32 秒 | 强制向前冲刺（速度 ×1.3，转向 ×0.55），受伤 −60%，不会硬直，推进不耗槽；撞到的敌人受 1500 伤害、硬直并被撞开；再按 V 提前结束 |
| 电子干扰 | 伯劳 | 7 秒 | 36 秒 | 敌方丢失对自己的锁定，来袭导弹失去制导，速度 +12% |
| 精密狙击 | 苍鹭 | 9 秒 | 38 秒 | 伤害 +30%，射速与蓄力 +30%，站定准备时间 −60%，散布降到 10% |
| 强袭超频 | 通用 | 12 秒 | 170 秒 | 射速 +40%，伤害 +20%，速度 +10%，稳定上限 ×1.5 |
| 机动超频 | 通用 | 14 秒 | 170 秒 | 速度 +32%，转向 +50%，推进不耗槽 |
| 壁垒超频 | 通用 | 12 秒 | 170 秒 | 受伤 −55%，不会硬直，臂盾恢复到至少 60% 并持续回复 |

三种超频结束后推进器强制过热（过热时长 ×1.25）。专属技能没有这个惩罚。

### 5.9 载荷与机动
每件装备有重量。`机动倍率 = clamp(1.14 − 0.2 × 总重 / 载荷上限, 0.72, 1.08)`，作用于步行、推进、快速推进速度，转向受一半影响。超载不禁止出击，但明显变慢。

**打法意图**

- **伯劳**：钩锁拉近 → 格斗连击 → 喷射取消脱离；装甲薄，靠干扰和机动生存。
- **苍鹭**：找高处站定狙击，一发即硬直；被贴近时用副武器和推进拉开。

## 8. 敌方 AI

AI 通过与玩家相同的控制输入驱动机架，所以受同样的惯性、后摇、过热约束。

| 行为 | 规则 |
|---|---|
| 索敌 | 每 0.6–1.1 秒重选；按距离挑选，玩家权重 ×0.8，非机架目标 ×1.3；被攻击后感知范围 ×2.2 |
| 保持距离 | 按机型的理想射程区间前进或后退，同时横向游走；与友军保持 24 米间距 |
| 点射节奏 | 开火与停火时段按机型配置交替，带 ±30% 随机 |
| 闪避 | 按机型间隔使用快速推进横移 |
| 重武器 / 站定武器 | 对准且有视线时按住扳机到准备完成（会自己站定） |
| 格斗 | 目标进入突进距离 80% 且高度差小于 10 米时，按机型概率出手；目标硬直时必定出手 |
| 脱困 | 0.5 秒内几乎不动则跳跃并换向 |
| 技能 | 超频与干扰在 AP 低于 60% 时使用；扫描有目标就用；冲锋在 30–150 米且对准时使用 |
| 目标猎杀 | “降下作战”中约 70% 的落地敌机直扑最近的对轨炮，只在被贴近（110 米内）或被打（240 米内）时才还击 |

敌方命中靠散布倍率控制（基础 ×2，再乘机型精度系数），提前量系数 0.8。

## 9. 任务

### 9.1 第一关：锈蚀回廊（OPERATION RUST CORRIDOR）
- **规模**：小队突击，限时 12 分钟，日间沙漠炼油基地。
- **地图**：边长约 1400 米的可活动区。南侧是开阔的沙地进场通道，中央是基地（机库、储罐、龙门架、集装箱），四周是阶地岩台。
- **我方**：玩家 + 僚机 砂砾 2（伤害 ×0.55，AP ×1.4）。

| 阶段 | 目标 | 敌人 | 触发 |
|---|---|---|---|
| 1 | 摧毁 3 座榴弹炮台 | 炮台 3、坦克 4、猎犬 3 | 开局 |
| 2 | 歼灭增援 | 猎犬 2、裂爪 1、重锤 1，从北侧接近 | 炮台全灭 |
| 3 | 击毁王牌「亡灵」 | 亡灵从 170 米高空降下 | 增援全灭后 4 秒 |

失败条件：机体被击毁、超时。

### 9.2 第二关：降下作战（OPERATION DESCENT）
- **规模**：大规模阵地防御，限时 16 分钟，黄昏。
- **地图**：边长约 2300 米。南侧是对轨炮阵地（3 座炮、6 座高炮、掩体墙、后方基地与巨型装配厂房），北侧是废墟城区（多种风格的塔楼、四座巨构、548 米高的轨道缆塔），远处是天际线平台城和两艘正在降下的登陆舰。
- **我方**：僚机 2（伤害 ×0.4）、守备机 3（×0.3）、坦克 6（×0.5）、对轨炮 3、高炮 6。
- **敌方落地机架**：AP 与伤害各 +25%。

| 阶段 | 内容 | 结束条件 |
|---|---|---|
| 1 迎击空降先遣 | 4 波攻击机（4–5 架）；4 波运输机（每波 3 架，共 12 架，约 28 台机架）飞抵 5 个空降区悬停投放 | 12 架运输机全部击落或撤离且地面敌机 ≤ 3，或 255 秒 |
| 2 轨道空降舱 | 20 个空降舱成对落向同一座炮（地面敌机 < 12 时每 8–11 秒一对）；每 40 秒 4 架攻击机；对轨炮充能（三炮齐全约 125 秒，每损失一座变慢）；登陆舰本体降下 | 充能 100% |
| 2 中段事件 | 充能 30% 时，轨道炮击扫过缆塔，约 30 秒内分段崩塌，压扁下方建筑并伤害塔下单位（每段最高 7000） | — |
| 3 击坠登陆舰 | 登陆舰悬停在阵地以北约 900 米、高度 340 米处，以 1.15 m/s 下沉；对轨炮每 16 秒齐射，每炮 1000 伤害；舰上每 9–13 秒投一个空降舱；每 45 秒 3 架攻击机 | 4 台引擎全灭 → 坠毁 → 5 秒后胜利 |

失败条件：机体被击毁、对轨炮全灭、登陆舰降到 150 米着陆高度、超时。

**难度意图**：对轨炮的齐射火力不足以单独打完四台引擎（合计 52000 AP），玩家必须向北推进或升空输出；同时不能丢下炮座。挂机模拟的结果是约 7 分钟时三座炮全灭。

## 10. 关卡与环境设计

## 12. 美术方向

### 12.1 机体设计语言
- **比例**：小腿与脚掌大、躯干紧凑、头部小，约 18 米高。
- **主轴装甲**：中型和重型机的腰腹、颈部、髋关节由装甲覆盖；轻型机保留少量外露骨架。
- **梯形接缝**：装甲板之间是带梯形凸台与缺口的真实缝隙。
- **指示灯**：每台 16–18 处，重点在背包、裙甲、小腿等追尾镜头可见处。
- **外露机构**：膝后与脚踝露出作动筒，正面被装甲遮住。
- **阵营区分**：本方是方块分面装甲 + 护目镜或镜头簇头部；敌方是圆润切板外壳 + 尖刺肩甲 + 单眼传感器。
- **预算**：每台不超过 45000 三角面、150 个网格节点。

## 15. 验证状态与已知问题

### 15.1 已验证
通过自动测试脚本（`_shots/run.ps1`）验证，均无脚本报错：
- 菜单全流程、两个任务的完整阶段推进、失败与胜利结算。
- 武器切换（含硬直中、连按、滚轮多格）、蓄力、照射、站定、后摇与取消、钩锁、下挂榴弹与枪刺、四个专属技能与超频、臂盾。
- 楼顶与岩台落脚、缆塔崩塌、设置项切换（窗口 / 全屏 / 分辨率 / 画质）。
- 第二关挂机模拟：不操作会失败。

### 15.2 未验证
- **真人手感**：操作响应、镜头、后摇时长、取消时机都没有真人试玩过。
- **音效**：从未被人耳听过，音量与音色未校准；缆塔崩塌的音效只核对了触发次数。
- **难度与平衡**：只做过挂机模拟；正常游玩的通关率、各机体与武器的强弱没有数据。
- **走进厂房、从巨构底下穿行**：只有射线检测依据，没有操作机体实测。
- **低配硬件**的性能。

### 15.3 已知问题
- 敌机落地瞬间有一次约 16–25 毫秒的停顿（生成机体模型）。
- 腰腹装甲在大幅前倾时可能与骨盆穿插。
- 狙击步炮约 14 米长，切换武器时枪口可能短暂穿地。
- 裂爪的传感器在大幅俯仰时可能露出头罩缝外。
- 机体站在画面底部时，脚部会被底部状态栏遮住一些。
- 退出游戏时有少量对象未释放的警告，不影响运行。
- 黄昏关卡整体偏红，逆光下机体接近剪影。

- **自机显示**：机体本身（躯干、头、四肢、肩部武器、臂盾、编号贴花）只画勾线（轮廓和装甲板棱线，半透明）；手持武器和近战刀身完整渲染；射弹、光束、枪口焰、剑弧照常显示。

- **受击即时表现**：座舱抖动、控制台迸出火花、指示灯闪白、画面横向撕裂并出现雪花。
- **低血量持续表现**：60% 以下开始出现显示面板熄灭或闪烁、面板接缝变明显、画面泛红；40% 以下座舱冒烟；30% 以下间歇火花；25% 以下舱内转红色应急灯、仪表屏闪断。正前方约 25° 内的面板最后才熄灭。这些损伤只画在舱外画面上，不覆盖座舱设备。

## 18. 版本 0.6 增补（2026-11-25）

本章记录 0.5 之后加入的内容；与前文（含第 17 章）冲突处以本章为准。

### 18.1 操作变更
| 输入 | 功能 |
|---|---|
| 空格 | 持续推进；空中为平飞（原 Shift） |
| Shift | 跳跃，空中按住持续升空；宇宙中为垂直上升（原空格） |
| C / Ctrl | 急降；宇宙中为垂直下降（不变） |
| Z | 解除锁定 |
| T（长按 0.45 秒） | 解除锁定 |

解除锁定后不再自动锁定，直到再按一次 T。

### 18.2 锁定规则
- **视线判定**：从镜头支点向目标中心打一条射线；射线畅通，或只在紧贴目标处被挡（舰船部件嵌在自己的船体里，机架可能半藏在山脊后），都算可锁。
- **细长遮挡物**：中心被挡时，再向目标左、右、上、下边缘各试一条射线，任意一条通过即可锁。船坞立柱、桁架、敌舰自身的獠牙不再让露出大半的炮塔锁不上。
- **锁定距离**：普通目标 720 米；战舰部件为 1.8 倍（约 1300 米）。
- 完全在船体背面、或被另一艘船整个挡住的部件仍然不可锁。

### 18.3 光束机枪
按下一次打出 5 连发，之后进入冷却（HUD 显示"冷却"，枪身冒烟），不是按住连射的武器。

| 版本 | 代号 | 单发伤害 | 连发间隔 | 冷却 | 射程 | 使用者 |
|---|---|---|---|---|---|---|
| 敌方 | E-BMG | 82 | 0.10 秒 | 2.3 秒 | 520 | EF-6 掠袭者、掠袭者 · 王牌 |
| 缴获 | BMG-5 | 165 | 0.09 秒 | 1.7 秒 | 600 | EF-6 掠袭者〔缴获〕的默认右手武器 |

缴获机右手挂点可选：光束机枪、单管火箭、冲锋枪。

### 18.4 近战武器挂架与格挡姿态
- **挂架**：近战武器平时挂在腰侧或背部的挂架上，手是空的；只有拔刀、挥击和收刀前的短暂时间才握在手里。射击时不再出现"一手持枪一手提刀"。
- **格挡**：举盾时肩部整体前送并抬起（不只是转大臂和小臂），臂盾自己转向正前方。按机体和臂盾的全部组合逐一测过，臂盾没入躯干的比例为 0。
- **格挡时的刀**：持刀格挡时，刀沿小臂的延长线指向斜上方。驾驶舱视角下格挡时隐藏这把刀，避免挡住视野。
- **肩部武器支架**：肩部武器离肩甲较远的机体（重锤）加了支架，不再浮空。
- 未做：拔刀没有伸手够武器的过渡动作；背部挂架目前没有机体使用。

### 18.5 警报
装甲低于 25% 时，两种视角都进入警报状态：
- 间歇警报声，装甲低于 12% 时加快。
- 屏幕边缘红色扫掠和整体红色脉动。
- HUD 在准星上方显示"装甲临界"横幅，画面两侧有向下滚动的警示条。
- 驾驶舱内：顶灯变暗，红色旋转警示灯点亮。

### 18.6 驾驶舱（取代 17.7 中的座舱外观与受损描述）
**视角**：座舱只跟随机体朝向，不随视线俯仰；抬头低头时仪表保持水平。

**球面显示墙**：
- 面板按圈排布、赤道一圈 18 块，左右镜像，正前方是一块完整面板，视野中心没有接缝。
- 面板大小不均匀，部分面板切掉 45° 角。宇宙战中同样显示接缝网格。
- 受损按面板计：整块面板出现三种故障之一——画面错位并带色散、雪花、熄灭。碎裂线就是面板原有的接缝，不是另画的裂纹。
- 故障面板的接缝处有电弧、光晕和下落的火星；头顶斜上方的故障点会向视野中心方向喷出一道细碎火花。

**座舱结构与外观**（`models/cockpit.glb`，约 11.1 万三角面，24 种材质）：
- **承力结构**：地板双纵梁加横梁、花纹钢踏板、座椅斜撑与减震器、两侧框架与扶手管、仪表台 A 形支架、线缆和焊缝。

- **两侧**：各一块触摸屏（奶白色切角包边、角螺栓、橙色标签）和一个三表仪表舱；顶部横梁带开关翼板；两侧控制台。
- **操纵杆**：左杆管移动（苦力帽、推进键、"移动"标牌），右杆管武器（带护盖的开火键、锁定键、选择拨轮、扳机、"武器"标牌）。按钮只做了造型区分，没有和实际操作联动。

**材质**：金属、漆面、花纹钢、皮革使用 Poly Haven 和 ambientCG 的开源贴图（来源见 `textures/CREDITS.md`）；钢管和操纵杆用自写的拉丝金属着色器，纹理和高光沿管轴方向拉伸，不依赖 UV。

- **獠牙号、鬣狗号**：甲壳环节上加了八条贯穿全长的纵向肋条、交错的装甲鳞片，尾段环节之间有发光散热缝。
- **主炮**：友方为楔形多面炮室，带测距仪横臂、指挥塔和蓝色舰线；敌方为多层甲壳加眉脊发光缝和鳃状鳍。炮管有耳轴鼓、根部护套和炮口装置（友方双环制退器，敌方喇叭口）。
- **点防御炮**：友方为带切角的流线吊舱，敌方为双层甲壳。
