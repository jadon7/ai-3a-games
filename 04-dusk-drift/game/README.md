# 暮色漂移 · Dusk Drift

把赛车漂移短片（`../racing/`）做成的可玩版本：影片里的三台车再加 10 台（共 13 台）、同一张天空、同一套半湿沥青和调色，
跑在浏览器里（three.js r187 + WebGPU），赛道改成了 1.5 公里、8 个弯的闭合赛道，第一个弯就是影片里的那个右弯。

## 怎么玩

双击 `启动游戏.command`（会在本机开一个静态服务器并打开浏览器；关掉弹出的终端窗口即退出）。
需要支持 WebGPU 的浏览器：Chrome / Edge 113 以上，或 Safari 26 以上。

| 按键 | 作用 |
|---|---|
| W / ↑ | 油门 |
| S / ↓ | 刹车，停住后继续按是倒车 |
| A D / ← → | 方向 |
| 空格 | 手刹 |
| C | 依次切换 8 个镜头 |
| 1–8 | 直接选镜头：1 追尾 · 2 远追尾 · 3 车顶 · 4 驾驶位 · 5 场边电视机位 · 6 低机位侧跟 · 7 前方倒拍 · 8 高空跟拍 |
| V | 直接切到驾驶位视角，再按一次回到原来的镜头 |
| R | 复位到赛道中间 |
| Esc / P | 暂停 |
| M / H | 静音 / 隐藏界面 |
| [ / ] | 转向灵敏度降 / 升一档（共 5 档，会记住） |
| X | 自动驾驶开 / 关 |
| N | 自动切镜开 / 关 |
| Shift + 1–8 | 把这个镜头加入 / 移出自动切镜的镜头池（会记住） |

也支持手柄（左摇杆方向、RT 油门、LT 刹车、A 手刹、Y 镜头）。

**转向灵敏度**：5 档，倍数 0.8 / 1.0 / 1.25 / 1.5 / 1.75，默认第 3 档（1.25，比原来高一档）。灵敏度同时影响两件事：按住方向键时方向打到位的快慢，以及中速时能打多大的方向（例如 100 km/h 时，按满方向的前轮转角从 10.5° 变成 12.6°）。高速时转角的下限保持 7.5° 不变，免得车尾更容易滑出。

**录制模式**：比赛中按 X 打开自动驾驶，再按 N 打开自动切镜，按 H 隐藏界面，就可以直接录屏。也可以在网址后面加 `?auto=1`，开局就同时打开自动驾驶和自动切镜。
- 自动驾驶在直道和小弯沿赛车线抓地跑（复用 AI 的走线和避让）。在 5 个转角超过 80° 的弯（T1、T3、T5、T6 发卡弯、T8）里，会先刹到入弯速度，拉手刹甩尾，再持续漂过去，车头对准出口后收车。每个弯的入弯速度、甩尾点、是否先摆到外侧，都是离线搜出来的（`src/autopilot.js` 的 `ZONE_TUNE`）。
- 自动驾驶时比赛不会结束，会一直跑下去。前方弯里有别的车就不漂，跟在后面抓地过；前车近就降速，不往别人身上挤。第一圈从最后一位发车，前几个弯常被前车挡住，所以想要每个弯都漂、画面最干净，可以在菜单里选"无对手 · 练习"。
- 自动切镜每个镜头停 4–8 秒，车一甩尾就从驾驶位、车顶这类平淡的机位切到侧跟、场边、倒拍、追尾、高空这类好看的机位。侧跟机位会放在前方弯道的外侧，拍到车横着滑过来。镜头池默认不含远追尾（和追尾太像），可以用 Shift + 数字增减。按数字键手动选镜头时，自动切镜会关掉。
- 离线测试：`node tools/autopilot_test.mjs`（每台车单独跑 3 圈）、`node tools/autopilot_zone.mjs`（逐弯）、`node tools/autopilot_traffic.mjs`（带 5 台 AI）、`node tools/autopilot_tune.mjs 弯号`（搜参数）。

**驾驶位视角**：方向盘会随打方向转动，一双戴皮手套的手臂握着它。方向盘最多只转 ±34°，正好是手能跟住的范围，所以手始终握在轮缘上；中间段做了放大，高速时前轮只转几度也看得出方向盘在动。车身侧滑角小于 6° 时，方向盘只跟玩家的输入走，不显示稳定辅助的细小修正；侧滑角超过 11° 才完整显示真实的漂移反打。
- 方向盘是从各车模型里自动分离出来的：先按材质名（Volante、SteeringWheel 等）找，找不到就按"圆、薄、半径 13–22 cm"挑最像轮缘的零件，再拟合出转向柱的方向和轮心（`src/cockpit.js`）。
- 手臂是写实模型（Sketchfab「Fps arms」），骨骼是在 Blender 里另外绑的（上臂 / 前臂 / 手，`racing/scene/arms_rig.blend`）。
- 握姿：在 Blender 里给手指加了指骨，对着一根半径 1.6 cm 的圆杆逐个关节往里弯，弯到贴住杆面为止（四指 + 拇指），再烘焙进模型（带指骨的版本存在 `arms_rig_fingers.blend`）。游戏里把这根"握杆"对齐到 9 点一刻握点处的轮缘切线，轮缘从拳心穿过；轮缘的实际半径、粗细是加载时从方向盘网格量出来的，管细的手会往里贴一点。
- 方向盘切出来以后还会用自身外轮廓拟合一次圆心和盘面，转轴偏了会自动纠正（Stratos 原来偏 3.5 cm、倾角差 9°）。
- 手臂用两段反向动力学从肩膀送到手腕；伸不到时那一侧肩膀往前探（最多 12 cm）。检查工具：`tools/cockpit_probe.js`（浏览器控制台里 import，见文件头）。
- 镜头每帧先更新整车的变换再取眼睛位置，所以高速时不会落在座位后面。

**怎么漂移**（2026-11-22 改成街机式，照另一个赛车游戏 UMBRA GT 第三版漂移的做法）：
- **进入**：带着方向拉一下空格（手刹），车尾立刻甩出去；或者带着方向点一脚刹车。
- **维持**：按住方向 + 油门。车身甩出去的角度决定车往弯里拐多快，所以漂移本身就是过弯的办法；
  按住方向在 80 km/h 时弧线半径约 45 米（T1 正好），拉住手刹能收到约 25 米（T6 发卡弯）。弧线太紧就点按方向，让角度小一点。
- **油门**：踩着油门时车被往车头指的方向推，车速基本不掉；松油超过 0.3 秒就开始收车。
- **收车**：松开方向、往反方向带一下、踩刹车、松油，都会在约 0.4 秒内收直。收车时行进方向往车头那边追三分之一，
  所以车头最后指着哪，车大致就往哪走：想出弯时车头对准出口再松手。
- **换边**：漂移中往反方向打并拉一下手刹，甩到另一侧（连续 S 弯）。
- 撞墙、转过头（超过约 77°）或车速低于 25 km/h，漂移自动结束。

AI 对手仍然用原来的抓地式开法，不漂移，所以会漂的玩家在弯里会比 AI 快不少（AI 落后时会稍微放快）。
参数都在 `src/physics.js` 的 `DRIFT`；`node tools/arcade_test.mjs` 可以无画面对比"原版 / 街机"两种手感过 T1 的结果。

菜单里可以选车（13 台，卡片可以左右滑，← → 也能切换）、圈数（2 / 3 / 5），以及有没有对手（5 台 AI，或无对手练习）。
每局的 5 台对手从车库里随机挑，不重复、也不会和你开同一台。

## 画质档位

地址后面加 `?q=ultra`、`?q=high`（默认）、`?q=medium` 或 `?q=low`。

| 档位 | 渲染像素 | 环境光遮蔽 | 车漆反射探针 | 其它 |
|---|---|---|---|---|
| ultra | 约 370 万 | 有 | 256，每帧 2 个面 | 同 high |
| high（默认） | 约 260 万 | 有 | 256，每帧 2 个面 | 3 级阴影、12 次采样的运动模糊、景深 |
| medium | 约 210 万 | 有 | 128，每帧 1 个面 | 2 级阴影、草减到六成 |
| low | 约 130 万 | 无 | 无（只反射天空） | 无抗锯齿、无运动模糊、无景深 |

帧率（M3 Max，2026-11-22 显卡空闲时）：最终版在约 260 万像素下，6 台新车一起跑、场边电视机位实测每帧 14.3 毫秒（约 70 帧，画面约 1080 万个三角面）。

更早的记录：加入遮蔽、雾、反射探针、车灯之后，在约 290 万像素下 6 台车停在发车格实测每帧 14.5 毫秒（约 69 帧/秒）。
之后又加了场边设施和草木的天光，并把默认档降到约 260 万像素；这之后没能再测出干净的数字（当时机器上另有渲染任务占着显卡），
所以最终版的帧率是未验证的。帧率不够就换 `medium`，或在地址后加 `&probe=0`、`&ao=0`、`&dressing=0` 逐项关掉。

## 物理

`src/physics.js` 是自己写的四轮模型：每个车轮有独立转速，轮胎力用归一化的合成滑移加魔术公式计算，
有纵向和横向的载荷转移、后轮驱动（锁止差速）、手刹、ABS、自动挡。积水处抓地力更低（和画面上的积水是同一份数据），
路肩、草地、砾石各有不同的抓地和阻力。键盘是开关量，所以加了三个辅助：自动反打、目标漂移角、分情况的牵引力限制。自动反打在抓地时（侧滑角 < 2°）只用一半力度，侧滑角超过 6° 才全力。原来全程满力度时，高速下它会和方向输入形成反馈：点一下方向键，前轮就在 ±4° 之间一直摆，停不下来。`node tools/steer_jitter.mjs` 可以量高速时前轮的来回摆动。
AI 沿最小曲率的赛车线做纯追踪，会避让，会根据和玩家的距离稍微放快或放慢。

## 已知不足

- 赛道是平的，没有起伏。
- 驾驶位视角：眼睛位置是对着截图一台台估的。手腕在手套和袖口之间露出一圈皮肤（原手臂模型就是这样）。917 和 280Z 用的是补装的方向盘（917 原模型的方向盘零件是坏的，280Z 原模型没有）；Stratos、Mustang 的方向盘位置是离线搜出来写死的。方向盘显示转角压到 ±34° 以内，不做交叉换手（试过跟到 ±50° 以上，交叉上来的手臂会挡住大半个前挡，低位方向盘的车手腕还会折得很怪）；代价是方向盘转动幅度比真车小得多。Stratos 模型自带的方向盘偏小（外径约 19 cm）。
- 街机漂移只用无画面测试和脚本按键验证过（T1 入弯 70 km/h 时 13 台车都能干净漂过，原版同样操作只有 5 台），还没有真人试玩，各弯的手感可能还要再调。
- 新加的 10 台都没有独立的刹车灯网格，刹车只靠尾灯光晕变亮表现；车灯光晕位置是按截图一台台对的，个别角度可能偏一点。
- 所有车都按后驱模拟；各车的手感参数是按车型特点估的，没有按真车数据标定，也没有真人逐台试驾过。
- 车与车的碰撞用三个圆近似车身，宽车（917、Countach）擦碰时车身可能看起来插进对方一点。
- Stratos 的模型没有独立的灯具网格：尾灯和大灯只有光晕，大灯光晕放在保险杠位置，车头那排拉力灯没有点亮。
- 草和树叶用的是引擎里不吃环境贴图的漫反射材质，天光是另外补的近似值。
- 看台观众、维修区立面是程序画的贴图，贴近看是平的。
- 声音是合成器做的，不是实录的引擎声。
- 不支持 WebGPU 的浏览器会回退到 WebGL，这条路径没有测过。
