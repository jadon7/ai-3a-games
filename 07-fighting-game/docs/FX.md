# 角色专属特效任务（共同说明）

你是 Opus 5.5，负责给格斗游戏《烬霜》里的**一个角色**做全套专属技能特效，要做到 3A 格斗游戏的特效水准（对标真人快打 1、铁拳 8、街霸 6 的技能特效：有层次、有体积、有节奏、和场景的光互相影响）。两个角色各一个任务并行：`yanjin`（阎烬，余烬之火）、`lingshuang`（凌霜，霜）。全程中文。用户在睡觉，没有人可以问：自己判断、自己截图挑毛病、改到满意。

## 先读

- `src/fx/types.ts`：你要实现的接口 `FighterFx`（每个钩子什么时候被调用都写在注释里）和 `FxCtx`。
- `src/fx/core.ts`：特效系统 `Fx`——粒子（`emit`，七种粒子）、弧形刀光（`slash`）、冲击环（`airRing`、`groundRing`）、柱子（`pillar`）、地面贴花（`decal`）、拖尾（`trail`）、残影（`ghost`）、瞬时点光（`flashLight`）、延时（`after`）、通用网格特效（`addMesh` + `material`）。**先把这个文件从头读一遍**，着色器怎么写、公共 uniform 有哪些都在里面。
- `src/fx/common.ts`（配色 `PAL`、通用打击火花）、`src/fx/generic.ts`（**元素基线特效：现在游戏里用的就是它，是你的起点和下限**，你的文件里没实现的钩子会自动落到它上面）。
- `src/present/fightFx.ts`：表现层怎么调用你的钩子，通用的打击火花、镜头震动、拖尾、轮廓光是它放的（你不用重复，在它上面加料）。
- `src/data/fighters.ts`：你这个角色的招式表（招式 id、帧数、`events` 里的特效事件点 `charge / release / dash / slam`、命中段的 `tag`）。`docs/FIGHTERS.md`：每一招的动作是什么样。
- `src/render/gfx.ts`：屏幕效果（`flash` 闪白、`chroma` 色散、`radialBlur` 径向模糊、`shockRing` 屏幕折射环）。`src/render/camera.ts`：`shake / addShake / hitPunch`。
- `src/present/fighterView.ts`：`self.rig.limbWorld('RH', v)`、`self.rig.weaponWorld(base, tip)`、`self.chestWorld(v)`、`self.pos`、`self.fighter`（模拟状态：`facing` 朝向 ±1、`move` 当前招、`mf` 招式进行到第几帧、`scale`）、`opp.tintK / tintColor`（给对手整体染色，比如冻结）、`opp.hitFlash`。

## 要交付的

`src/fx/<id>.ts`，默认导出一个工厂：`export default function (ctx: FxCtx): FighterFx { … }`。表现层看到这个文件就会自动用它（没实现的钩子落到基线）。需要的辅助代码放 `src/fx/<id>_lib.ts`（只有你用）。**`src/` 下别的文件都只读**；特效系统缺什么能力，先在自己的文件里用 `ctx.fx.addMesh` + 自己的着色器实现，同时写进报告。

每一招都要有专属的东西（清单在下面“美术方向”），重点投入顺序：**大招（定格 + 演出 + 最后一击）> 三个技能 > 重击和连段收尾 > 常驻细节 > 轻击**。

## 质量要求

- **分层**：一个好的技能特效至少有——预兆（蓄力：粒子向手上汇聚、光渐亮）、主体（形状清楚、有亮芯和有颜色的身子）、次级（火星 / 冰屑、烟 / 雾）、对环境的影响（瞬时点光把角色和地面照亮、地面留下痕迹、屏幕折射）、余韵（慢慢散掉的烟、余烬、冰屑，不要啪一下全没）。
- **形状要干净**，亮芯克制：泛光阈值是亮度 1.0，粒子 `intensity` 给太高、太多会糊成一片白。一个画面里最亮的东西只能有一两个。场景是雪夜（暗、冷），特效是画面里最亮的东西，但要留出层次。
- **节奏**：出手那一帧最强，之后快速衰减；命中时短促有力（顿帧期间特效照常走）。不要所有粒子同一时刻出生、同一时刻消失。
- **和动作贴合**：位置从骨骼、刀的世界坐标取（`limbWorld`、`weaponWorld`），方向跟 `self.fighter.facing`，不要写死。角色会镜像（二号位朝左），你的特效在朝左时也要对。
- **性能**：1920×1080 全套后处理下稳 60 帧。粒子池有上限（`core.ts` 里 `caps`），一招别超过几百个粒子；`ghost` 一次冲刺最多四五个；`flashLight` 只有 4 盏轮流用；`update` 里不要每帧 `new` 对象、不要每帧建材质。演出结束后不留常驻的网格和灯。
- **不要改玩法**：特效只是画面，不许改 `fighter` 的状态；`ctx.slowmo` 只在大招最后一击这类时刻用，时间别超过 1 秒（表现层已经在最后一击放了慢动作，你一般不用再放）。

## 怎么看效果

- 开发服务器已经在 `http://localhost:5300`（Vite，没有热更新，改了刷新）。**不要重启、不要停。**
- 连拍工具（无界面 Chrome，一招拍若干帧拼成联系表）：
  ```bash
  node tools/fxshot.mjs --out docs/fx_<id>/sp1.jpg --move sp1 --who 0 --frames 4,10,16,22,30,40,55,75 --gap 3.5 --q "standin&training&mute&nostage&p1=<id>"
  ```
  - `--who 1` 加 `--q "…&p2=<id>"` 可以看朝左（镜像）的情况。`--opp block` 看被防住。`--gap` 是两人间距（米）。`--move light1,light2,light3` 连着出。
  - `--q` 里：`standin` 用替身模型（**现在正式模型的动作还没做完，先用替身调；替身的动作和正式的不一样，所以位置一律从骨骼取**），`nostage` 用占位场景（正式场景做好以后去掉它再看一遍），`training` 训练模式（气是满的）。等 `art/fighter/<id>/STATUS.md` 里写着你要看的那几招已经有了，就去掉 `standin` 用正式模型再拍一遍。
  - 大招：`--move ult --frames 5,30,60,80,95,110,130,160,190,220,260,300 --gap 2.2`（定格约 60 帧，命中后进入演出）。
  - 页面里有 `window.__dbg`（`src/debug.ts`）：`__dbg.move(i, id)`、`__dbg.run(秒)`、`__dbg.place(x0, x1)`、`__dbg.state()`；`--pre "JS"` 可以在出招前执行一段。
- 用 Read 看联系表。每一招都要看：朝右、朝左、被防住、打空。看完自己列毛病（糊、太亮、位置不对、层次少、消失太突然、和动作脱节），改完再拍，至少三轮。
- 帧率：`--pre` 里跑一段然后读 `__dbg.fps()` 不准（手动推进时不是实时）；用真实时间量：自己写个小脚本让页面自动跑 5 秒（`game.manual=false`）连续放技能，读 `game.fps`。
- 同一时间只开一个你自己的无界面 Chrome（`fxshot.mjs` 每次自己开自己关）。另一个角色的任务、场景任务、界面任务也在用无界面 Chrome，机器会忙，截图白屏或超时就重来。

## 美术方向

### 阎烬 `yanjin` · 余烬之火
配色：亮芯暖白偏黄 → 橙 → 深红 → 黑烟，加大量上升的余烬火星。写实的火：有噪声侵蚀出来的火舌形状、有黑烟、有热浪折射，不是卡通的一团橙色。
- 常驻：前臂铁箍缝里的余烬——站着时偶尔飘起一两颗火星；出重招时铁箍“烧起来”（前臂上附着火舌和一盏跟着手走的小橙光）。
- 轻击连段：拳风拖尾已经有了；`light3`（顶肘）和 `heavy`（崩拳）命中时，火焰顺着出拳方向从对手身后喷出去一股（锥形火舌 + 火星），不是只在命中点炸一团。
- `lunge`（贴山靠）：冲撞的路径上地面留一道焦痕，撞上时一圈径向的火焰爆开。
- `launcher`（冲天炮）：拳头上升的路径上一条螺旋上升的火带，命中时一小股向上的火柱。
- `sweep`：贴地一道扇形的火星和雪尘。`air`（飞踢）：脚上拖火。
- `grab`：每一下短拳一小团爆燃，最后一推是一次像样的爆炸。
- `sp1` 隔空崩拳（`charge` → `release` → 飞行道具 `fireblast`）：蓄力时余烬向右拳汇聚、拳头越来越亮、脚下一圈热浪；出手瞬间拳前一个冲击环加屏幕折射；火球本体是一个明亮的核加一层层翻卷的火焰外壳，后面拖着长长的火舌、黑烟和火星，飞过的地面被照亮；命中或对撞时爆炸（火球、黑烟蘑菇、四溅的火星落地反弹、焦痕）。
- `sp2` 燎原冲拳（`dash`）：冲刺全程身后拉出一道贴地燃烧的火线（留在地上烧零点几秒）和余烬色的残影；最后的上勾拳带一道向上的火弧。
- `sp3` 震地（`slam` → 贴地道具 `firepillar`）：拳头砸地：裂痕贴花（缝里透红光，慢慢暗下去）、冲击环、碎石和雪被掀起；然后火沿着地面向前窜，每隔一段喷出一根火柱（柱子有粗有细、有高有低，根部有碎石），火柱灭了以后地上留着几处小火苗烧一会儿。
- `ult` 焚天：
  - 定格（`onSuperFreeze`，约 1 秒）：他周身的火“点着了”——脚下一圈火环向外推开、身上附着向上窜的火焰、大量火星向上、场景被橙光照亮。
  - 冲刺重拳命中后进入演出（`onCineStart` / `onCineBeat`）：每一拳一团方向各不相同的爆燃（左拳往右喷、右拳往左喷），一拳比一拳大；顶肘和回身摆拳带火弧。
  - 最后一击（`final`）：冲天炮——一根直冲出画面的巨大火柱（外层旋转的火、内层白亮的芯），地面炸出大片裂痕和焦坑，满屏下落的余烬（持续两三秒），闪屏、折射冲击波。这一下要是全场最震撼的画面。

### 凌霜 `lingshuang` · 霜
配色：白 → 冰青 → 蓝。冷、锋利、干净：细而亮的刀光、会碎的冰、贴地蔓延的霜、缓慢下沉的寒雾。不要做成一团团蓝色的火。
- 常驻：刀身上持续往下淌的寒气（很淡），刀尖偶尔一点冷光闪过。
- 轻击连段：刀光拖尾已经有了；每一刀在命中帧补一道**和这一刀的挥动方向一致**的月牙弧光（用刀在前后两帧的位置算出挥动的平面和方向，`ctx.fx.slash` 的 `rot` 可以定平面），细、亮、很快消失；命中时冰屑四溅。
- `heavy`（力劈）：一道竖直的大月牙，刀落地的地方向前窜出一条霜线。
- `lunge`（突刺）：沿刀的方向一道细长的直线寒光（像一根光的长枪）加一个小冲击环。
- `launcher`（上撩）：向上的月牙，带起一串上升的冰屑。`air`（跃斩）：向下的月牙。
- `sp1` 霜月斩（`charge` → `release` → 飞行道具 `crescent`）：蓄力时刀身结霜变亮、寒气向刀汇聚；月牙冰刃本体是一道大的弧（薄而亮的刃口 + 半透明的冰质身子），后面拖着冰屑和寒雾，经过的地面留下一条霜痕；命中时碎成一大片冰晶，对手短暂被染成霜色（`opp.tintK`）。
- `sp2` 踏雪（`dash`，命中段 `tag: 'dashcut'`）：起步处炸开一团雪尘，身形化成几道冰青色的残影，路径上一条贯穿的细亮直线；**命中后延迟零点一几秒**，对手身上才接连闪出两三道交叉的斩痕（细长的白线，一道一道出现），然后冰屑爆开。这个“先过去、后斩开”的延迟是这一招的灵魂。
- `sp3` 冰棘（`slam` → 贴地道具 `icespikes`）：刀插进地面，霜从刀尖向前蔓延（贴花），一丛一丛的冰刺依次破地而出（有主有次、有菲涅尔的冰质感、顶端有高光），停一下以后碎成冰屑，地上留着霜痕。基线里的 `iceSpike` 可以拿来改。
- `ult` 霜天：
  - 定格：气温骤降——以她为中心一圈霜在地面上向外蔓延、空中出现大量缓慢飘落的冰晶、刀身亮到发白、整个画面被冷光照亮。
  - 演出每一刀：贯穿对手的细长斩痕（方向各不相同），**斩痕留在原地不消失、越积越多**；回旋斩和上撩带大的月牙。
  - 最后一击：下劈的瞬间，之前留下的所有斩痕同时亮起，对手被一大丛冰晶封住（`opp.tintK = 1`），停顿一拍，然后冰晶连同斩痕一起炸碎——满屏冰屑、白闪、一圈雪雾冲击波，地上留下一大片霜和残冰。

## 规矩和交付

- 只写 `src/fx/<id>.ts`、`src/fx/<id>_lib.ts`、`docs/fx_<id>/`。
- 尽快先交一版（哪怕只重做了大招和一个技能），之后边做边覆盖；每次交付在 `docs/fx_<id>/STATUS.md` 记一行。文件随时要能通过类型检查（`npx tsc --noEmit`，只看你自己文件的报错），不然整个游戏的特效会掉回基线。
- 结束进程只用确切 PID，禁止 `pkill`、`killall`；`rm` 只写完整的字面量绝对路径；不跑等输入的命令；长命令放后台；不 `git commit`。
