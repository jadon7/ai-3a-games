# 场景任务：雪夜残寺

你是 Opus 5.5，负责给一个 2.5D 横版格斗游戏（three.js 0.175，写实 · 东方暗黑武侠）做**唯一的一张对战场景**，要做到 3A 游戏的观感。全程中文。用户在睡觉，没有人可以问：自己判断、自己改到满意，走不通的写进报告。

## 画面目标

**雪夜的山中残寺前院**。两名角色：阎烬（火，橙红）对凌霜（霜，冰蓝）。场景的光也是这一对颜色：**冷的月光和雪**对**暖的灯笼和火盆**，青橙对比是这张图的灵魂。

- 地面：大块的旧石板，缝里有残雪，局部有薄冰和积水（有反光），两侧和远处是积雪。**对战的那一条（x 从 -10 到 10、z 从 -1.5 到 1.5）必须是 y = 0 的平地**，不能有凸起，角色的脚、影子、地面特效都贴着它。
- 中景（z 约 -5 到 -14）：寺庙的山门或大殿正面（红漆剥落的木柱、斗拱、瓦顶上压着雪），台阶，一对石狮或石像生，石灯笼，两个烧着火的铁火盆（火光是场景里最重要的暖光源，有闪烁），挂着的红灯笼（微微摇晃），褪色的经幡或布条在风里动。
- 远景：雪松或枯树的剪影，远山，月亮，夜空薄云。分三四层，有雾把层次隔开。
- 空气：缓慢飘落的雪（近处大而虚、远处小而密），火盆飘起的火星，地面一层流动的薄雾。
- 调子：整体偏暗、对比高，但角色脚下的地面要是中间调，角色站上去轮廓清楚；不要整张图黑成一片，也不要高饱和的霓虹色。画面中间（角色活动的区域）背后不要放太花、太亮的东西，免得抢角色。

对标：真人快打、铁拳、对马岛之魂里雪夜场景的质感。做之前先想清楚这类场景好看在哪（层次、体积雾、冷暖光、地面反光），做完对着找差距，改几轮。

## 技术约束

- 坐标：对战在 z = 0 平面，x 左右（角色活动范围 -8.2 到 8.2），y 向上，地面 y = 0。**镜头在 +z 一侧朝 -z 看**：竖直视角 32 度，离对战平面 6.1 到 11.5 米，高 1.3 到 2.2 米，注视点高约 1 米，左右跟着角色移动（镜头 x 大约在 -6.5 到 6.5）。画面上能看到的范围大约是 x -17 到 17。
- 大招和出场时镜头会切到近景：离角色 2 到 4 米、高 0.5 到 2 米、绕到侧前方最多 50 度。所以背景要往两侧延伸（x 到 ±28），z 到 +6 以内的地面也要像样；镜头身后（z > 12）不用做。
- 实现 `src/stage/types.ts` 里的 `Stage` 接口，入口是 `src/stages/temple/index.ts`，导出 `export const createTempleStage: StageFactory`。场景自己负责：`scene.background`、雾、`scene.environment`（环境贴图，要给角色提供像样的环境光和反射）、所有灯光、主光的阴影（阴影要盖住 x ±11、z ±3 的范围，角色投影清楚）。参考占位实现 `src/stage/placeholder.ts`。
- `setDim(k)`：大招时把场景压暗（灯光、环境光、自发光、雾色都跟着暗），k 从 0 到 1 连续变化，每帧都可能被调用，不能有开销大的操作。
- `onImpact(x, strength)`（可选）：有东西砸地时附近的雪粉、火盆有点反应。
- 游戏那边会另外给角色加轮廓光、画技能特效、做后处理（泛光阈值在亮度 1.0 以上、环境光遮蔽、色调映射 ACES、暗角、颗粒）。所以：火、灯笼的自发光要给到 1 以上才会有泛光；别的东西不要超过 1。你不要自己加后处理。
- 性能：M3 Max 的 Chrome 里 1920×1080 加上全部后处理要稳 60 帧。总面数 60 万以内，绘制调用 150 以内（同种东西用实例化），贴图单张不超过 2048，能合并就合并；带阴影的灯只有主光一盏，火盆和灯笼用不带阴影的点光（总数不超过 6）。雪和火星用一个着色器粒子系统（放在顶点着色器里算，不要逐粒子用 JS 更新）。
- 地面反光：先用低粗糙度加环境贴图。**加分项**：给对战那一条地面做平面反射（角色和技能特效的光倒映在湿石板上，模糊、按湿度图遮罩，半分辨率），做成可开关（`?reflect=0` 关），掉帧就默认关。
