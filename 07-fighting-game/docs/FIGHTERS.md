# 角色与动作设计（主线定稿，2026-11-25）

游戏：原创 2.5D 横版格斗（3D 角色、侧面镜头），写实 · 东方暗黑武侠。两名全新角色，做到极致。
对战时两人沿左右方向对站，**游戏镜头在角色的右手一侧**（等于动作管线里的“侧面机位”）。所以所有动作**首先要在侧面机位里好看**：出招往“正前方”（正面机位的方向、侧面画面里的右边）打，幅度和剪影在侧面要读得清。

## 两名角色

| id | 名字 | 定位 | 元素 | 武器 | 设定图 |
|---|---|---|---|---|---|
| `yanjin` | 阎烬 · 烬拳 | 重拳压制，八极拳 / 洪拳路子，沉、狠、每一下都带震脚 | 余烬之火（橙红） | 赤手空拳（前臂铁箍缠手） | `concepts/fighters/yanjin-sheet-1.png` |
| `lingshuang` | 凌霜 · 霜刃 | 快攻，唐刀术，轻、快、转身多、刀随身走 | 霜（冰蓝、冷白） | 右手单手长刀「霜刃」 | `concepts/fighters/lingshuang-sheet-1.png`，武器 `lingshuang-weapon-1.png` |

身高（游戏里）：阎烬 1.92 米，凌霜 1.74 米。

## 架势（两人通用的规矩）

- **左脚在前、左肩朝向对手**，胸口转向自己的右侧（侧面机位能看到胸口和持刀的右手）。重心下沉，双膝微屈。
- 所有一次性动作（攻击、技能、防御、跳）**从架势开始、回到架势结束**，游戏里才能和别的动作接上。
- 动作原地做（像在跑步机上），不要走出画面；向前冲的招式用“上一步、身体前压到极限”表现，位移由游戏加。

## 每人 21 段专属动作（走视频管线）

动作 id 两人相同，游戏按 id 取用。每段视频 5 秒。一次性动作写成“做一遍，收回架势，停顿片刻，再做一遍”，挑好的那一遍。

### 阎烬 `yanjin`

| id | 类型 | 怎么动 |
|---|---|---|
| `idle` | 循环 | 八极拳架势：左脚在前，左手立掌护在胸前、掌心朝右，右拳收在右腰侧；重心沉，双膝微屈，随呼吸缓慢起伏，左手手指偶尔开合，像一头随时会扑出去的虎 |
| `walk_f` | 循环 | 保持架势向前垫步：左脚向前滑进半步，右脚跟上，不交叉步，上身稳、头不晃，双手始终护在身前（跑步机上那样原地做） |
| `walk_b` | 循环 | 保持架势向后撤步：右脚先退半步，左脚跟着收回，上身稳，双手护在身前 |
| `jump` | 一次 | 屈膝下蹲蓄力，垂直向上高高跃起，空中收腿团身、双拳护在胸前，落地屈膝缓冲，回到架势 |
| `block` | 一次 | 双前臂竖起并拢挡在面前和胸前（铁箍朝外），含胸收下巴，重心后坐、后腿弯曲撑住，保持约两秒，然后放下回到架势 |
| `light1` | 攻击 | 左手刺拳：前手从胸前笔直向正前方快速打出一拳，手臂伸直、肩膀送出去，立刻收回 |
| `light2` | 攻击 | 右手直拳：右脚蹬地、腰胯猛地向左拧转，右拳从腰间向正前方直线打出，身体前压，手臂完全伸直，再收回架势 |
| `light3` | 攻击 | 上步顶肘：右脚向前重重踏上一大步（震脚），身体前冲，右臂屈肘、肘尖向正前方猛顶出去，左手掌托在右拳上；停住半拍，再撤步回架势 |
| `heavy` | 攻击 | 崩拳：右拳先大幅拉到身后蓄力、身体向右拧到极限，然后后脚猛蹬、全身拧转，右拳向正前方轰出一记重拳，身体前压到极限、后腿蹬直，拳停在最远处定格半秒，再收回 |
| `lunge` | 攻击 | 贴山靠：身体下沉、右肩向后一收，然后左脚向前垫一大步，整个人侧过身用左肩和后背向正前方猛撞出去，双臂向两侧震开；定格半拍，再收回 |
| `launcher` | 攻击 | 冲天炮：深蹲、右拳收到胯边，然后双腿猛蹬，右拳自下而上打出一记大幅度上勾拳，整个人跟着腾空跳起、右拳举过头顶，落地回架势 |
| `sweep` | 攻击 | 扫堂腿：身体迅速下蹲、左手撑一下地，右腿伸直贴着地面从右向左横扫半圈，然后收腿站起回架势 |
| `air` | 攻击 | 飞踢：原地高高跳起，空中右腿向正前方斜下方用力蹬出、左腿收在身下，双臂张开保持平衡，落地屈膝缓冲回架势 |
| `grab` | 攻击 | 擒拿：左脚上一步，左手向正前方探出、五指一抓并往回拽到胸前（像揪住对方衣领），紧接着右拳连续两记短促的勾拳打向身前腹部高度，最后双掌向正前方猛力一推，定格 |
| `sp1` | 技能 | 隔空崩拳（放出火焰冲击波）：右拳缓缓拉到耳后、左掌前伸瞄准，蓄力半秒，然后弓步向正前方凌空轰出一拳，手臂伸直定格一秒，再收回 |
| `sp2` | 技能 | 燎原冲拳（冲刺重拳）：身体压低前倾成冲刺预备姿势、右拳拖在身后，然后向正前方大步冲出两步，冲到尽头右拳自下而上斜着向前上方猛轰出去，身体舒展到极限，定格半秒 |
| `sp3` | 技能 | 震地（地面喷火）：右拳高高举过头顶、身体后仰蓄力，然后向前跨半步单膝重重跪下，右拳狠狠砸向身前的地面，左手撑膝，低头；停住一秒再站起回架势 |
| `ult_start` | 大招 | 焚天 · 起手：双脚左右一震、沉腰扎马，双臂从身体两侧缓缓上举再猛地向两侧震开，仰头怒吼；然后压低身体，向正前方冲出一步打出一记右手重拳，定格 |
| `ult_combo` | 大招 | 焚天 · 连打：站在原地向正前方连续打出左、右、左、右四记大幅度的重拳（每一拳身体都跟着拧转），接一记右顶肘，再接一记转身左摆拳，最后深蹲蓄力、打出一记腾空的冲天炮上勾拳并跃起，落地后右拳缓缓收回腰间 |
| `win` | 一次 | 胜利：右拳重重砸进左掌，双手在胸前抱拳，然后右拳缓缓收到腰间、左手背到身后，站直身体、昂首，定格 |
| `intro` | 一次 | 出场：向前稳步走上两步站定，双手在身前扯紧前臂上的缠手带（左、右各一下），头向左、向右各扭一下活动脖子，右拳砸一下左掌，然后沉腰摆出架势 |

### 凌霜 `lingshuang`（刀始终在右手，不脱手）

| id | 类型 | 怎么动 |
|---|---|---|
| `idle` | 循环 | 刀架势：左脚在前、前脚掌虚点地，右手持刀垂在右侧身后、刀尖斜指前下方，左手两指并拢成剑指立在胸前；重心轻，随呼吸微微起伏，刀尖偶尔轻轻一颤 |
| `walk_f` | 循环 | 保持持刀架势向前垫步：左脚轻快地向前点出半步，右脚跟上，不交叉步，上身稳，刀拖在身后（跑步机上那样原地做） |
| `walk_b` | 循环 | 保持持刀架势向后撤步：右脚先退、左脚跟着收回，脚步轻，刀横在身前戒备 |
| `jump` | 一次 | 轻轻一蹲，垂直向上高高跃起，空中双腿收起、身体舒展，刀横在身前，轻盈落地、屈膝缓冲，回到架势 |
| `block` | 一次 | 双手持刀竖在身前：右手握柄、左手掌根抵住刀背，刀身竖直挡在面前，重心后坐，保持约两秒，然后放下回到架势 |
| `light1` | 攻击 | 横斩：右手刀从右向左在胸口高度迅速横斩一刀，腰跟着拧，刀停在左侧 |
| `light2` | 攻击 | 回斩上挑：刀从左下方向右上方反手斜挑上去，身体跟着舒展，刀尖指向右上方 |
| `light3` | 攻击 | 回旋斩：以左脚为轴向右快速转身一整圈，刀随身体水平抡满一圈，转回来时刀正好横扫过正前方，马尾跟着甩起来；停住，收回架势 |
| `heavy` | 攻击 | 力劈：双手握刀高高举过头顶、身体后仰，然后右脚向前重踏一步，刀从头顶笔直劈到身前膝盖高度，身体前压，定格半秒，再收回 |
| `lunge` | 攻击 | 突刺：身体压低、刀收到右腰侧、刀尖朝前，然后右脚向前猛跨一大步成弓步，右臂完全伸直把刀尖向正前方直刺出去，左臂向后展开，身体和后腿成一条直线，定格半秒 |
| `launcher` | 攻击 | 上撩：深蹲、刀垂到左脚边，然后双腿蹬地，刀自下而上贴着身前撩起一个大弧，整个人跟着腾空跃起、刀举过头顶，落地回架势 |
| `sweep` | 攻击 | 扫腿：迅速下蹲、左手撑地，右腿伸直贴着地面从右向左横扫半圈，刀背在身后，然后站起回架势 |
| `air` | 攻击 | 跃斩：原地高高跳起，空中双手握刀举过头顶，然后向正前方的斜下方用力劈下，落地屈膝、刀劈到身前，回架势 |
| `grab` | 攻击 | 擒拿：左脚上一步，左手向正前方探出一抓并往回一带，紧接着右膝向前上方提膝一撞，再用右手刀柄的柄尾向正前方猛地一捣，定格 |
| `sp1` | 技能 | 霜月斩（放出月牙冰刃）：身体向右后方大幅拧转、刀拉到左肩后方蓄力，停半秒，然后猛地反向拧身，刀在胸口高度向正前方水平挥出一个大弧，挥完手臂伸展、刀指向正前方，定格一秒 |
| `sp2` | 技能 | 踏雪（瞬步突进斩）：身体压得很低、刀收在左腰侧像拔刀的预备姿势，停半秒；然后右脚向前猛蹬一大步，刀从左腰向右上方闪电般横斩出去，手臂完全展开，身体停在弓步、刀斜指右后上方，定格一秒 |
| `sp3` | 技能 | 冰棘（地面冒冰刺）：把刀倒转成刀尖朝下，双手握柄高举过头，然后单膝跪下，把刀尖狠狠插向身前的地面，低头，停住一秒；再拔刀站起回架势 |
| `ult_start` | 大招 | 霜天 · 起手：把刀缓缓举到面前横着，左手两指从刀根慢慢抹到刀尖；然后刀一甩、身体压低，向正前方闪电般冲出一步斩出一刀，定格 |
| `ult_combo` | 大招 | 霜天 · 连斩：站在原地向正前方连续斩出四刀（右上到左下、左上到右下、横斩、反手横斩，一刀接一刀很快），接一个转身一圈的回旋斩，再接一记自下而上的上撩并腾空跃起，空中双手握刀向下劈落，落地单膝跪地、刀横在身侧定格 |
| `win` | 一次 | 胜利：刀在身侧挽一个刀花，向斜下方用力一甩（甩掉刀上的霜），然后刀尖斜指地面，侧身、抬头，定格 |
| `intro` | 一次 | 出场：右手提刀垂在身侧，向前缓步走两步站定；抬刀横到眼前，左手两指从刀根抹到刀尖；然后刀向右下一挥，沉身摆出持刀架势 |

## 通用动作（另一个任务做，不走视频）

受击（头、腹、侧、重击）、击飞倒地、起身、被击败、眩晕等，用 Tripo 的预设动作重定向到每个角色自己的骨架上，产出 `<id>_generic.glb`。视频管线不擅长贴地的姿势，所以这些不在上面的清单里。
