# 筋斗云驾驶模拟器

在云海之上的峰林间驾云飞行。画面沿用写实版影片的角色、石峰、天空和调色，全部实时渲染。

## 怎么启动

双击 `启动游戏.command`。它会在本机开一个小型文件服务，并用默认浏览器打开游戏（推荐 Chrome）。关掉弹出的终端窗口就是退出。

也可以在这个文件夹里手动运行：

```bash
node tools/serve.mjs --open
```

## 操作

| 按键 | 作用 |
|---|---|
| W / S 或 ↑ / ↓ | 拉高 / 俯冲 |
| A / D 或 ← / → | 左转 / 右转（也可以移动鼠标） |
| Shift | 加速（镜头会被甩到身后很远，能看到整条筋斗云拖尾） |
| Ctrl 或 X | 减速 |
| 空格（或鼠标左键） | 翻筋斗冲刺 |
| C | 换镜头：追尾、贴身、侧面跟拍、正面特写、掠过机位、航拍 |
| Q / E（按住）或滚轮 | 调镜头焦距：Q 广角、E 长焦，按 0 复位；暂停菜单里也有焦距滑条，当前焦距显示在屏幕右侧 |
| T | 自动巡航（自己沿金环航线飞，适合看风景和录屏） |
| V | 拍照模式：时间变慢，移动鼠标环绕，滚轮调远近 |
| L | 电影遮幅（2.39:1 黑边） |
| H | 隐藏界面 |
| R | 回到起点 |
| Y | 升降反向 |
| M | 静音 |
| F | 显示帧率 |
| Esc / P | 暂停（菜单里可以切画质） |

手柄也能用：左摇杆转向升降，RT 加速，LT 减速，A 翻筋斗，Y 换镜头。

## 玩法

- 沿途的金环连成一条航线，穿过加分，连续穿过累计连击。
- 贴着云面飞会被云托住，可以短暂钻进云里。
- 撞到石峰会被弹开并掉速。
- 右下角记录已飞行的里程，目标是十万八千里。

## 这一版新增

- 美猴王造型：凤翅金冠、两根长翎子、黄金甲、带金线纹样的大红披风（实时布料解算）。
- 待机时会在搭凉棚、叉腰、扛棒、挠头、回头、大笑等姿态之间自己切换。
- 双脚陷在筋斗云里；贴着云面飞会把云海犁开，留下 V 形尾波。
- 加速时镜头被甩到身后很远，换成广角，能看到整条筋斗云拖尾；带速度流光和运动模糊。

## 画质

暂停菜单里可以在「流畅 / 高 / 极致」之间切换，运动模糊也在这里调（关 / 标准 / 强），也可以直接在网址后面加 `?q=low`、`?q=high`、`?q=ultra`。

## 录屏和截图（开发用）

```bash
node tools/shot.mjs --q "shot=1&t=6&cammode=side&hud=0&lb=1" --out shots/a.jpg
```

```bash
node tools/record.mjs --out shots/demo.mp4 --q "t=2&cammode=chase&hud=0" --seconds 10
```
